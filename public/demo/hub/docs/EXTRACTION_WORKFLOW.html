전향 연구 데이터 추출

14일마다 수술 전·후를 통합한 CDW 요청 명단을 만들고, 받은 원천자료를 사전점검 후 처리해 결과를 확인합니다.

격주 통합 추출 규칙

언제·무엇을

14일마다(금요일 08:00) 수술 전·후를 한 번에 요청합니다. CDW 시트도 구분 없이 한꺼번에 뽑습니다.

명단은 작업 스케줄러가 자동으로 만들고 팝업으로 알립니다. 수동 실행은 python -m scripts.prepare_extraction.
누가 대상인가

수술 3일 뒤부터 명단에 오릅니다. 수술 전이 미완료이거나, POD45 이상인데 수술 후가 미완료인 건이 대상입니다.

수술 전·후가 모두 완료(Y)면 대상에서 빠집니다. 취소 수술은 제외합니다.
단계

POD45 미만은 수술 전·수술 중(preop.·op.)까지, POD45 이상은 병리·수술 후·합병증까지 처리합니다.

대상 명단의 단계 열(pre / full)로 구분합니다.
PASS 와 재요청

RID 미매칭·수술기록 미작성·변수 오류는 PASS 로 두고 다음 배치에 다시 요청합니다. 연속 3회 PASS 면 검토 파일로 올립니다.

data/review/extraction/<배치>_PASS_검토.csv
재추출 자료

같은 키는 이전 버전을 보존한 채 새 값으로 교체합니다. 조회 기간은 환자별 "전체~추출일"이며 적재는 자르지 않습니다.

변경·삭제 의심은 환자번호 기준으로 data/working/change_history/<배치>.xlsx 에 기록합니다.
분기 확정 재추출

완료된 건도 분기마다 1회 다시 받아 원천 수정을 반영합니다. 스케줄러가 통합 명단과 함께 만듭니다.

수동 실행은 python -m scripts.prepare_extraction --recheck.

준비할 자료

전향 등록 마스터

연구 대상자 등록번호와 RID 연결을 관리하는 명단입니다.

data/linkage/hospital/incoming/에서 관리합니다. 매 배치에 복사하지 않습니다.
이번 배치 대상자 명단

이번에 추출할 환자번호와 수술일 목록입니다.

배치 폴더의 target_episodes.xlsx와 batch.json에 지정합니다.
CDW 원천자료

대상 에피소드의 등록자료, 수술일정, 필요한 검사·기록 자료입니다.

ENROLLMENT_LIST.xlsx와 수술일정 등 요구 원천을 배치 폴더에 둡니다.

배치 처리 순서

1

전향 등록 마스터를 갱신합니다.
등록번호와 RID 연결은 공통 연결표에서 관리합니다.

2

생성된 CDW_REQUEST.xlsx를 CDW에 올리고, 받은 원천자료를 data/inbox/YYYYMMDD_NN/에 넣습니다.
대상 명단(target_episodes.xlsx)은 명단 생성 때 같은 배치 폴더에 만들어집니다. 시트는 수술 전·후를 나누지 않고 한 번에 뽑습니다.

3

사전점검 후 배치를 실행합니다.
적재 뒤 등록번호를 RID와 연결하고, 연결 또는 대상 에피소드가 불확실하면 검토 대상으로 멈춥니다.

4

검토 항목을 확인하고 eCRF 결과를 확인합니다.
통과한 결과는 출력 폴더에 생성됩니다. 파일을 넣는 것만으로 자동 제출되지는 않습니다. 근거가 같은 항목의 이전 승인은 자동으로 이어지고, 근거가 달라지면 다시 검토로 돌아옵니다.

enroll_list는 입력 파일이 아닙니다. 파이프라인이 만드는 뷰입니다. 다만 CDW 원천인 ENROLLMENT_LIST.xlsx는 배치 입력으로 필요합니다.

점검과 결과 위치

CDW 업로드용 Excel 생성

통합(기본): python -m scripts.prepare_extraction
분기 확정 재추출: python -m scripts.prepare_extraction --recheck

첫 시트 A열에 헤더 없는 환자번호 명단(data/working/cdw_requests/<배치>/CDW_REQUEST.xlsx)을 생성합니다. 명령이 반환한 파일을 CDW에 올리고, 추출본은 반환한 배치 폴더에 넣습니다. 동의서 마스터의 수술 전·수술 후 Y/N은 에피소드별 완료 기록(매칭·수술기록·변수 실행 성공)으로 갱신되며, PASS 건은 완료로 세지 않습니다. 이전 방식인 --phase pre·--phase post 단독 실행은 호환용으로만 남아 있습니다.
사전점검

python -m scripts.preflight_batch --batch-id YYYYMMDD_NN

필수 명단·원천·파일 구성을 확인합니다.
