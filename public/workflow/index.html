에이전트 작업 지도

임상 기준을 정하고 결과를 승인하는 사람은 연구자입니다. Claude Code 는 요구사항을 구조화해 설계안과 작업 지시를 만들고, 리뷰·테스트·커밋을 조정합니다. 코드는 실행 담당 둘 중 하나가 짭니다. 로컬은 Codex, 원격은 Jules 입니다. 모든 작업은 워크트리에서 시작해 /land 로 main 에 합쳐집니다. 출처는 AGENTS.md, docs/agent/*_DELEGATION.md, 프로젝트·전역 settings.json 의 훅 설정입니다.

연구자 (최종 판단) Claude Code (조정) Codex (로컬 실행 담당) Jules (원격 실행 담당) 넘으면 안 되는 경계

누가 무엇을 하나

연구자 · 최종 판단

  • 임상 기준·변수 정의
  • 요구사항 승인
  • 사례 판정·포함/제외 기준
  • 결과 검증과 최종 결정

Claude Code · 조정

  • 요구사항 구조화·설계안 작성
  • 지시서 작성·실행 담당 선택
  • diff 리뷰·테스트·커밋·병합
  • 판정이 필요한 항목은 대기열로 넘김

Codex · 로컬 실행 담당

  • 로컬 코드 구현·테스트 작성
  • 로컬 DB·파일이 필요한 일
  • 모델은 지시서에서 -m 으로 지정 (기본 SOL)
  • 커밋하지 않음

Jules · 원격 실행 담당

  • CI·의존성·독립 버그 수정
  • 합성 fixture·테스트·기계적 리팩터링
  • 명세가 확정된 구현
  • 결과는 report 요약만 읽음

통제의 한계

훅과 규칙이 실제로 보장하는 것과 보장하지 못하는 것입니다. 2026-10-22 에 훅 코드와 설정 파일을 직접 읽고 확인했습니다.

커밋 전 리뷰

하는 일리뷰 표시가 30분 안에 없으면 첫 커밋을 한 번 멈추고 /code-review 를 하라고 알립니다.
보장하지 못하는 것표시가 커밋할 diff 와 묶여 있지 않습니다. 같은 커밋을 다시 시도하면 리뷰 없이 통과합니다. 실제 품질 확인은 4단계 diff 리뷰와 /land 의 테스트가 맡습니다.

Codex 실행 권한

하는 일워크트리 안에서만 부르게 막고, 맡길 범위는 지시서로 정합니다. 결과는 커밋 전에 diff 로 리뷰합니다.
보장하지 못하는 것샌드박스 없이 전체 권한으로 실행되고, 명령마다 승인을 묻지 않습니다. Windows 샌드박스 계정이 만든 임시 폴더를 지울 수 없는 문제 때문에 이렇게 정했습니다. 네트워크·파일 접근을 막는 장치는 없습니다.

실데이터 경계

하는 일data/ 파일은 커밋하지 않고, GitHub·Jules 로는 코드만 보냅니다. Jules 는 합성 데이터로만 테스트합니다.
보장하지 못하는 것Claude Code·Codex 가 작업 중 읽은 내용은 각 모델 서버로 전달됩니다. 파일 업로드는 막지만, 에이전트가 읽는 것까지 막지는 않습니다.
