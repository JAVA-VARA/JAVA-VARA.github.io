### 혼자 공부하는 자바스크립트

## **06. 객체**

06–3. 객체와 배열 고급

1. 속성 존재 여부 확인

객체에 없는 속성에 접근하면 undefined 자료형이 나온다. 조건문인지 undefined인지 확인하면 속성 존재 여부를 확인할 수 있다.

```
        
        //객체를 선언합니다.
        const object = {
            name: '혼자공부하는파이썬',
            price: 18000,
            publisher: 'hanbit',
        }

        //객체 내부에 속성이 있는지 확인한다.
        //[방법 1]
        if(object.name !== undefined){
            console.log('name 속성이 있습니다.')
        }else{
            console.log('name 속성이 없습니다.')
        }

        if(object.author !== undefined){
            console.log('author 속성이 있습니다.')
        }else{
            console.log('author 속성이 없습니다.')
        }

        //[방법 2]
        if(object.name){
           console.log('name 속성이 있습니다.')
        }else{
            console.log('name 속성이 없습니다.')
        }
        if(object.author){
            console.log('author 속성이 있습니다.')
        }else{
            console.log('author 속성이 없습니다.')
        }

        //[방법3]
        object.name||console.log('name 속성이 없습니다.')
        object.author||console.log('author 속성이 없습니다.')
```

2. 기본 속성 지정하기

```
//객체의 기본 속성을 지정합니다.
object.name=object.name !== undefined? object.name: '제목 미정'
object.author=object.author !==undefined? object.author: '저자 미상'

//객체를 출력합니다.
console.log(JSON.stringify(object,null,2))
```

3. 다중 할당

3–1. 배열 기반의 다중 할당

한 번에 여러 개의 변수에 값 할당 가능

```
>let[a,b] = [1,2]
undefined

>console.log(a,b)
1 2
undefined

>[a,b]=[b,a]
(2) [2, 1]

>console.log(a,b)
2 1
undefined

*참고: 다중 할당 시 배열의 크기 같을 필요 없다.

>let arrayA=[1,2,3,4,5]
undefined
>const[c,d,f]=arrayA
undefined
console.log(c,d,f)
1 2 3 --> 앞에 있는 3개의 값만 할당되었다.
undefined
```

3–2. 객체 기반의 다중 할당

```
        //객체 속성 꺼내서 다중 할당하기
        //{속성 이름, 속성 이름} = 객체
        //{식별자=속성이름, 식별자=속성이름} = 객체

        //객체 속성 꺼내서 다중 할당하기

        //객체를 생성합니다.
        const object2={
            name: '혼자공부하는파이썬',
            price: 18000,
            publisher: 'hanbit',
        }

        //객체에서 변수를 추출

        const{name,price}=object2
        console.log('#속성 이름 그대로 꺼내서 출력하기')
        console.log(name, price)
        console.log('')

        const{a=name, b=price} = object2
        console.log('#다른 이름으로 속성 꺼내서 출력하기')
        console.log(a,b)
```

4. 전개 연산자

4–1. 배열 전개 연산자

[1]얕은 복사: 배열과 객체는 할당할 때 *“얕은 복사”*가 이루어진다. 배열 복사해도 다른 이름만 붙고 같은 값이 나온다.

```
        const 물건_200301 = ['우유','식빵']
        const 물건_200302 = 물건_200301
        물건_200302.push('고구마')
        물건_200302.push('토마도')

        console.log(물건_200301)
        console.log(물건_200302)

[결과값]
['우유', '식빵', '고구마', '토마도']
['우유', '식빵', '고구마', '토마도']
```

[2]깊은 복사: 복사한 두 배열이 완전히 독립적으로 작동. 전개 연산자를 사용해 배열 복사

```
        const 물건_220301 = ['우유','식빵']
        const 물건_220302 = [...물건_220301]
        물건_220302.push('고구마')
        물건_220302.push('토마도')

        console.log(물건_220301)
        console.log(물건_220302)

[결과값]
['우유', '식빵']
['우유', '식빵', '고구마', '토마도']

        const 물건_230114 = ['우유','식빵']
        const 물건_230115 = ['고구마', ...물건_230114 ,'토마토']

        console.log(물건_230114)
        console.log(물건_230115)

[결과값]
['우유', '식빵']
['고구마', '우유', '식빵', '토마토']
```

4–2. 객체 전개 연산자

[1] 얕은 복사

```
       const 구름 = {
        이름: '구름',
        나이: 6,
        종족: '강아지'
       };

       const 별 = 구름
       별.이름 = '별',
       별.나이=1

       console.log(JSON.stringify(구름))
       console.log(JSON.stringify(별))

[결과]
{"이름":"별","나이":1,"종족":"강아지"}
{"이름":"별","나이":1,"종족":"강아지"}*
*구름을 별에 복사하고, 별 이름과 나이를 수정하니, 
구름의 이름과 나이까지 함께 수정 되었다.
```

[2]깊은 복사

(1)깊은 복사 기본

```
       const 구름 = {
        이름: '구름',
        나이: 6,
        종족: '강아지'
       };

       const 별 = {...구름} -> 전개 연산자 사용
       별.이름 = '별',
       별.나이=1

       console.log(JSON.stringify(구름))
       console.log(JSON.stringify(별))

[결과]
{"이름":"구름","나이":6,"종족":"강아지"}
{"이름":"별","나이":1,"종족":"강아지"}
```

(2) 변경하고 싶은 속성만 추가

```
       const 구름 = {
        이름: '구름',
        나이: 6,
        종족: '강아지'
       };

       const 별 = {...구름,
       이름: '별',
       나이: 1,
       예방접종: true,
       }

       console.log(JSON.stringify(구름))
       console.log(JSON.stringify(별))

[결과]
{"이름":"구름","나이":6,"종족":"강아지"}
{"이름":"별","나이":1,"종족":"강아지","예방접종":true}
```

(3) 전개 부분 뒤로 이동하기

```
      const 구름 = {
        이름: '구름',
        나이: 6,
        종족: '강아지'
       };

       const 별 = {
       이름: '별',
       나이: 1,
       예방접종: true,
       ...구름* 
       }

       console.log(JSON.stringify(구름))
       console.log(JSON.stringify(별))*

[결과]
{"이름":"구름","나이":6,"종족":"강아지"}
{"이름":"구름","나이":6,"예방접종":true,"종족":"강아지"}

*전개 위치를 뒤로 옮기면, 뒤에 있는 이름과 나이가 앞에 있는 이름과 나이를 덮는다.
```
