### [solution]

1. mode = 0 으로 설정
2. code라는 문자열 내에 “1”을 만날 때마다 mode가 0 or 1로 바뀌도록 설정
3. “1” 이 아닌 문자열을 꺼내는 경우 중
- mode = 0 일 때, 짝수 index는 새로운 문자열에 추가, 홀수 index를 만나는 경우 continue하여 for 문 처음부터 시작하도록 함.
- mode = 1 일 때, 위 경우의 수와 반대로 설정

```
def solution(code):
    mode = 0
    ret = ""
for i in range(len(code)):
        if code[i] == "1":
            if mode == 0:
                mode = 1
            elif mode == 1:
                mode = 0
        elif code[i] != "1":
            if mode == 0:
                if i % 2 == 0:
                    ret += code[i]
                elif i % 2 == 1:
                    continue
            if mode == 1:
                if i % 2 == 1:
                    ret += code[i]
                elif i % 2 == 0:
                    continue
    if ret == "":
        return "EMPTY"
    else:
        return ret

print(solution("abc1abc1abc"))  # "acbac"
```

코드 작성 시간보다, 기준점을 설정하는 데 많은 시간이 걸렸다.

```

    mode = 0
    ret = ""
for i in range(len(code)):
        while mode == 0 
        ... 
            if code[i] == 1:
                mode = 1

```

처음에는 위와 같은 개념으로 접근했으나, mode가 문자열 “1”을 만나 1로 변경되고, 그 이후에 다시 “1”을 만나면 0으로 재변경 되어야 하는데, 동일한 문자를 만날 때 마다 mode가 변경되어야 하기에, 코드로 구현하는데 어려움이 있었다.

코드 구현에 어려움이 있을 때는 시작점으로 돌아가, 기준점과 구현하려는 조건에 대해 다시 한 번 더 확인하는 것도 좋은 방법인 것 같다.
