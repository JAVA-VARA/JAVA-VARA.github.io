### 스택 & 큐/ 이진트리(1)

## 스택

자료를 임시 보관할 수 있는 자료구조(선형). 데이터의 입,출력 순서는 후입 선출(LIFO, Last In First Out)이다.

- `size()`: 현재 스택에 들어 있는 데이터 원소의 수를 구함
- `isEmpty()`: 현재 스택이 비어 있는지를 판단 (`size() == 0?`)
- `isFull()`: 현재 스택이 꽉 차 있는지를 판단
- `push(x)`: 데이터 원소 `x` 를 스택에 추가
- `pop()`: 스택에 가장 나중에 저장된 데이터 원소를 제거 (또한, 반환)
- `peek()`: 스택에 가장 나중에 저장된 데이터 원소를 참조 (반환), 그러나 제거하지는 않음

### [주의]

```
def is_empty(self) ->bool:
  return self.ptr == 0

def full(self) ->bool:
  return self.ptr == self.capacity

프로그램 오류 등으로 ptr(스택포인터) 값이 0보다 작아지거나, 
capacity보다 커질 가능성이 있으므로 추천하지 않는다.
```

## 큐

자료를 임시 보관할 수 있는 자료구조(선형). 데이터의 입,출력 순서는 선입선출(FIFO, First In First Out)이다.

### 우선순위 큐(Priority Queues)

원소들의 우선 순위에 따라 큐에서 빠져나오는 방식

**서로 다른 두 가지 방식이 가능  
1. **Enqueue 할 때 우선 순위 순서 유지  
2. Dequeue할 때 우선 순위 높은 것 선택

**서로 다른 두 가지 재료 이용 가능  
1. **선형 배열(공간적으로 유리)  
2. 연결 리스트(시간적으로 유리)
