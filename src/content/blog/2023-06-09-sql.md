## 스토어드 프로시저

- 형식

```
DELIMITER $$  -- DELIMITER를 $$로 변경
CREATE PROCEDURE 이름
BEGIN
...
SQL 코드
...
END $$ -- 스토어드 프로시저의 끝
DELIMITTER ; -- DELIMITER를 ; 로 다시변경
```

DELIMITTER: 구분자. 기본적으로 “ ; “ 를 구분자로 사용하지만, SQL 문 작성 시에도 많은 ;가 나와 스토어드 프로시저가 끝인지, 코드의 끝인지 구분이 어려움. 구분자를 $$로 변경하여, 프로시저의 끝을 표시함.

- 호출

```
CALL PROCEDURE 의 이름();
```

- 생성

```
DROP PROCEDURE IF EXISTS user_proc;
DELIMITTER $$
CREATE PROCEDURE user_proc()
```

- 삭제

— PROCEDURE()

```
DROP PROCEDURE 의 이름();
```

- **매개변수**

— 입력 매개변수 IN()

[예시 1]

```
USE market_db;
DROP PROCEDURE IF EXISTS user_proc1;

DELIMITER $$
CREATE PROCEDURE user_proc1(IN userName VARCHAR(10)) -- 전달받은 매개변수를 userName 매개변수에 대입
BEGIN
SELECT * FROM member WHERE mem_name = userName; -- 에이핑크가 mem_name인 행에 대한 조회 수행.

END $$
DELIMITER ;

CALL user_proc1('에이핑크'); -- 에이핑크를 "입력 매개변수"로 전달
```

[예시 2]

```
DROP PROCEDURE IF EXISTS user_proc2;

DELIMITER $$
CREATE PROCEDURE user_proc2(
IN userNumber INT,
IN userHeight INT)

BEGIN
SELECT * FROM member
WHERE mem_number > userNumber AND height > userHeight;
END $$
DELIMITER ; 

CALL user_proc2(6,165);
```

— 출력 매개변수 OUT()

```
OUT 매개변수_이름_데이터 형식
```

[예시 1]

```
DROP PROCEDURE IF EXISTS user_proc3;
DELIMITER $$

CREATE PROCEDURE user_proc3(
IN txtValue CHAR(10),
OUT outValue INT ) -- 출력 매개 변수인 outValue 지정

BEGIN
INSERT INTO noTable VALUES(NULL,txtValue); -- outvalue에 id열의 최댓값을 지정
SELECT MAX(id) INTO outValue FROM noTable;

END $$
DELIMITER ;

CALL user_proc3('테스트', @myValue);
SELECT CONCAT('입력된 ID 의 값 >', @myValue);
```

[예시 2]

— noTable 생성

```
CREATE TABLE IF NOT EXISTS noTable(
id INT AUTO_INCREMENT PRIMARY KEY,
txt CHAR(10)
);
```

— no Table에 데이터 INSERT 및 SELECT

```
DROP PROCEDURE IF EXISTS user_proc3;
DELIMITER $$

CREATE PROCEDURE user_proc3(
IN txtValue CHAR(10),
OUT outValue INT ) -- 출력 매개 변수인 outValue 지정

BEGIN
INSERT INTO noTable VALUES(NULL,txtValue); -- noTable에 입력된 값 INSERT
SELECT MAX(id) INTO outValue FROM noTable; -- outvalue에 id열의 최댓값을 지정

END $$
DELIMITER ;

CALL user_proc3('테스트', @myValue);
SELECT CONCAT('입력된 ID 의 값 >', @myValue);
```

### IF ~ ELSE 문

```
DROP PROCEDURE IF EXISTS ifelse_proc;

DELIMITER $$
CREATE PROCEDURE ifelse_proc(
IN memName VARCHAR(10) -- 매개 변수로 가수 그룹의 이름을 넘겨받는다.
)
BEGIN
DECLARE debutYear INT; -- 변수 선언, 데뷔 연도를 저장한다.
SELECT YEAR(debut_date) INTO debutYear FROM member -- 데뷔일자 중에서 year()함수로 연도만 추출 -> debutYear 변수에 저장.
WHERE mem_name = memName; -- 넘겨받은 가수 이름 조회

IF(debutYear >= 2015) THEN -- IF ELSE 구문으로 보낼 메시지 결정
SELECT '신인가수네요 화이팅 하세요' AS '메시지' ;
ELSE 
SELECT '고참가수네요 그동안 수고하셨습니다.' AS '메시지';

END IF;
END $$
DELIMITER ;

CALL ifelse_proc('오마이걸'); -- 오마이걸로 스토더드 프로시저 테스트.
```

### 동적 SQL 활용

```
DROP PROCEDURE IF EXISTS dynamic_proc()

DELIMITER $$
CREATE PROCEDURE dynamic_proc(
IN tableName VARCHAR(20)
)

BEGIN
 SET @sqlQuery = CONCAT('SELECT * FROM' , tableName);
 PREPARE myQuery FROM @sqlQuery;
 EXECUTE myQuery;
 DEALLOCATE PREPARE myQuery;
END $$
DELIMITER ;

CALL dynamic_proc('member');
```
