## Java LV02. Stack and Queue.

문제를 푸는 중에 아래와 같은 error 메세지를 만났다.

## - Error Message

![](/images/medium/67a5aa89fe4/1.png)

```
The type java.util.Vector cannot be resolved. 
It is indirectly referenced from required type java.util.StackJava(16777563)
```

=> `java.util.Stack` 클래스가 `java.util.Vector` 클래스에 의존하고 있는데, 컴파일러가 `java.util.Vector` 클래스를 찾을 수 없어 에러 발생.

`java.util.Vector` 클래스가 프로젝트의 클래스패스에 존재하지 않거나, 잘못된 버전의 Java를 사용하고 있는 경우에 발생할 수 있음을 서치를 통해 알게 되었다.

현재 java가 최신 version이 설치되어 있기 때문에 class path가 잘못되어 불러오지 못하는 것으로 생각되어, 아래와 같이 디렉토리를 설정했다.

![](/images/medium/67a5aa89fe4/2.png)

```
PS C:\workspace\vscode\Programmers> & 
'C:\Program Files\Java\jdk-20.0.1\bin\java.exe' 
' - enable-preview' '-XX:+ShowCodeDetailsInExceptionMessages' 
'-cp' 
'C:\workspace\vscode\Programmers\bin' 'App'
```

JDK가 새로 만든 workspace 디렉토리에 설치되었고, 해당 디렉토리에서 java code가 error 없이 잘 실행되었다.

별도의 개발환경을 설하지 않고, 바탕화면에 폴더를 만들어 코드를 실행했을 때 필요한 클래스를 불러올 때 오류가 발생할 수 있음을 알게되었다.
