## 혼자 공부하는 자바스크립트

DAY3

03–2. switch 조건문과 짧은 조건문

1. swich 조건문

```
switch(자료*){
  case 조건 A:xx ; break ;
  case 조건 B:xx ; break ;
  default: xx ; 
}

(자료*)에 비교할 값을 입력.
중괄호 필요 없음.
break 는 조건문, 반복문을 빠져나오기 위해 사용하는 키워드
```

2. 조건부 연산자

> *불 표현식* **?** *참일 때의 결과 :* ***거짓일 때의 결과*

3. 짧은 조건문

논리합 연산자 좌변이 참일 때 추가 연산을 진행하지 않는다.

- true || alert(‘참’) → true
- false || alert(‘참’) → ‘참’(우변 실행)

논리곱 연산자 좌변이 거짓일 때 추가 연산을 진행하지 않는다.

- fasle && ○○○ → 항상 거짓, 우변 실행하지 않음.
4. 주요 작성 코드

연습 문제로 아래의 코드를 작성했다. 연습 문제의 정답은 1991년을 입력했을 때 **“신미년”**이 출력되어야 한다. 그러나 코드 작성 후 1991을 입력했을 때 계속 **“신해년” **출력 되었다. 오류가 있는 구문이 있는지 찾아봤지만, 찾을 수 없었다. 한참을 헤맨 후에 띠의 순서를 case 0부터 평소 익숙하게 외워왔던 순서인 “자축인묘진사오미신유술해”로 작성했기 때문에 출력값이 정답과 일치하지 않음을 확인했다.

이번 실수는 60갑자에 대한 무지함 때문에 발생한 것인데, 구현해내고자 하는 것에 대한 배경 지식이 부족하면, 코딩 실력과 상관 없이 문제가 발생할 수 있음을 되새기게 되었다.

```
<script>
         const rawInput=prompt('태어난해를입력해주세요','')
         const year=Number(rawInput)

         let e=year%10
         let tti=year%12

         let 간
         switch(e){
            case 0: 간='경';break;
            case 1: 간='신';break;
            case 2: 간='임';break;
            case 3: 간='계';break;
            case 4: 간='갑';break;
            case 5: 간='을';break;
            case 6: 간='병';break;
            case 7: 간='정';break;
            case 8: 간='무';break;
            case 9: 간='기';break;
         }

         let 띠
         switch(tti){
            case 0: 띠='신';break;
            case 1: 띠='유';break;
            case 2: 띠='술';break;
            case 3: 띠='해';break;
            case 4: 띠='자';break;
            case 5: 띠='축';break;
            case 6: 띠='인';break;
            case 7: 띠='묘';break;
            case 8: 띠='진';break;
            case 9: 띠='사';break;
            case 10: 띠='오';break;
            case 11: 띠='미';break;
         }
            
        alert(`입력하신 년도 ${year}은 ${간}${띠}년입니다.`)

</script>
```

아래의 코드는 위에 예시 문제로 풀었던 것과 같은 문제를 오늘 배운 것을 토대로 간단하게 구현해보았다. 코드를 효율적으로, 깔끔해 보이도록 만들었을 때 쾌감이 느껴진다. 음하하하

```
<script>
    
         const rawInput=prompt('태어난해를입력해주세요','')
         const year=Number(rawInput)

         const 간='경,신,입,계,갑,을,병,정,무,기'.split(',')
         const 띠='신/유/술/해/자/축/인/묘/진/시/오/미'.split('/')

         alert(`${year}은 ${간[year%10]}${띠[year%12]}년 입니다.`)

</script>
```
