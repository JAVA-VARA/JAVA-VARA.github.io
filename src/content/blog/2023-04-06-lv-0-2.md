## [Q] 가장 큰 수 찾기

정수 배열 `array`가 매개변수로 주어질 때, 가장 큰 수와 그 수의 인덱스를 담은 배열을 return 하도록 solution 함수를 완성해보세요.

**sol1)**

max() 함수를 이용하여, 배열 내 가장 큰 수를 찾은 후 해당 값을 index() 함수로 index를 반환하였다.

```
def solution(array):
    return [max(array), array.index(max(array))]

print(solution([1, 8, 3])) #[8,1]
print(solution([9, 10, 11, 8])) #[11, 2]
```

**sol2)**

for 문을 이용하여 배열 내 임의의 값 i를 반복적으로 비교하여, 최종적으로 가장 큰 i 값이 반환되도록 코드를 작성해보았다.

```
def solution2(array):
    max = 0
    index = 0

    for i in array:
        if i > max:
            max = i
            index = array.index(i)
    
    return [max, index]

print(solution2([1, 8, 3])) #[8,1]
print(solution2([9, 10, 11, 8])) #[11, 2]
```

## [Q] 편지

머쓱이는 할머니께 생신 축하 편지를 쓰려고 합니다. 할머니가 보시기 편하도록 글자 한 자 한 자를 가로 2cm 크기로 적으려고 하며, 편지를 가로로만 적을 때, 축하 문구 `message`를 적기 위해 필요한 편지지의 최소 가로 길이를 return 하도록 solution 함수를 완성해주세요.

문제를 읽고 아래와 같은 방식으로 접근했다.

1. string 을 list로 만든다.
2. list 길이를 len() 으로 구한 뒤 2를 곱해준다.

```
def solution(message):
    answer = len(list(message))*2

    return answer

print(solution("happy birthday!")) #30
print(solution("I love you~")) #22
```

len() 함수로 리스트나 튜플의 길이만 확인 가능한 줄 알았으나, 위와 같이 코드를 작성 후 len() 함수에 대해 다시 확인해보니 아래와 같은 정의와 특성을 가지고 있음을 재확인할 수 있었다.

> len(): ***문자열의 길이 반환***, *리스트나, 튜플 등에서는 그 안에 속한 값의 개수 반환 *정수나 실수 등은 문자열이 아니므로 에러가 발생하므로 문자열로 변환 후 적용한다.

print(len(message)) 을 통해 message 매개 변수의 문자열 길이 반환하는 것을 확인 후 아래와 같이 코드를 간결하게 수정하였다.

```
def solution(message):
    return len(message)*2

print(solution("happy birthday!")) #30
print(solution("I love you~")) #22
```

## [Q] 한 번만 등장한 문자

문자열 `s`가 매개변수로 주어집니다. `s`에서 한 번만 등장하는 문자를 사전 순으로 정렬한 문자열을 return 하도록 solution 함수를 완성해보세요. 한 번만 등장하는 문자가 없을 경우 빈 문자열을 return 합니다.

sol1)

1. 한번만 등장한 문자 반환
- 문자열을 리스트로 변환
- for()문과 count()함수를 이용해 한 번만 등장한 문자 확인 후 리스트에 추가
2. 사전 순으로 정렬

```
def solution(s):
    answer = ''
    s_list = list(s)
    for i in s_list:
        if s_list.count(i) == 1:
            answer += i
    
    return "".join(sorted(answer))

print(solution("abcabcadc")) #d
print(solution("abdc")) #abcd
print(solution("hello")) #eho
print(solution("ll")) #''
```

sol2) 편지 문제와 마찬가지로 count() 함수를 문자열에 적용 가능함을확인하여 문자열을 list로 변환하는 과정을 생략 후 코드를 작성하였다.

```
def solution(s):
    answer = ''
    for i in s:
        if s.count(i) == 1:
            answer += i

    return "".join(sorted(answer))
```

sol3) 정답 제출 이 후 더 간결하게 작성된 코드를 확인하여, 가져왔다.

```
def solution(s):
    answer = "".join(sorted(i for i in s if s.count(i) == 1))

    return answer
```

## [Q] 숫자 찾기

정수 `num`과 `k`가 매개변수로 주어질 때, `num`을 이루는 숫자 중에 `k`가 있으면 `num`의 그 숫자가 있는 자리 수를 return하고 없으면 -1을 return 하도록 solution 함수를 완성해보세요.

제한사항

- 0 < `num` < 1,000,000
- 0 ≤ `k` < 10
- `**num**`**에 **`**k**`**가 여러 개 있으면 가장 처음 나타나는 자리를 return 합니다.**
1. 숫자를 문자열로 변환
2. 문자열 내 수와 k값이 일치 여부 확인
3. 일치한다면 인덱스는 0부터 시작하므로 +1을 하여 자리 수를 반환한다.
4. 일치하는 수가 없다면 -1을 반환한다.

```
def solution(num, k):
    newnum = str(num)

    for i in newnum:
        if int(i) == k:
            answer = newnum.find(i) + 1

        else:
            answer = -1

    return answer

print(solution(29183, 1)) #-1
print(solution(232443, 4)) #-1
print(solution(123456, 7)) #-1

#확인을 위해 추가!!!
print(solution(123456, 6)) #?
```

위와 같이 코드를 작성하니 모든 값이 -1로 반환되었다. 일치하는 값을 찾은 이후에도 for()문이 계속 돌아가고 있음을 깨달았고, 숫자의 끝자리와 k값을 동일하게 지정해보니 일치하는 수의 자리를 나타냄을 확인했다.

```
print(solution(123456, 6)) #6
```

제한 사항 중 "`**num**`**에 **`**k**`**가 여러 개 있으면 가장 처음 나타나는 자리를 return 합니다. ” **이라는 문구가 있어, 일치하는 i값을 찾으면, 반복을 중단하는 break 문을 추가하여 문제를 해결하였다.

```
def solution(num, k):
    newnum = str(num)

    for i in newnum:
        if int(i) == k:
            answer = newnum.find(i) + 1
            break

        else:
            answer = -1

    return answer

print(solution(29183, 1)) #3
print(solution(232443, 4)) #4
print(solution(123456, 7)) #-1
```
