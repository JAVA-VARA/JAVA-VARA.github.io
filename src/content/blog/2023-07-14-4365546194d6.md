## [Sol1]

```
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.PriorityQueue;

public class HallOfFame {
    public int[] solution(int k, int[] score) {

        List<Integer> minScore = new ArrayList<>();
        PriorityQueue<Integer> pQueueLowest = new PriorityQueue<>();


        //명예의 전당 등록 가능 수 보다 지원자가 많은 경우.
        if(score.length > k){
            //k번째 까지 명예의 전당 리스트&최소값 반환
            for(int i =0; i < k ; i ++){
                pQueueLowest.add(score[i]);
                minScore.add(pQueueLowest.peek());
            }

            //k번째 이 후 명예의 전당 리스트&최소값 반환
            for(int i = k; i < score.length; i++){
                if(pQueueLowest.peek() < score[i]){
                    pQueueLowest.poll();
                    pQueueLowest.add(score[i]);
                    minScore.add(pQueueLowest.peek());
                }else{
                    minScore.add(pQueueLowest.peek());
                }
            }
    
        //명예의 전당 등록 가능 수 보다 지원자가 적은 경우.
        }else{
            for(int i =0; i < score.length ; i ++){
                pQueueLowest.add(score[i]);
                minScore.add(pQueueLowest.peek());
            }

        }

        int[] answer = minScore.stream()
                .mapToInt(Integer::intValue)
                .toArray();

        return answer;
    }
    //Test
    public static void main(String[] args) {
        HallOfFame hof = new HallOfFame();
        System.out.println(Arrays.toString(hof.solution(3, new int[]{10, 100, 20, 150, 1, 100, 200})));
        System.out.println(Arrays.toString(hof.solution(4, new int[]{0, 300, 40, 300, 20, 70, 150, 50, 500, 1000})));
        System.out.println(Arrays.toString(hof.solution(3, new int[]{10, 20, 30, 40, 50, 60, 70, 80})));
        System.out.println(Arrays.toString(hof.solution(9, new int[]{1, 2, 3, 4, 5, 6, 7, 8})));
        System.out.println(Arrays.toString(hof.solution(9, new int[]{9, 8, 7, 6, 5, 4, 3})));
    }

}

import java.util.Arrays;
import java.util.PriorityQueue;

public class HonorOfFame {
    public int[] solution(int k, int[] score) {

        PriorityQueue<Integer> pQueueLowest = new PriorityQueue<>();

        int[] answer = new int[score.length];
        for (int i = 0; i < score.length; i++) {
            pQueueLowest.add(score[i]);
            
            //반복문을 돌며, pQueueLowest에 add된 점수가
            //k값보다 큰 경우에 가장 작은 값을 제거.
            
            //pQueueLowest 크기에 제한을 두어, 
            //sol1에서 작성한 if문 코드를 효율적으로 변경할 수 있었다.
            if(pQueueLowest.size() > k){
                pQueueLowest.poll();
            }
            
            //PriorityQueue에서 peek()한 값을 바로 int[] answer에 추가하여,
            //list에서 변환하는 과정을 없앨 수 있었다.
            answer[i] = pQueueLowest.peek();
        }
        return answer;
    }
}
```

### 우선 순위 큐란?

우선순위 큐는 각 요소들이 각각의 우선 순위를 갖고있고, 요소들의 대기열에서** ‘우선 순위가 높은 요소’가 ‘우선 순위가 낮은 요소’보다 먼저 제공되는 자료구조.**

모든 요소들을 고려하여 우선순위를 정할 필요 없이 **부모 노드는 자식노드보다 항상 우선순위가 앞선다는 조건만 만족시키며 완전이진트리 형태로 채워나간다.**

![](/images/medium/4365546194d6/1.png)

**“루트 노드(root node)는 항상 우선순위가 높은 노드” 이다**. 이러한 원리로 최댓값 혹은 최솟값을 빠르게 찾아낼 수 있다는 장점(시간복잡도 : O(1))과 함께 삽입 삭제 연산 시에도 부모노드가 자식노드보다 우선순위만 높으면 되므로 결국 트리의 깊이 만큼만 비교를 하면 되기 때문에 O(logN) 의 시간복잡도를 갖아 매우 빠르게 수행할 수 있다.
