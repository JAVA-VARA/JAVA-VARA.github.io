### **대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기**

[**코딩테스트 연습 - 대여 횟수가 많은 자동차들의 월별 대여 횟수 구하기**  
*문제 설명 다음은 어느 자동차 대여 회사의 자동차 대여 기록 정보를 담은 CAR_RENTAL_COMPANY_RENTAL_HISTORY 테이블입니다. CAR_RENTAL_COMPANY_RENTAL_HISTORY…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/151139)[](https://school.programmers.co.kr/learn/courses/30/lessons/151139)

### #1 오답…

```
SELECT MONTH(START_DATE) AS MONTH, CAR_ID, COUNT(CAR_ID) AS RECORDS
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
GROUP BY CAR_ID, MONTH(START_DATE)
HAVING COUNT(CAR_ID) >= 5
ORDER BY MONTH, CAR_ID DESC
```

### 문제점

1)“2022년 8월부터 10월까지 총 대여 횟수가 5회 이상인 자동차”에 대한 조건을 먼저 구해야함.  
2) `GROUP BY` 절에 의해 이미 `MONTH(START_DATE)`와 `CAR_ID`로 그룹화가 된 상태에서 `HAVING COUNT(CAR_ID) >= 5` 적용  
3)각 월별로 특정 자동차의 대여 횟수가 5회 이상인 경우만 결과에 포함된다.  
4)**문제에서 요구한 것은 월별이 아닌 전체 기간(2022년 8월 ~ 10월)의 총 대여 횟수가 5회 이상인 자동차**에 대한 것

### #2

1. 2022년 8월부터 10월까지의 전체 기간 동안 대여 횟수가 5회 이상인 자동차를 구한다.(BY. 서브 쿼리)
2. 해당 자동차들에 대해 **월별로 대여 횟수를 집계**

```
SELECT MONTH(START_DATE) AS MONTH, CAR_ID, COUNT(*) AS RECORDS
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE 
    START_DATE BETWEEN '2022-08-01' AND '2022-10-31' AND 
    CAR_ID IN (
      SELECT CAR_ID
      FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
      WHERE START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
      GROUP BY CAR_ID
      HAVING COUNT(*) >= 5)
    
GROUP BY MONTH(START_DATE), CAR_ID
HAVING COUNT(*) > 0
ORDER BY MONTH(START_DATE), CAR_ID DESC
```

### #3WITH절

긴 구절의 서브쿼리를 사용하다보니 가독성이 떨어져 CHAT GPT에게 도움을 요청했더니 WITH 절을 사용한 코드를 알려주었다.

**‘WITH’절**: 서브쿼리를 만들고 재사용 가능한 공통 테이블 표현식(Common Table Expression, CTE)을 정의하는 방법. 하나 이상의 서브쿼리에서 반환된 데이터를 단일 쿼리에서 재사용할 수 있다. 코드 중복을 줄이고 쿼리의 가독성 향상 가능!!!

```
WITH CAR_TATAL_RENTALS AS (
    SELECT CAR_ID, COUNT(*) AS TOTAL_RENTALS
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
    GROUP BY CAR_ID
    HAVING COUNT(*) >= 5
)

SELECT MONTH(START_DATE), CAR_ID, COUNT(*) AS RECORDS
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE START_DATE BETWEEN '2022-08-01' AND '2022-10-31'
    AND CAR_ID IN (SELECT CAR_ID FROM CAR_TATAL_RENTALS)
    GROUP BY MONTH(START_DATE), CAR_ID
    HAVING COUNT(*) > 0
    ORDER BY MONTH(START_DATE), CAR_ID DESC
```

CAR_TATAL_RENTALS 이라는 가상테이블을 재사용할 수 있다.
