## 05–1 재귀 알고리즘의 기본

### 재귀 호출

- 팩토리얼 함수

```
def factorial(n: int) -> int:
    """양의 정수 n의 팩토리얼을 구하는 과정"""
    if n > 0:
        return n * factorial(n - 1)
 
    else:
        return 1

if __name__ == '__main__':
    n = int(input('출력할 팩토리얼 값을 입력하세요.: '))
    print(f'{n}의 팩토리얼은 {factorial(n)}입니다.')
```

재귀 함수 알고리즘 구현되는 상세한 과정은 아래와 같다.

```
def factorial(n: int) -> int:
    if n > 0:
        return n * factorial(n - 1)
    else:
        return 1

'''

factorial(3)을 구한다고 가정.

1. factorial(3) 실행 -> factorial() 함수 호출 => 3*factorial(2) 호출.
2. 위 값을 구하려면 factorial(2) 값을 알아야함.
3. factorial(2) 실행 -> factorial() 함수 호출 => 2*factorial(1) 호출
4. 위 값을 구하려면 factorial(1) 값을 알아야함.
5. factorial(1) 실행 -> factorial() 함수 호출 => 1*factorial(0) 호출
6. factorial(0) -> n<0 이므로, 1을 "반환"

7. factorial() 함수는 반환된 값을 받아 1*factorial(0) 실행 => 1*1 반환.
8. factorial() 함수는 반환된 값을 받아 2*factorial(1) 실행 => 2*1 반환.
9. factorial() 함수는 반환된 값을 받아 3*factorial(2) 실행 => 3*2 반환.

=>최종적으로 6!의 값을 얻을 수 있다.

'''
```

=> factorial() 함수는 n-1의 팩토리얼값을 구하기 위해 “자기 자신과 똑같은” factorial() 함수를 호출한다. 이를 재귀 호출(recursive call)이라고 한다.

**#직접 재귀  
**factorial() 함수는 내부에서 자신과 똑같은 factorial() 함수를 호출. 자신과 똑같은 함수를 호출하는 방식을 집접재귀라고 한다.

**#간접 재귀  
**a()함수가 b()함수를호출하고, 다시 b()함수가 a()함수를 호출하는 구조

### 유클리드 호제법

두 정수값의 최대 공약수(GCD, greatest common divisor)를 재귀적으로 구하는 방법 알아보자.

- y가 0이면 x값 반환
- y가 0이 아니면 gcd(y, x%y) 반환.

```
def gcd(x: int, y: int) -> int:
    """정숫값 x와 y의 최대 공약수를 반환"""
    if y == 0:
        return x
    else:
        return gcd(y, x % y)

if __name__ == '__main__':
    print('두 정숫값의 최대 공약수를 구합니다.')
    x = int(input('첫 번째 정숫값을 입력하세요.: '))
    y = int(input('두 번째 정숫값을 입력하세요.: '))

    print(f'두 정숫값의 최대 공약수는 {gcd(x, y)}입니다.')
```

[result] x=8, y=22 입력 => gcd(8,22)

1. y != 0 이므로 => gcd(22, 8) 호출
2. y != 0 이므로 => gcd(8, 6) 호출
3. y != 0 이므로 => gcd(6, 2) 호출
4. y != 0 이므로 => gcd(2, 0) 호출
5. y==0 이므로 2 반환 => gcd(8,22) = 2

2. 재귀 제거
- 현재의 n 값을 임시로 저장 -> recur(n-1) 처리 완료 후 임시로 저장했던 n값을 꺼내 출력

```

from stack import Stack  # stack.py의 Stack 클래스를 임포트

def recur(n: int) -> int:
    """재귀를 제거한 함수 recur"""
    s = Stack(n)

    while True:
        if n > 0:
            s.push(n)         # n 값을 푸시
            n = n - 1
            continue
        if not s.is_empty():  # 스택이 비어 있지 않으면
            n = s.pop()       # 저장하고 있는 값을 n에 팝
            print(n)
            n = n - 2
            continue
        break

x = int(input('정수값을 입력하세요.: '))

recur(x)
```

## 6. Complexity of Algorithms

### 공간 복잡도(Space Complexity)

문제의 크기와 이를 해결하는 데 필요한 메모리 공간 사이의 관계

### 시간 복잡도(Time Complexity)

문제의 크기와 이를 해결하는 데 걸리는 시간 사이의 관계

- **평균 시간 복잡도(Average Time Complexity)**  
임의의 입력 패턴을 가정했을 때 소요되는 시간의 평균

- **최악 시간 복잡도(Worst-case Time Complexity)**  
가장 긴 시간을 소요하게 만드는 입력에 따라 소요되는 시간

- Big-O Notation  
점근 표기법, 알고리즘의 복잡도를 표현할 때 쓰임  
어떤 함수의 증가 양상을 다른 함수와의 비교로 표현  
(ex)O(1), O(n), O(logn)

### - 선형 시간 알고리즘 — O(n)

ex) 선형 탐색으로 리스트 내 최댓값 찾기  
- Average case: O(n)  
- Worst-case: O(n)

### - 로그 시간 알고리즘 — O(log n)

ex) n개의 크기 순으로 정렬된 수 에서 특정 값을 찾기 위해 이진 알고리즘 적용  
- Average case: O(log n)  
- Worst-case: O(n)

### - 이차 시간 알고리즘 — O(n²)

ex1) 삽입 정렬(insertion sort)  
- Best case: O(n)  
- Worst-case: O(n²)

### - 병합 정렬(merge sort) 알고리즘 — O(n*log n)

정렬 문제에 대해 가장 낮은 복잡도를 가지고 있는 알고리즘

1. 정렬할 데이터를 반씩 나누어 각각 정렬시킨다. => O(log n)
2. 정렬된 데이터를 두 묶음씩 한 곳에 합친다. => O(n)

예제)N 행 N 열의 정사각행렬 A 와 B 가 주어진다고 할 때, 이 두 행렬의 곱 (product) 인 N X N 행렬 C 를 계산하기 위하여 다음과 같은 방법을 쓸 수 있습니다.

```
for i in range(N):
    for j in range(N):
        C[i][j] = 0
        for k in range(N):
            C[i][j] += A[i][k] * B[k][j]


=> O(n³) 의 복잡도를 가진다.
(A,B,C 각각 O(n)의 복잡도를 가지며, 경우의 수를 곱하면 O(n³))
```
