### Solution_1

```
package Programmers_Solution;
import java.util.*;

public class DartGame{
    public int solution(String dartResult) {
        int answer = 0;
        Queue<String> resultQueue = new LinkedList<>(Arrays.asList(dartResult.split("")));
        int[] scores = new int[3]; 
        int idx = 0; 

        while (!resultQueue.isEmpty()) {
            String dot = resultQueue.poll();

            if (dot.matches("^[0-9]*$")) {
                scores[idx] = Integer.parseInt(dot);
                if(!resultQueue.isEmpty() && resultQueue.peek().equals("0")){
                    scores[idx] = 10;
                    resultQueue.poll();
                }
                idx += 1;

            } else if ("SDT".contains(dot)) {
                if(dot.equals("D")){
                    scores[idx-1] *= scores[idx-1];
                } else if (dot.equals("T")) {
                    scores[idx-1] = scores[idx-1]*scores[idx-1]*scores[idx-1];
                }
            } else if ("#*".contains(dot)) {
                if(dot.equals("#")){
                    scores[idx-1] = -scores[idx-1];
                }else if(dot.equals("*")) {
                    if(idx > 1){
                        scores[idx-2] = (scores[idx-2])*2;
                    }
                    scores[idx-1] = (scores[idx-1])*2;

                }
            }
        }
        for(int i : scores){answer += i;}
        return answer;
    }
    //test
    public static void main(String[] args) {
        DartGame DartGame = new DartGame();
        System.out.println(DartGame.solution("1S2D*3T"));
        System.out.println(DartGame.solution("1D2S#10S"));
        System.out.println(DartGame.solution("1D2S0T"));
        System.out.println(DartGame.solution("1S*2T*3S"));
        System.out.println(DartGame.solution("1D#2S*3S"));
        System.out.println(DartGame.solution("1T2D3D#"));
        System.out.println(DartGame.solution("1D2S3T*"));
    }
}

### Solution_2

**#1. 변수 이름 수정:** 변수 이름을 *dot*”에서 *currentChar*로 변경. 내가 작성한 변수가 무엇을 의미하는지 변수명 내에 명시하였다.

#2. if-else 문 → swith문 변경: 코드의 depth를 줄이고, 코드를 정돈하여 읽기 쉽도록 변경하였다.

#3. Math class import:

```
[before]
scores[idx-1] = scores[idx-1]*scores[idx-1]*scores[idx-1];

[After]
scores[idx - 1] = (int) Math.pow(scores[idx - 1], 2);
```

**#4. 반복문 → stream API 활용.**

stream은 배열을 스트림으로 변환하고, `sum()` 메서드는 스트림의 모든 요소를 합계하는 연산을 수행한다. 내부적으로 병렬 처리를 사용하여 성능을 최적화할 수 있고 배열의 크기가 크거나 연산이 무거운 경우에 더 효과적일 수 있다고 한다.

```
[before]
for(int i : scores){answer += i;}

[After]
answer = Arrays.stream(scores).sum();
```

```
import java.util.*;

public class DartGame{
    public int solution(String dartResult) {
        int answer;
        Queue<String> resultQueue = new LinkedList<>(Arrays.asList(dartResult.split("")));
        int[] scores = new int[3];
        int idx = 0; 

        while (!resultQueue.isEmpty()) {
            //#1 변수 이름 수정:
            String currentChar = resultQueue.poll();

            if (currentChar.matches("^[0-9]*$")) {
                scores[idx] = Integer.parseInt(currentChar);

                if(!resultQueue.isEmpty() && resultQueue.peek().equals("0")){
                    scores[idx] = 10;
                    resultQueue.poll();
                }
                idx += 1;
                
            //#2. if-else 문 → swith문 변경:
            } else if ("SDT".contains(currentChar)) {
                switch (currentChar) {
                    //#3 Math class import
                    case "S" -> scores[idx - 1] = (int) Math.pow(scores[idx - 1], 1);
                    case "D" -> scores[idx - 1] = (int) Math.pow(scores[idx - 1], 2);
                    case "T" -> scores[idx - 1] = (int) Math.pow(scores[idx - 1], 3);
                }

            } else if ("#*".contains(currentChar)) {
                switch (currentChar) {
                    case "#" -> scores[idx - 1] = -scores[idx - 1];
                    case "*" -> {
                        if (idx > 1) {scores[idx - 2] = (scores[idx - 2]) * 2;}
                        scores[idx - 1] = (scores[idx - 1]) * 2;
                    }
                }
            }
        }
        //#4. 반복문 수정
        answer = Arrays.stream(scores).sum();
        return answer;
    }
}
