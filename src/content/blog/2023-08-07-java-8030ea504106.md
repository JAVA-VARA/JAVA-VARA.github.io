이유를 찾아보니 Java에서는 아래와 같이 Char 형과 String형을 구분하여 따옴표를 사용한다고 한다.

## “String” vs ‘Char’

### String

- 타입: reference type
- 메모리 저장 방식: 메모리의 힙(heap) 영역에 저장.
- 리터럴 표기: 큰따옴표(`"`)로 묶어서 표기
- 크기: 길이가 가변적이며, 필요에 따라 많은 문자를 포함
- 불변성: 불변(immutable)하며, 한 번 생성된 후에는 변경할 수 없다.

### char

- 타입: primitive type
- 메모리 저장 방식:메모리의 스택(stack) 영역에 저장되며, 각 문자는 아스키 코드* 규칙에 따라 **정수로 치환**되어 저장된다.(단 하나의 문자만 저장 가능)
- 리터럴 표기: 작은따옴표(`'`)로 묶어서 표기
- 크기: 2byte
- 불변성: 변경 가능.

(1)미국 표준 부호 체계. 영문자, 숫자, 특수 문자에 고유의 숫자를 부여한 것
