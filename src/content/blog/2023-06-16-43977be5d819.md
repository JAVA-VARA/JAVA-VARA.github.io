```

```

answer = 0 값이 나오는 것은 위 구문에서 seoul[i]에 “Kim”과 일치하는 값이 없음을 의미하는 것으로 판단하여, 관련 사항에 대해 알아보았다.

String 연산자를 비교하는 경우 equals() 메소드를 사용 해야 하는 것을 알게되어 아래와 같이 코드 수정 후 문제를 해결할 수 있었다.

```
public class Findkim {
    public String solution(String[] seoul) {
        int answer = 0;
        for (int i = 0; i < seoul.length; i++) {
            if (seoul[i].equals("Kim")) { //<--- ==을 equals()로 수정한 코드
                answer = i;
                break;
            }
        }
        return "김서방은 " + answer + "에 있다.";
    }
```

## Java에서 연산자 == 와 equals() 메소드의 차이

### == 연산자

비교하고자 하는 두개의 대상의** 주소값을 비교**한다. 보통 **Primitive type(ex.** INT, CHAR**)** 비교에 사용된다. primitive type은 Constant pool에 있는 특정 상수를 참조한다. 같은 상수를 참조하면 주소값이 같기 때문에 동일하다고 판단할 수 있기 때문이다.

## equals()

**Reference type(ex. String, Array)**의 경우, 변수에 클래스를 선언하여 메모리에 올리게 되는데, 메모리에 올라간 클래스(인스턴스)를 변수가 가리키게 된다. 변수에는 인스턴스의 값 자체가 아닌, 메모리의 주소 값이 저장되는데 이 주소 값은 클래스만의 고유한 값이므로, 같은 값으로 클래스를 만들게 되어도, 서로 다른 인스턴스를 참조하게 된다.

따라서, Reference type의 값이 같은지 비교하기 위해서는 주소 값이 아닌 값 자체를 비교해주는 equals() 메소드를 사용해주어야 한다.

어떻게 String을 생성하느냐**에 따라 결과가 달라지지 않고 정확한 비교를 할 수 있다.

String 변수 생성 시 주소 할당**

변수 생성할 때 두 가지 방법이 있다.

1. 리터럴(literal)을 이용한 방식

=> string constant pool 영역에 존재 → “==” 연산자로 비교 가능.

2. new 연산자를 이용한 방식

=> Heap의 영역에 존재 → equals() 메소드 사용.

```
public class Solution {
    public String solution(String s, int n) {
        String answer = "";
        String strB = "ABCDEFGHIJKLMNOPQRSTUVWXYZABCDEFGHIJKLMNOPQRSTUVWXYZ";
        String strS = "abcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyz";

        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) != ' ') {

                for (int j = 0; j < strB.length() / 2; j++) {
                    if (s.charAt(i) == strB.charAt(j)) {
                        answer = answer + strB.charAt(j + n);

                    } else if (s.charAt(i) == strS.charAt(j)) {
                        answer = answer + strS.charAt(j + n);
                    }
                }

            } else {
                answer = answer + " ";
            }

        }

        return answer;
    }

    public static void main(String[] args) {
        Solution dc = new Solution();
        System.out.println(dc.solution("B", 1));
        System.out.println(dc.solution("Y", 3));
        System.out.println(dc.solution("Z", 2));

    }
}
```

```
public class Solution {
    public String solution(String s, int n) {
        String answer = "";
        String strB = "ABCDEFGHIJKLMNOPQRSTUVWXYZABCDEFGHIJKLMNOPQRSTUVWXYZ";
        String strS = "abcdefghijklmnopqrstuvwxyzabcdefghijklmnopqrstuvwxyz";

        for (int i = 0; i < s.length(); i++) {
            if(s.charAt(i) == ' ') {
                answer += " ";
                continue;
            }

            for (int j = 0; j < strB.length() / 2; j++) {
                boolean isUpperMatch = s.charAt(i) == strB.charAt(j);
                boolean isLowerMatch = s.charAt(i) == strS.charAt(j);
                                
                if (isUpperMatch) { answer += strB.charAt(j + n);}
                if (isLowerMatch) { answer += strS.charAt(j + n);}                
            }
        }
        return answer;
    }
}
```

```
public class FoodFight {
    public String solution(int[] food) {
        String answer1 = "";
        String answer2 = "0";

        for (int i = 1; i < food.length; i++) {
            answer1 += String.valueOf(i).repeat(food[i] / 2);
            answer2 += String.valueOf(food.length - i).repeat(food[food.length - i] / 2);
        }

        return answer1 + answer2;
    }

    public static void main(String[] args) {
        FoodFight ff = new FoodFight();
        System.out.println(ff.solution(new int[] { 1, 3, 4, 6 }));
        System.out.println(ff.solution(new int[] { 1, 7, 1, 2 }));
    }

}
```
