[**코딩테스트 연습 - 자동차 대여 기록에서 대여중 / 대여 가능 여부 구분하기**  
*다음은 어느 자동차 대여 회사의 자동차 대여 기록 정보를 담은 CAR_RENTAL_COMPANY_RENTAL_HISTORY 테이블입니다. CAR_RENTAL_COMPANY_RENTAL_HISTORY 테이블은 아래와…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/157340)[](https://school.programmers.co.kr/learn/courses/30/lessons/157340)

[문제 분석]

(1)`CAR_RENTAL_COMPANY_RENTAL_HISTORY` 테이블에서

```
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
```

(2)2022년 10월 16일에 대여 중인 자동차인 경우 '대여중' 이라고 표시하고,   
대여 중이지 않은 자동차인 경우 '대여 가능'을 표시하는 컬럼  
- 컬럼명: `AVAILABILITY `  
- 반납 날짜가 2022년 10월 16일인 경우에도 ‘대여중’으로 표시)

(3)**자동차 ID와 **`**AVAILABILITY**`** 리스트를 출력**하는 SQL문을 작성해주세요.

```
SELECT CAR_ID, [(2)번 항목] AS AVAILABILITY
```

(4)**결과는 자동차 ID를 기준으로 내림차순 정렬해주세요.**

```
ORDER BY CAR_ID DESC
```

(1),(3),(4) 항목까지는 쉽게 해결했으나, (2) 항목을 해결하는데 꽤 오랜 시간이 걸렸다.

먼저 자동차 대여한 START_DATE와 END_DATE에 2022년 10월 16일이 포함되는지 여부 및 새로운 열을 추가하기 위해 아래와 같은 코드를 작성했다.

```
CASE WHEN 
IF('2022-10-16' BETWEEN START_DATE AND END_DATE, 1, 0) 
THEN "대여 중" ELSE "대여 가능" 
END AS AVAILABILITY
```

삼항 연산자를 이용한 IF 구문을 작성하여 2022–10–16 과 겹치는 날이 있으면 참이므로 1 반환, 없으면 0을 반환하여 CASE 문에서 참일 때 “대여 중”, 거짓 일 때 “대여 가능” 을 반환하게 했다.

[Solution 1]

```
# -- 코드를 입력하세요
SELECT CAR_ID, 
CASE WHEN 
IF('2022-10-16' BETWEEN START_DATE AND END_DATE, 1, 0) 
THEN "대여중" ELSE "대여 가능" 
END AS AVAILABILITY

FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC
```

=> 오답이 나와 START_DATE와 END_DATE까지 나오도록 값을 출력 후 확인해보았다.

![](/images/medium/4d4282672b0a/1.png)

CAR_ID별 겹치는 날짜에는 “대여 가능”, 그렇지 않으면 “대여 중”을 출력하였으나, 이를 GROUP BY()로 묶으면서 가장 상단의 값만 최종적으로 출력됨을 확인할 수 있었다.

CRA_ID 별로, 단 한 번이라도 “대여 중”인 항목이 있을 경우, 대여가 불가능한 것으로 나와야 정상이기 때문에 코드를 재작성하였다.

먼저 CASE문이 아닌 SELECT와 WHERE문으로 날짜(2022–10–16)가 겹치는 차량 번호를 모두 추출했다.

```
SELECT CAR_ID
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE '2022-10-16' BETWEEN START_DATE AND END_DATE
    ORDER BY CAR_ID
```

![](/images/medium/4d4282672b0a/2.png)

그 후 서브쿼리를 사용하여 CAR_ID 중 위의 차량 번호를 포함하는 경우 “대여중”, 그렇지 않은 경우 “대여 가능”이 반환되도록 하여 최종적으로 문제를 해결할 수 있었다.

[FINAL SOULTION]

```
SELECT CAR_ID, 
IF(CAR_ID IN(
    SELECT CAR_ID
    FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
    WHERE '2022-10-16' BETWEEN START_DATE AND END_DATE), "대여중", "대여 가능") 
    AS AVAILABILITY



FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
GROUP BY CAR_ID
ORDER BY CAR_ID DESC
```
