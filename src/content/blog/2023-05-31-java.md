### do while문

무조건 한 번은 실행하는 문장

do ~ while 부분을 한 번 수행하고, 이후 while문의 조건을 만족할 때 다시 do까지 올라가 문장 수행(반복).

```
do{
  반복할 문장들
}while()
```

[예제 1]

```
import java.util.Scanner;

public class DowhileExam {
    public static void main(String[] args) {
        int value = 0;
        Scanner scan = new Scanner(System.in);

        do {
        value = scan.nextInt();
        System.out.println("입력받은 값:" + value);
        } while (value != 10);
        System.out.println("반복문 종료!!!");
```

[예제 2]

### for 문

```
for(변수 초기화; 조건식 ; 증감식){실행할 문장들;)
```

**[예제1]1~100까지 짝수의 합**

```
public class ForExam {

    public static void main(String[] args) {
        int total = 0;
        for (int i = 1; i <= 100; i++) {
            if (i % 2 != 0) {
                continue; //totoal = total + i 부분을 실행시키지 않고, 다음 부분으로 넘어간다.
            }
            total = total + i;

            if (i == 50) {
                break;
            }
        }
        System.out.println(total);
    }
}
```

### for each

```
for(자료형* 변수명:배열명){반복해서 수행할 문장들}
```

*자료형은 배열에 들어가는 형을 써준다. 배열을 돌면서 배열에 들어있는 데이터를 하나씩 꺼내어 변수에 담기 때문에, 변수의 타입이 배열에 들어있는 자료형과 일치해야 한다.  
(ex) int, char, Book …

- **for 문을 이용한 원소 반환:** index를 이용해 값을 꺼내어 int형 변수 value에 담아준다.

```
public class ForEachExam {

    public static void main(String[] args) {
        int[] iarr = { 10, 20, 30, 40, 50 };

        // for문을 이용하여 각각의 원소에 접근
        for (int i = 0; i < iarr.length; i++) {
            int value = iarr[i];
            System.out.println(value);
        }
    }
}
```

- **for each 문을 이용한 원소 반환**: 바로 value값 출력이 가능. 간결, 배열 크기를 몰라도 사용할 수 있으며, 배열처럼 값을 여러개 저장하는 자료구조에서 편하게 사용할 수 있다.

```
public class ForEachExam {

    public static void main(String[] args) {
        int[] iarr = { 10, 20, 30, 40, 50 };

        // for each문으로 변경
        /* for(형과 값을 받아줄 변수명:출력하고 싶은 자료구조) */
        for (int value : iarr) {
            System.out.println(value);
        }

    }
}
```

## 클래스와 객체

### 클래스 선언

- **객체 지향 프로그래밍:** 프로그램을 구성하는 요소를 객체로 보고, 그 객체 간에 상호 작용하도록 프로그래밍 하는 것  
객체로 도출 가능한 것은 사람, 사물, 장소, 개념 등이 있다. 각 객체는 스스로의 속성을 알고, 기능을 가지고 있고 객체를 만들려면 반드시 클래스를 먼저 만들어야 한다.

- **클래스:** 객체를 만들기 위한 설계도, 틀. 객체를 만들기 전 객체가 어떤 속성을 가져야 하는지, 어떤 기능을 가져야 하는지 필요한 사항을 확인 후 설계한다.  
클래스 블록을 만들어서 그 안에 필요한 구성 요소를 넣어준다.  
(ex)붕어빵을 만들어내는 틀

- 객체: 붕어빵. 클래스를 이용해 만들어낸 실체. 프로그램 내에서 실제로 사용하는 객체를 만들어 사용.
- **패키지:** 클래스가 파일이라면, **클래스를 모아둔 폴더**

### 참조형

**— 자바 변수 자료형 “기본형”**

- 논리형: boolean
- 문자형: char
- 정수형: byte, short, int, long
- 실수형: float, double

**— 자바 변수 자료형 “참조형”  
**기본형을 제외한 모든 형(ex. 배열, 클래스 등…)

new: 클래스를 메모리에 올리라는 뜻

인스턴스: 메모리에 올라간 클래스

메모리에 올라간 인스턴스를 가리키는 변수, 참조하는 변수, 레퍼런스하는 변수가 str이라는 변수이다.

변수가 인스턴스를 가지는 것 아니라, 가리킨다는 의미.

다른 메모리 영역에 있는 String이라는 인스턴스를 변수 str이 가리키는 것

str이라는 변수에는 인스턴스가 저장된 메모리의 위치(주소값)가 저장된다. 위치 값을 저장한다 하더라도 어떤 메모리에 저장하는지 그 정보를 알 수는 없다.

결론: str 변수는 String 인스턴스를 참조한다.

[참조형 변수]

```
String str = new String("hello");
```

- str 변수 앞에 기본 자료형이 아닌 String class가 적혀있다.
- “=” 뒤에는 “new” 다음에 생성자라는 것이 있다.

객체: 우리가 소프트웨어 세계에서 구현해야할 대상

클래스: 객체를 구현하기 위한 설계또

인스턴스: 클래스라는 설계또에 따라 소프트웨어 세상에 구현된 실체가 인스턴스

### 메서드

객체지향 언어: 하나의 사물을 하나의 클래스로 설명하는 언어. 사물에 대한 설명은 그 물체에 대한 상태와 행동으로 나눌 수 있다. 물체에 대한 상태를 필드, 물체에 대한 행동을 메소드로 볼 수 있다.

메서드는 입력값을 받은 후 결과를 도출해 낸다.

이 때 입력값을 인자(Argument) 혹은 매개변수(Parameter)라고 한다.

- 매개변수: 전달된 인자를 받아들이는 변수

```
public void method(int i, String str){}
```

=> i, str이 매개변수다.

- 인자: 어떤 함수를 호출할 때 전달되는 값 자체

```
method(10, "abc")
```

=>10, “abc” 가 인자이다.

### 메서드 사용

String의 메소드: String을 리턴하는 메서드는 String의 값을 변화시키지 않고, 새로운 String을 생성하여 리턴한다.

- length(): 문자열의 길이
- concat(): 문자열 연결
- substring(): 문자열자르기

```
package javaStudy;

public class StringMethodExam {
    public static void main(String[] args) {
        String str = new String("hello");
        System.out.println(str.length());
        System.out.println(str.concat(" World"));

        System.out.println(str);

        str = str.concat(" World");
        System.out.println(str);

        System.out.println(str.substring(3));
        System.out.println(str.substring(3, 6));

    }
}
```
