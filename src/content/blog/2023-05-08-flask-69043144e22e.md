플라스크앱 실행을 위해 코드 작성 후 FLASK run 이라는 명령어를 호기롭게 시행하였으나 아래와 같은 error를 만났다.

> Error: Could not locate a Flask application. Use the ‘flask — app’ option, ‘FLASK_APP’ environment variable, or a ‘wsgi.py’ or ‘app.py’ file in the current directory.

Flask app을 실행할 수 없고, ‘FLASK_APP’ environment variable을 사용하라고 하는데 이게 무슨 뜻이지?

## 환경변수란?

환경변수(environment variable)는 **프로세스가 컴퓨터에서 동작하는 방식에 영향을 미치는, 동적인 값(변수)들의 모임**

플라스크 서버를 실행하려면 반드시 FLASK_APP이라는 환경 변수에 플라스크 애플리케이션을 지정해 주어야 한다.

- Application 실행 절차  
1. 파이썬 스크립트(코드) 작성  
**2. 환경변수 설정**  
3. flask run 명령어 실행

### 파이썬 스크립트 작성

```
#FLASK 애플리케이션 생성.
from flask import Flask

#app 모듈 실행
myapp = Flask(__name__)

#데코레이터(기존 함수 변경 없이 추가 기능을 덧붙일 수 있게 해주는 함수): 
#특정 주소("/")에 접속하면 다음 줄에 있는 함수를 호출.
@myapp.route("/")
def index():
    return "Hello, Flaskbook!"
```

### 환경 변수 설정 및 flask run 명령어 실행

스크립트 작성 후 FLASK_APP에 “apps\minimalapp/myapp.py”을 지정해준 후 앱을 실행시켰다. error가 발생하지 않고 [http://127.0.0.1:5000](http://127.0.0.1:5000) URL에 연결이 되었다.

```
(venv01) PS C:\Users\sjyou\flaskbook01> $env:FLASK_APP="apps\minimalapp/myapp.py"  
(venv01) PS C:\Users\sjyou\flaskbook01> FLASK run

 * Serving Flask app 'apps\minimalapp/myapp.py'
 * Debug mode: off
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit
```

> WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead

플라스크 서버가 개발 환경으로 실행되지 않으면(라이브 환경에서 실행되면) 위와 같은 경고 문구가 나온다. 이를 해결하기 위해서 아래와 같은 명령어를 입력했다.

```
(venv01) PS C:\Users\sjyou\flaskbook01> $env: FLASK_ENV="development"
```

그러나, 명령어 입력 후에도 지속적으로 warning 문구가 나와 알아보니 “FLASK_ENV” 는 Flask v2.2.x 부터 지원하지 않는 것으로 확인했다.

대신 debug mode를 사용하여, 변경된 내용을 자동으로 인식 및 reload 할 수 있다. code를 변경하면 terminal에 아래와 같은 안내가 뜨고, 변경 내용이 웹페이지에 반영되는 것을 확인할 수 있었다.

```
#debug mode ON!
(venv01) PS C:\Users\sjyou\flaskbook01> flask run --debug

 * Debug mode: on
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.

Press CTRL+C to quit

 * Debugger is active!

```

### Jinja 2 사용법

**변수 값 표현 : {{ }}**

```
<h1>Name: {{name}}</h1>
```

**조건식 if문 사용: {% %}**

```
{% if name %}
<h1>Name: {{name}}</h1>
{% else %}
<h1>Name:</h1>
{% endif %}
```

**반복 for문 사용: {% %}**

```
{% for user in users %}
<li>

</li>

{% endfor %}
```

### 애플리케이션 컨텍스트와 요청 컨텍스트

- current_app: 액티브 앱(샐행 중의 앱)의 인스턴스
- g: 요청을 통해 이용할 수 있는 전역 임시(일시) 영역. 요청마다 리셋

=> app = Flask(__name__)으로 app에 접근하면 앱의 인스턴스에 접근할 수 있지만, 앱 규모가 커지면 상호 참조해 순환 참조 발생하여 오류 발생한다.

=>current_app에 접근한다.
