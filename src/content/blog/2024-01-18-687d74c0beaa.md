*두 문자열 s와 skip, 그리고 자연수 index 가 주어질 때, 다음 규칙에 따라 문자열을 만들려 합니다. 암호의 규칙은 다음과 같습니다. 예를 들어 s = "aukks", skip = "wbqd", index…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/155652)[](https://school.programmers.co.kr/learn/courses/30/lessons/155652)

## Solution 1

```
import java.util.*;

public class SecretNumber2 {
    public String solution(String s, String skip, int index) {

        // skip해야할 알파벳 제거
        String alphabet =  "abcdefghijklmnopqrstuvwxyz";
        char[] totalAlphabet = alphabet.toCharArray();
        char[] skipArray = skip.toCharArray();

        Set<Character> arrangedAlphabet = new HashSet<>();
        for(char element: skipArray){
            arrangedAlphabet.add(element);
        }

        List<Character> resultList = new ArrayList<>();
        for(char element: totalAlphabet){
            if(!arrangedAlphabet.contains(element)){
                resultList.add(element);
            }
        }

        // idx 이동
        char[] originalString = s.toCharArray();
        char[] convertedChars = new char[s.length()];
        int i = 0;

        for(char element: originalString){
            int originalIdx = resultList.indexOf(element);

            //index만큼의 뒤의 알파벳이 z를 넘어갈 경우 다시 a로 돌아감.
            int idxToMove = (originalIdx + index) % resultList.size();

            convertedChars[i] = resultList.get(idxToMove);;
            i++;
        }

        return new String(convertedChars);
    }

    public static void main(String[] args) {
        SecretNumber2 secretNumber = new SecretNumber2();
        System.out.println(secretNumber.solution("aukks", "wbqd", 5)); // happy
    }
}
```
