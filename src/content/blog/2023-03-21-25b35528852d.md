## 08. 이미지를 위한 인공 신경망

## 08–3 합성곱 신경망의 시각화

**가중치 시각화**

합성곱 층은 여러 개의 필터를 사용해 이미지에서 특징을 학습 각 필터는 커널이라 부르는 가중치와 절편을 가지고 있음. 가중치는 입력 이미지의 2차원 영역에 적용되어 어떤 특징을 두드러지게 표현

모델이 어떤 가중치를 확인했는지 확인. keras 모델에 추가한 층은 layers 속성에 저장되어 있다.

```
from tensorflow import keras
model = keras.models.load_model('best-cnn-model.h5')
```

```
model.layers
```

- 첫 번째 합성층의 가중치 조사. 층의 가중치와 절편은 층의 “weights” 속성에 저장
- weights의 첫 번째 원소(가중치)와 두 번째 원소(절편)의 크기 출력

```
conv = model.layers[0]
print(conv.weights[0].shape, conv.weights[1].shape)
```

가중치 배열의 평균과 표준 편차를 넘파이 배열로 변환 후 계산

```
conv_weights= conv.weights[0].numpy()
print(conv_weights.mean(), conv_weights.std())
```

**훈련하지 않은 빈 합성곱 신경망 만들기**

```
# Sequential 클래스로 모델 만듦
no_training_model = keras.Sequential()
```

```
# Conv2D로 첫번째 층 추가가
no_training_model.add(keras.layers.Conv2D(32, kernel_size=3, activation='relu', padding='same', input_shape=(28,28,1)))
```

```
# 첫번째 층 가중치를 no_training_conv 변수에 저장
no_training_conv = no_training_model.layers[0
print(no_training_conv.weights[0].shape)
```

**가중치의 평균과 표준 편차 확인 및 히스토그램/그림으로 표현**

```
no_training_weights = no_training_conv.weights[0].numpy()
print(no_training_weights.mean(), no_training_weights.std())
```

**함수형 API** Sequential 클래스: 층을 차례대로 쌓은 모델을 만든다. 함수형 API: 입력층, 출력층이 여러 개일 때 사용.

```
dense1 = keras.layers.Dense(100, activation='sigmoid')
dense2 = keras.layers.Dense(10, activation='softmax')
```

```
hidden = dense1(inputs)
# 입력값 input을 dense 층에 통과시킨 후 출력 값을 만들어준다.
```

```
output = dense2(hidden)
```

```
model = keras.Model(inputs, outputs)
```
