연속된 세 개의 정수를 더해 12가 되는 경우는 3, 4, 5입니다. 두 정수 `num`과 `total`이 주어집니다. 연속된 수 `num`개를 더한 값이 `total`이 될 때, 정수 배열을 오름차순으로 담아 return하도록 solution함수를 완성해보세요.

[sol1]

```
def solution(num, total):
    a = num * (num - 1) // 2
    x = (total - a) // num
    answer = []

    for i in range(num):
        answer.append(x)

        x += 1

    return answer
```

[다른 사람 풀이]

```
def solution(num, total):
    return [(total - (num * (num - 1) // 2)) // num + i for i in range(num)]
```

### 부동소수점 반올림 오차(rounding error)

실제 값과 근사값에서 발생하는 오차를 부동소수점 반올림 오차(rounding error) 라고 부른다.

[예시]

```
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)

0.30000000000000004
False
```

파이썬은 부동소수점 형식(가수부와 지수부로 나누어 표현하는 방식)을 사용하고 있어, 부동소수점 반올림 오차가 발생한다.

첫 번째 시도한 코드에서 루트로 계산한 뒤 나온 실수에 대해 오차가 발생했음을 알게되어 부동소수점을 사용하지 않는 코드로 재작성 후 오차없이 문제를 해결할 수 있었다.

### [Final Solution]

```
def distance(a, b, c, d):
    x = (c - a) ** 2
    y = (d - b) ** 2

    return x + y


def solution(m, n, startX, startY, balls):
    result = []
    answer = []
    for i in range(len(balls)):
        if startX <= balls[i][0] or startY != balls[i][1]:
            pp = distance(startX, startY, -balls[i][0], balls[i][1])
            result.append(pp)

        if startX != balls[i][0] or startY >= balls[i][1]:
            qq = distance(startX, startY, balls[i][0], 2 * n - balls[i][1])
            result.append(qq)

        if startX >= balls[i][0] or startY != balls[i][1]:
            rr = distance(startX, startY, 2 * m - balls[i][0], balls[i][1])
            result.append(rr)

        if startX != balls[i][0] or startY <= balls[i][1]:
            ss = distance(startX, startY, balls[i][0], -balls[i][1])
            result.append(ss)

        answer.append((min(result)))
        result = []

    return answer


print(solution(10, 10, 3, 7, [[7, 7], [2, 7], [7, 3]]))
```
