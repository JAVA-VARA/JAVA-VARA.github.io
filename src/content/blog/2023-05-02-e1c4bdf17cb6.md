2. 중위 표현식을 왼쪽부터 한글자씩 읽어서
- 피연산자이면 그냥 출력
- ‘(’ 이면 스택에 push
- ) 이면 (이 나올때까지 스택에서 pop
- 연산자이면 스택에서 이보다 높거나 같은 우선순위들을 pop
- 같은 우선 순위의 경우 왼쪽 연산자부터 계산한다.(- or / 이면 순서에 따라 결과값이 달라지므로)
- 스택에 남아 있는 연산자 모두 pop 출력

[코드 구현]

#1 스택의 맨 위에 있는 연산자와의 우선순위 비교 → 스택의 **peek()연산** 이용

#2 스택에 남아 있는 연산자 모두 pop() 하는 순환문   
→ **while not opStack.isEmpty()**

```
class ArrayStack:

    def __init__(self):
        self.data = []

    def size(self):
        return len(self.data)

    def isEmpty(self):
        return self.size() == 0

    def push(self, item):
        self.data.append(item)

    def pop(self):
        return self.data.pop()

    def peek(self):
        return self.data[-1]

prec = {'*': 3, '/': 3, '+': 2, '-': 2, '(': 1}

def solution(S):
    opStack = ArrayStack()
    answer = ''

    for i in S:
        #피연산자인 경우 그대로 출력
        if i not in "*+-/()":
            answer =+ i
     
        # ( 를 만나면 stack에 집어 넣음.
        if i == "(":
            opStack.push(i)

        #)를 만나면 ( 를 만날때까지 stack 안에 원소들을 꺼내어 answer에 추가
        if i == ")":
            while opStack.peak() != "(":
                answer += opStack.pop()
                opStack.pop()

        #연산자를 만난 경우
        if i in "*+-/"
            #stack 이 비어있으면 바로 stack에 push()
            if opStack.isEmpty():
                opStack.push(i)
            #stack에 연산자가 들어 있으면 
            else:   
                #stack에 맨 위에 들어있는 연산자와 현재 확인한 연산자 우선순위 비교
                while prec[opStack.peek()] >= prec[i]:
                    #stack에 들어 있는 연산자가 큰 경우에는 연산자 pop하여 answer에 추가
                    answer += opStack.pop()
                    
                    #stack에 아무것도 남아있지 않으면 종료
                    if opStack.isEmpty():
                        break
                 #새로운 연산자를 stack에 집어넣음.
                 opStack.push(i)


      #stack이 비어 있지 않으면 stack 내의 연산자를 꺼내서 사용.    
      while not opStack.isEmpty():
          answer += opStack.pop()
      
      return answer
          
```

1. 후위 표현식을 왼쪽부터 한 글자씩 읽는다.
- 피연산자 → 스택에 push
- 연산자 → 스택에서 pop (1), pop (2) → (2) 연산자 (1) 의 결과를 스택에 push
- 수식에 끝에 도달하면 스택에서 pop → 최종 계산 결과가 나옴.

class Node:
    #양방향 연결리스트 구현(빈 리스트 생성)
    def __init__(self, item):
        self.data = item
        self.prev = None
        self.next = None


class DoublyLinkedList:
    #양방향 연결리스트 head, tail 생성
    def __init__(self):
        self.nodeCount = 0
        self.head = Node(None)
        self.tail = Node(None)
        self.head.prev = None
        self.head.next = self.tail
        self.tail.prev = self.head
        self.tail.next = None


    def __repr__(self):
        #연결리스트가 비어있는 경우 empty 반환
        if self.nodeCount == 0:
            return 'LinkedList: empty'

        s = ''
        curr = self.head
        #마지막 node에 도달할 때까지 반복
        while curr.next.next:
            curr = curr.next
            s += repr(curr.data)
            #마지막 node에 도달하지 않았다면, '->' 반환
            if curr.next.next is not None:
                s += ' -> '
        return s


    def getLength(self):
        return self.nodeCount


    def traverse(self):
        result = []
        curr = self.head
        while curr.next.next:
            curr = curr.next
            result.append(curr.data)
        return result


    def reverse(self):
        result = []
        curr = self.tail
        while curr.prev.prev:
            curr = curr.prev
            result.append(curr.data)
        return result


    def getAt(self, pos):
        if pos < 0 or pos > self.nodeCount:
            return None

        if pos > self.nodeCount // 2:
            i = 0
            curr = self.tail
            while i < self.nodeCount - pos + 1:
                curr = curr.prev
                i += 1
        else:
            i = 0
            curr = self.head
            while i < pos:
                curr = curr.next
                i += 1

        return curr


    def insertAfter(self, prev, newNode):
        next = prev.next
        newNode.prev = prev
        newNode.next = next
        prev.next = newNode
        next.prev = newNode
        self.nodeCount += 1
        return True


    def insertAt(self, pos, newNode):
        if pos < 1 or pos > self.nodeCount + 1:
            return False

        prev = self.getAt(pos - 1)
        return self.insertAfter(prev, newNode)


    def popAfter(self, prev):
        curr = prev.next
        next = curr.next
        prev.next = next
        next.prev = prev
        self.nodeCount -= 1
        return curr.data


    def popAt(self, pos):
        if pos < 1 or pos > self.nodeCount:
            raise IndexError('Index out of range')

        prev = self.getAt(pos - 1)
        return self.popAfter(prev)


    def concat(self, L):
        self.tail.prev.next = L.head.next
        L.head.next.prev = self.tail.prev
        self.tail = L.tail

        self.nodeCount += L.nodeCount
