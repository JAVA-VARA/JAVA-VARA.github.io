[**코딩테스트 연습 - 특정 기간동안 대여 가능한 자동차들의 대여비용 구하기**  
*다음은 어느 자동차 대여 회사에서 대여 중인 자동차들의 정보를 담은 CAR_RENTAL_COMPANY_CAR 테이블과 자동차 대여 기록 정보를 담은 CAR_RENTAL_COMPANY_RENTAL_HISTORY…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/157339)[](https://school.programmers.co.kr/learn/courses/30/lessons/157339)

위 문제를 4가지 PART로 쪼개어 풀이를 했다.

1. 11월이 포함되어 있지 않은 차량의 CAR_ID

(2)11월 중에 대여가 예정된 CAR_ID 먼저 구한 후

```
SELECT CAR_ID FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE STR_TO_DATE(START_DATE, '%Y-%m-%d') < '2022-11-30' AND  
STR_TO_DATE(END_DATE, '%Y-%m-%d') >= '2022-10-31'
```

(2) 서브 쿼리 및 NOT IN() 을 통하여, 11월 중에 대여 기록이 있는 차량을 제외한 차량의 CAR_ID를 SELECT 하였다.

```
SELECT CAR_ID
FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE CAR_ID NOT IN(
SELECT CAR_ID FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY
WHERE STR_TO_DATE(START_DATE, '%Y-%m-%d') < '2022-11-30' AND  
STR_TO_DATE(END_DATE, '%Y-%m-%d') >= '2022-10-31')
GROUP BY CAR_ID
ORDER BY CAR_ID
```

2. CAR_ID, CAR_TYPE별 할인된 가격(실수형 →정수형으로 변환)

```
SELECT C.CAR_ID, C.CAR_TYPE, 
CONVERT((C.DAILY_FEE - C.DAILY_FEE * P.DISCOUNT_RATE *1/100)*30, SIGNED) 
AS FEE
FROM CAR_RENTAL_COMPANY_CAR AS C
JOIN CAR_RENTAL_COMPANY_DISCOUNT_PLAN AS P
ON C.CAR_TYPE = P.CAR_TYPE
```

3. 1번 풀이와 2번 풀이를 Join 및 서브쿼리를 이용하여, 합쳐주었다.

```
SELECT C.CAR_ID, C.CAR_TYPE, 
CONVERT((C.DAILY_FEE - C.DAILY_FEE * P.DISCOUNT_RATE *1/100)*30, SIGNED) AS FEE
FROM CAR_RENTAL_COMPANY_CAR AS C
JOIN CAR_RENTAL_COMPANY_RENTAL_HISTORY AS H
ON C.CAR_ID=H.CAR_ID
JOIN CAR_RENTAL_COMPANY_DISCOUNT_PLAN AS P
ON C.CAR_TYPE = P.CAR_TYPE

WHERE 
(C.CAR_ID NOT IN(SELECT 
                 CAR_ID FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY 
                 WHERE STR_TO_DATE(START_DATE, '%Y-%m-%d') < '2022-11-30' AND STR_TO_DATE(END_DATE, '%Y-%m-%d') >= '2022-10-31')) 
```

4. 그 외 나머지 조건들 추가하여 최종적으로 문제를 해결했다.

```
SELECT C.CAR_ID, C.CAR_TYPE, 
CONVERT((C.DAILY_FEE - C.DAILY_FEE * P.DISCOUNT_RATE *1/100)*30, SIGNED) AS FEE
FROM CAR_RENTAL_COMPANY_CAR AS C
JOIN CAR_RENTAL_COMPANY_RENTAL_HISTORY AS H
ON C.CAR_ID=H.CAR_ID
JOIN CAR_RENTAL_COMPANY_DISCOUNT_PLAN AS P
ON C.CAR_TYPE = P.CAR_TYPE

WHERE 
(C.CAR_ID NOT IN(SELECT CAR_ID FROM CAR_RENTAL_COMPANY_RENTAL_HISTORY 
                 WHERE STR_TO_DATE(START_DATE, '%Y-%m-%d') < '2022-11-30' AND STR_TO_DATE(END_DATE, '%Y-%m-%d') >= '2022-10-31')) AND
(C.CAR_TYPE = "SUV" OR C.CAR_TYPE = "세단") AND
((C.DAILY_FEE - C.DAILY_FEE * P.DISCOUNT_RATE *1/100)*30 >= 50000) AND
((C.DAILY_FEE - C.DAILY_FEE * P.DISCOUNT_RATE *1/100)*30 < 2000000) AND
(P.DURATION_TYPE = "30일 이상")

GROUP BY C.CAR_ID
ORDER BY FEE DESC, C.CAR_TYPE ASC, C.CAR_ID DESC
```
