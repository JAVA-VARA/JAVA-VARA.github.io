지난 며칠 간 공부한 “혼자 공부하는 자바스크립트” 개념 정리 및 응용을 위해 아래 문제에 도전해 보았다.

[명세]

- 로또 번호는 1~45 의 랜덤한 숫자를 가진다.
- 추첨은 공 6개와 보너스 공 1개를 뽑는다.
- 회차에 랜덤한 숫자 6개와 보너스 숫자 1개를 발행한다.
- 자신이 입력한 로또 번호와 회차 번호를 비교하여 등수를 출력한다.
- 등수 rule
- 1등 : 공 6개 일치(보너스 공 제외)
- 2등 : 공 5개 일치 + 보너스 공
- 3등 : 공 5개 일치
- 4등 : 공 4개 일치
- 5등 : 공 3개 일치
- 꽝 : 그 외

간단한 변수 선언부터 조건문 그리고 가장 어려웠던 반복문과 중첩 반복문 모두 사용해볼 수 있는 예제였다. 그 동안 잘 이해가 가지 않거나, 어려운 문제에 봉착하면 책자 뒤쪽의 답안지를 보면서 예제를 풀어왔는데 오늘의 문제는 답안지가 따로 없다.(구글링하면 다 나오겠지만…)

백지부터 시작을 하니 머릿속도 백지가 되어버린 느낌. 변수 선언하는 것부터 처음부터 다시 복습해가며 차근차근 코드를 적어 내려갔다. 중첩 반복문은 책을 보고도 사용할 생각을 하지 못하여] 문제 제공자로부터 힌트를 얻기도 했다.

그렇게 아래와 같은 코드를 작성하였으나, 아직 중복된 숫자를 완전히 걸러내지 못하고 있음을 발견했다. 어떤 부분이 잘못되었는지 몇 시간 동안 보고 있지만…아직 모르겠다. 죽이 되든 밥이 되든 내가 공부한 내용을 가지고 만들어보고자 했는데 미완성된 채 점점 곤죽이 되어가는 이 코드가 지금의 내 상태 같다.

보완된 코드는 내일 꼭 완성해서 최종 정리 후 업로드 할 예정.

화이팅!

```
1. 로또 번호
2. 사용자 번호
3. 등수
4. 출력

+ 중복된 숫자 제외, 숫자 정렬   

[로또 번호]

    let randomIndexArray=[]
    let randomNum=Math.floor(Math.random()*44+1)
        for(let i=0;i<7;i++){ 
            for (let i in randomIndexArray){
                while(randomNum===randomIndexArray[i]){
                    randomNum=Math.floor(Math.random()*44+1)
                    }
                }
       
        randomIndexArray.push(randomNum)  
        }

        randomIndexArray.sort(function(a,b){
            return a-b
         
        })
            
        console.log(randomIndexArray)
             
        [로또 자동 추첨 번호]
        
        let userArray=[]
        let userNum=Math.floor(Math.random()*44+1)
            for(let j=0;j<7; j++){
                for(let j in userArray){
                    while(userNum===userArray[j]){
                        userNum=Math.floor(Math.random()*44+1)
                    }
                }
        userArray.push(userNum)
        }
        userArray.sort(function(c,d){
            return c-d
        })
        
        console.log(userArray)


        [등수]
        let count = 0

        for(let m=0;m<7;m++){
            for (let n=0;n<7;n++){
                if(randomIndexArray[m]===userArray[n]){
                    if(m===6){
                        bonusNum = true;
                    }
                    else{
                        count++
                    }
                }
            }
        }
        if(count===6){
            console.log('1등')
        }else if(count===5&&bonusNum){
            console.log('2등')
        }else if(count===5){
            console.log('3등')
        }else if(count===4){
            console.log('4등')
        }else if(count===3){
            console.log('5등')
        }else{
            console.log('꽝')
        }
```
