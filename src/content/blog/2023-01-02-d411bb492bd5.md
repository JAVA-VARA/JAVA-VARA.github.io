04–1. 배열

**배열(array):** 여러 개의 변수를 한 번에 선언해 다룰 수 있는 자료형.

각각의 변수를** *“요소”***라고 하고, 요소의 순소를 **“*인덱스(index)*”**라고 한다.

EX) const array = [273,ture,(),[],…]

04–2. 반복문

- for in 반복문: 배열의 인덱스 기반으로 반복

```
const todos=['우유구매','업무 메일확인하기','필라테스수업']
        
        for(const i in todos){
           console.log(`${i}번째 할 일:${todos[i]}`)
        }
        
        for (const key in object) {
            //**if (Object.hasOwnProperty.call(object, key)) {
                const element = object[key];
                
            }
        
        //* for in 반복문은 **와 같은 코드를 추가해서 사용해야 안정성이 있다.
```

- for of 반복문: 배열의 값을 기반으로 반복

```
const todos=['자바스크립트공부','블로그쓰기','청소']
        for (const todo of todos){
            console.log(`오늘의 할 일: ${todo}`)
        }
```

- for 반복문: 횟수를 기반으로 반복

```
let output=1
        for(let i=1;i<=100; i++){
            output *=i
        }
        console.log(`1~100의 숫자를 모두 곱하면, ${output}입니다.`)
```

- While 반복문: if 조건문과 형태 비슷하나 ‘불표현식’이 true면 문장 실행 무한반복.

ex1)기본 반복문

```
let i=0
        while(confirm('계속 진행하시겠습니까')){
            //사용자가 [확인] 버튼을 클릭하면 true가 되어 계속 반복합니다.
            alert(`${i}번째 반복입니다.`)
            i=i+1
        }
```

ex2)반복문과 함께 배열 사용

```
let i =0
        const array=[1,2,3,4,5]

        while(i<array.length){
            console.log(`${i}:${array[i]}`)
            i++
        }

*실행결과
0:1
1:2
2:3
3:4
4:5
```

- break 키워드: 무한 루프는 break 키워드를 통해 벗어난다.

```
for(let i=0;true;i++){
            alert(i+'번째 반복문입니다.')
        
        //진행 여부를 물어봅니다.
        const isContinue=confirm('계속하시겠습니까')
        if(!isContinue){
            break
        }
        }
        //프로그램의 종료를 확인합니다.
        alert('프로그램종료')
```

- continue 키워드

```
let output=0

        //반복문
        for(let i=1;i<=10;i++){
            //조건문
            if(i%2===1){
                //홀수면 현재 반복을 중지하고 처음으로 돌아가 다음 반복을 수행.
                continue
            }
            output+=i
        }
        alert(output)

->1~10 사이의 짝수의 함으로 결과값 도출!
```

- 중첩반복문

```
<script>
        let output=''
        const size=5

        for(let i=1;i<=size;i++){
            for(let j=size;j>i;j--){    
                output+=' '           
            }
            for(let k=0;k<2*i-1;k++){
                output+='*'
            }
            output+='\n'

        }

        for(let i=size-1;i>0;i--){
            for(let j=size;j>i;j--){
                output+=' '
            }
            for(let k=0;k<2*i-1;k++){
                output+='*'
            }
            output+='\n'
        }
        console.log(output)

</script>
```
