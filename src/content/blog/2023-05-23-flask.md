## 사용자 인증 기능 만들기

- Blueprint로 인증 기능 등록(apps/app.py)

```
from apps.config import config
from flask_wtf.csrf import CSRFProtect
from pathlib import Path
from flask import Flask
from flask_migrate import Migrate
from flask_sqlalchemy import SQLAlchemy
from flask_login import LoginManager

login_manager = LoginManager()
# login_view 속성에 미로그인 시 리다이렉트하는 엔드포인트를 지정한다.
login_manager.login_view = "auth.signup"
# login 시 뜨는 메시지 설정
login_manager.login_message = ""

def create_app(config_key):
    app = Flask(__name__)
    app.config.from_object(config[config_key])

    db.init_app(app)  # SQLAlchemy와 앱 연결
    Migrate(app, db)  # Migrate와 앱 연결
    csrf.init_app(app)
    login_manager.init_app(app)  # login_manager를 application이랑 연결

    from apps.crud import views as crud_views

    app.register_blueprint(crud_views.crud, url_prefix="/crud")

    # auth 패키지로부터 views를 import 한다.
    from apps.auth import views as auth_views

    # register_blueprint를 사용해 views의 auth를 앱에 등록한다.
    app.register_blueprint(auth_views.auth, url_prefix="/auth")

    return app
```

- 인증 기능 엔드포인트 추가(apps/auth/views.py)

```
from flask import Blueprint, render_template

auth = Blueprint("auth", __name__, template_folder="templates", static_folder="static")


# index로 엔드포인트를 작성한다.
@auth.route("/")
def index():
    return render_template("auth/index.html")
```

### [프로그래머스 예제]

[https://school.programmers.co.kr/learn/courses/30/lessons/120812](https://school.programmers.co.kr/learn/courses/30/lessons/120812)

최빈값은 주어진 값 중에서 가장 자주 나오는 값을 의미합니다. 정수 배열 `array`가 매개변수로 주어질 때, 최빈값을 return 하도록 solution 함수를 완성해보세요. 최빈값이 여러 개면 -1을 return 합니다.

[sol1]

# set() 으로 묶어서 중복되는 값 제거

# set()에 들어있는 원소를 dict의 key 값으로 설정

# array를 반복문으로 돌면서 key 값과 동일한 값을 value로 하나씩 추가

# value의 값이 가장 큰 값 반환.

# value 값이 가장 큰 key 값이 2개 이상인 경우 -1 return

```
def solution(array):
    dict = {}
    count = 0

    newArray = list(set(array))

    for i in newArray:
        dict.setdefault(i)
        dict[i] = []

    for j in array:
        dict[j].append(j)

    for k in dict:
        dict[k] = len(dict[k])

    for x in dict:
        if dict[x] == max(dict.values()):
            count += 1

    if count > 1:
        return -1
    else:
        return max(dict, key=dict.get)


print(solution([1, 2, 3, 3, 3, 3, 4]))  # 3
print(solution([1, 1, 2, 2]))  # -1
print(solution([1]))  # 1
```

Flask로 웹앱 개발책을 보며 공부하는데 너무나 많은 빈도로 오류가 발생해 진도를 나가기 어려웠다. error가 발생하면, error 문구에 따라 코드를 수정했는데, 수정을 반복하면서 전체적인 디렉토리 구성이 잘못되었음을 깨달았다.

코드를 한 줄 한 줄 씩 이해하고 적어나가는 것에 집중 하다보니, 전체적인 디렉토리의 구성이 잘 못 되었음을 인지하지 못했던 것이다. 뒤늦게 디렉토리의 위치들을 수정했지만, import 했던 패키지 그리고 환경 변수들의 경로가 섞이면서 코드들을 수정하는데 너무나 많은 시간이 소요되었고, 결국 다 엎어 버린 후 처음부터 다시 시작했다.

결론: 코드도 중요하지만, 전체적인 구성이 어떻게 되는지 잘 살펴보자.
