```
pip install pandas
```

### 2. 사용:

```
import pandas as pd
```

### 3. 주요 함수

- pandas library에서 지원하는 주요 함수

```
#1 read_excel: excel 파일을 2차원 Dataframe 형식으로 변환하여 읽어온다.
df = pd.read_excel(file_path)

#2 Dataframe 형식의 data에서 각 셀 단위로 인수로 전달한 함수를 적용한다.
# 함수는 각 셀의 값을 인수로 받으며, 단일값을 반환해야한다.
df_transformed = df.applymap( function )

#3 변환된 dataframe 형식의 data를 excel 파일로 변환 후 입력해준 경로에 저장한다.
df_transformed.to_excel(output_path, index=False)
```

- 그 외 함수

**zip(iterables object, iterables object, …)  
**반복 가능한 객체를 묶어서 tuple로 반환한다.  
길이가 다른 iterables를 묶을 때는 가장 짧은 것이 기준이 된다.

[ex]

```
list_1 = [1,2,3]
list_2 = [a,b,c]
zipped = zip(list_1, list_2)

print(list(zipped))
#[(1,a),(2,b),(3,c)]
```

4. 실제 코드

증상에 따라 분류된 코드를 현재 사용할 증상 코드로 변환했다.

```
import pandas as pd

# 변환 함수 정의
def transform_symptoms(symptom):
    if symptom == 0:
        return ""
    if symptom in [3, 7] or isinstance(symptom, str) and any(keyword in symptom for keyword in ["속쓰림", "옆구리", "아랫배"]):
        return 1
    if isinstance(symptom, str) and any(keyword in symptom for keyword in ["FEVER", "발열"]):
        return 2
    if symptom == 2:
        return 3
    if symptom in [1, 4, 5, 6, 8, 9, 10, 11]:
        return f"4 & {symptom}"
    if isinstance(symptom, str):
        return f"4 & {symptom}"
    
    return 'null'

# 파일 리스트 정의
file_paths = [f'./ms_{i}.xlsx' for i in range(1, 6)]
output_paths = [f'./mschanged_{i}.xlsx' for i in range(1, 6)]

# 파일 읽기, 변환, 저장을 반복문으로 처리
for file_path, output_path in zip(file_paths, output_paths):
    # Excel 파일 읽기
    df = pd.read_excel(file_path)
    
    # 변환 함수 적용
    df_transformed = df.applymap(transform_symptoms)
    
    # 결과를 새로운 Excel 파일로 저장
    df_transformed.to_excel(output_path, index=False)

# 결과 파일 경로 출력
output_paths
```
