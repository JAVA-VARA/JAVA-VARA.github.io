## 대용량 데이터 처리에 Pandas 라이브러리 사용해보기-1

## 업무

- excel 파일에서 의료 데이터 분석을 위한 변수를 추출하고 정제하는 작업 진행.
- **데이터 양**: 약 400개의 변수, 각 변수 당 10,000 ~ 100,000건의 데이터.

## 문제 상황

**엑셀 파일 성능 문제**: 함수 수식을 추가할 때마다 파일 크기가 커지고, 로딩이 느려지거나 프로그램이 강제 종료됨.

## 해결 방법

### **해결 방법-#1**

- **1차 데이터 가공**: 데이터를 러프하게 1차적으로 가공하여, 수식을 제거하고 정제된 데이터를 최종적으로 원하는 형식으로 만듦.
- **문제점**: 엑셀 파일이 여러 개로 나뉘면서 관리의 복잡도가 증가하고 리소스가 낭비됨.

### **해결 방법 2**

- **Pandas 라이브러리 사용**: 대용량 데이터를 보다 효율적으로 처리하고 하기 위해 Pandas 라이브러리를 사용하기로 결정.
- **Pandas선택 이유: **파이썬으로 excel 파일에 저장된 데이터들을 가공할 수 있도록 해주는 대표적인 라이브러리에 openpyxl 과 Pandas가 있다. 이 둘의 장단점과 차이점은 아래와 같다고 한다,(by chap-gpt 4).

## **[Openpyxl]**

### 장점

- Excel 파일을 읽고, 쓰고, 수정할 수 있는 라이브러리로, **엑셀의 기능(수식, 서식, 필터, 차트 등)을 그대로 사용**할 수 있는 장점이 있음.
- **세부 조작 가능**: 셀 단위로 데이터를 추가, 수정, 삭제하는 등의 미세한 제어가 가능.
- **엑셀과의 호환성**: 엑셀에서 작업한 파일과 동일한 서식을 유지할 수 있어 보고서나 출력물에 적합.

### 단점:

- **대용량 데이터 처리 성능 저하**: 데이터 양이 많아지면 처리 속도가 느려지고 메모리 사용량이 급증.
- **분석 기능 부족**: 데이터를 읽고 쓰는 작업은 가능하지만, **데이터 분석을 위한 기능은 거의 없음**.
- **복잡한 수식 처리 비효율성**: 많은 수식이 포함된 파일은 작업 시 로딩 시간이 길어질 수 있음.

## [Pandas]

**주요 특징**:

- **데이터 분석을 위한 파워풀한 라이브러리**로, CSV, Excel, SQL 등 다양한 데이터 형식을 빠르게 처리할 수 있음.
- 데이터를 다루고 변형하는 데 최적화된 함수와 기능이 많음.

### 장점:

- **빠른 대용량 데이터 처리**: 수십만 건의 데이터를 효율적으로 처리할 수 있어 대용량 작업에 적합.
- **데이터 분석 및 변환에 강점**: 데이터를 그룹화, 필터링, 변환 등의 작업을 쉽게 할 수 있음.
- **다양한 파일 포맷 지원**: Excel뿐만 아니라 CSV, JSON, SQL 등 다양한 데이터 소스를 쉽게 읽고 쓸 수 있음.
- **메모리 효율성**: 대용량 데이터를 메모리 효율적으로 처리하는 능력이 뛰어남.

### 단점:

- **엑셀의 서식 및 기능 지원 부족**: 서식, 차트, 수식 등 엑셀 고유의 기능은 거의 지원하지 않음.
- **엑셀 파일 수정 불가**: Pandas는 데이터를 읽고 수정하는 것보다 **주로 데이터를 추출하고 분석하는 데 중점**을 둠. 엑셀 파일 내 특정 서식을 유지하면서 수정하는 데는 적합하지 않음.

## 결론

- 대규모 데이터 처리에 용이하고 엑셀의 세부적인 작업 및 수식/서식이 필요하지 않기 때문에 Pandas가 효율적이라고 판단.
- 별도의 데이터분석 연구에 사용될 가능성이 있기 때문에 pandas 사용.
