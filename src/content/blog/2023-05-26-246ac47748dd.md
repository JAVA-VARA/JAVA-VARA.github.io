### [solution 1]

```
def solution(n):
    newList = list(str(n))
    x = 0

    for i in newList:
        x += int(i)

    return x
```

### [solution 2]

```
def solution2(n):
    newList = list(str(n))
    return sum(int(i) for i in newList)


print(solution2(123))  # 6
print(solution2(987))  # 24
```
