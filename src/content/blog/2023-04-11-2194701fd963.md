### #리스트 스캔

- enumerate() 함수: 인덱스와 원소를 짝지어 튜플로 꺼내는 내장 함수

```
#enumerate() 함수 사용-1
x=['john' , 'GEOGRE', 'WERQDFS', 'CAR']

for i, name in enumerate(x):
    print(f'x[{i}] = {name}')

#enumerate() 함수 사용-2
x=['john' , 'GEOGRE', 'WERQDFS', 'CAR']

for i, name in enumerate(x,1):
    print(f'x[{i}번째 = {name}')


#for()문 사용
x=['john' , 'GEOGRE', 'WERQDFS', 'CAR']

for i in x:
  print(i)
```

### #이터러블(iterable, 반복 가능)

원소를 하나씩 꺼내는 구조, 내장 함수인 iter()의 인수로 전달하면, 그 객체에 대한 이터레이터(iterater, 반복자)를 반환한다. iterater는 데이터의 나열을 표현하는 객체이다.

- 이터러블 객체: 문자열, 리스트, 튜플, 집합, 딕셔너리 등의 자료형

### #함수 사이의 인수 전달

파이썬에서 인수 전달은 실제 인수인 객체에 대한 참조를 값으로 전달하여 매개변수에 대입하는 방식이다.

- **인수가 이뮤터블일 때**

함수 안에서 매개변수의 값을 변경하면 다른 객체를 생성하고, 그 객체에 대한 참조로 업데이트 된다. 매개변수의 값을 변경해도 호출하는 쪽의 실제 인수에는 영향을 주지 않는다.

```
def sum_1ton(n):
    s=0
    while n>0:
        s += n
        n -= 1
    return s

x = int(input('x의 값을 입력하세요.: '))
print(f'1부터 {x}까지 합은 {sum_1ton(x)}입니다.')
```

x값에 5를 입력하면, x가 대입된 n은 5를 참조(n값은 x값을 참조하는 것이 아니다. 정수 5를 참조한다.) 한다. 변수 n값은 업데이트 되는 시점에 다른 객체를 참조하게 되므로, 함수를 종료할 때 x값은 5, n값은 0이 된다.(n값은 정수 0을 참조하게 된다.)

- **인수가 뮤터블일 때**

함수 안에서 매기변수의 값을 변경하면 객체 자체를 업데이트한다. 매개변수의 값을 변경하면 호출하는 쪽의 실제 인수의 값도 변경된다.

```
def change(lst, idx, val):
    """lst[idx]의 값을 val로 업데이트"""
    lst [idx] = val

x = [11, 22, 33, 44, 55]
print('x =', x)

index = int(input('업데이트할 인덱스를 선택하세요.: ')) # 정수 2값 입력
value = int(input('새로운 값을 입력하세요.: ')) # 정수 99값 입력

change(x, index, value)
print(f'x = {x}')

[실행결과]
x=[11,22,99,44,55]
```

인수가 뮤터블하면, 함수 안에서 업데이트한 값이 원래 호출한 곳으로 전달된다.

### #소수 나열하기

- 소수: 자신과 1 이외의 정수로 나누어 떨어지지 않는 정수

```
counter = 0  # 나눗셈 횟수

for n in range(2, 1001):
    for i in range(2, n):
        counter += 1
        if n % i == 0 :     # 나누어 떨어지면 소수가 아님
            break           # 반복은 더 이상 불필요하여 중단
    else:                   # 끝까지 나누어 떨어지지 않으면 다음을 수행
        print(n)
print(f'나눗셈을 실행한 횟수: {counter}')
```

아래의 방법으로 연산 횟수를 줄일 수 있다.

```
counter = 0             # 곱셈과 나눗셈을 합한 횟수
prime = [2, 3]          # 소수를 저장하는 배열

for n in range(5, 1001, 2):     # 홀수만을 대상으로 설정
    i = 1
    while prime[i] * prime[i] <= n:
        counter += 2
        if n % prime[i] == 0:   # 나누어 떨어지므로 소수가 아님
            break               # 반복 중단
        i += 1
    else:                       # 끝까지 나누어 떨어지지 않았다면
        prime += [n]            # 소수로 배열에 등록
        counter += 1

for i in prime:                 # 소수를 출력
    print(i)
print(f'곱셈과 나눗셈을 실행한 횟수: {counter}')
```

### #리스트의 원소와 복사

- 얕은 복사: 리스트 안의 원소가 ***참조하는 곳까지*** 복사된다. 즉 객체가 참조 자료형의 멤버를 복사하는 것.

```
x=[[1,2,3],[4,5,6]]
y=x.copy() 
#얕은 복사로 원소 x[0] 과 x[1]이 복사된다.
#x[0] = [1,2,3]
#x[1] = [4,5,6]

x[0][1] = 9

print(x)
[[1,9,3],[4,5,6]]

print(y)
[[1,9,3],[4,5,6]]

copy 후 x 값 업데이트하면 y값도 업데이트 된다.
x[0]이 참조하는 곳과 y[0]이 참조하는 곳이 같으므로
x[0][1] 과 y[0][1]이 참조하는 곳이 같다.
```

- 깊은 복사: 리스트 안의 구성 원소 수준(원소의 원소)으로 복사하는 방법. 즉 객체가 참조값과 참조하는 객체 자체를 복사하는 것.

```
import copy

x=[[1,2,3],[4,5,6]]
y=copy.deepcopy(x)

x[0][1] = 9

print(x)
print(y)
```
