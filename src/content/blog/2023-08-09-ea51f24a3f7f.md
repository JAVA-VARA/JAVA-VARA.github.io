### Solution_1

- 주요 제한 사항  
(1) 5 ≤ `players`의 길이 ≤ 50,000  
 (2) 2 ≤ `callings`의 길이 ≤ 1,000,000

내가 생각한 문제 해결 key point

1. 제한 사항 (2)에 따라 `callings`의 길이가 길어, 배열을 한 번만 순회하며 순위 변동 사항을 적용
2. LinkedList를 이용: 등수가 변경될 때마다 배열 내부에 **“추가/삭제” **가 지속적으로 진행되어야 하기 때문에 해당 기능에 O(1)의 시간복잡도를 가지는 LinkedList 사용.

위 두 가지 포인트를 생각하며 시간복잡도 O(n)을 가지도록 아래와 같이 코드를 구성하였다.

```
package Programmers_Solution;

import java.util.Arrays;
import java.util.Collections;
import java.util.LinkedList;

public class Race {
    public String[] solution(String[] players, String[] callings) {
        String[] answer = new String[players.length];

        LinkedList<String> currRank = new LinkedList<>(); //O(1)
        Collections.addAll(currRank, players); //O(1)

        for (String name : callings) { //O(N)
            int changedRank = currRank.indexOf(name)-1; //O(N)
            currRank.remove(name); //O(N)
            currRank.add(changedRank, name); //O(N)
        }. 

        for (int i = 0; i < players.length; i++) {
            answer[i] = currRank.get(i);
        }
        return answer;
    }
    //test
    public static void main(String[] args) {
        Race runningRace = new Race();
        System.out.println(Arrays.toString(runningRace.solution(
                new String[]{"mumu", "soe", "poe", "kai", "mine"},
                new String[]{"kai", "kai", "mine", "mine"})));
    }
}
```

정확도는 통과하였지만 효율성 test에서 시간 초과로 탈락하였다. 이중 for문만 쓰지 않으면 될 것이라고 생각했지만 아래 2가지 과정을 진행 시 list의 head부터 tail까지 순회 해야 하기 때문에 O(n²) 시간 복잡도를 가지는 것을 알게되었다.

- 원하는 요소의 index를 찾는 과정 / indexOf()
- 추가/삭제할 요소를 찾는 과정 / remove(element), add(index, element)

```
        for (String name : callings) { //O(N)
            int changedRank = currRank.indexOf(name)-1; //O(N)
            currRank.remove(name); //O(N)
            currRank.add(changedRank, name); //O(N)
        }
```

### Solution_2

callings 배열을 한 번만 순회하며, 반복문 내부에 또 다른 순회 코드가 들어가지 않도록 코드를 재구성하였다.

여러 가지 시도 끝에 현재 순위가 담긴 players 배열을 실시간으로 변경하는 방법을 시도하였다. 배열 index를 가지고 접근할 때 O(1)의 시간 복잡도를 갖기 때문에 연산하는 시간을 줄일 수 있었다.

```
import java.util.*;

public class RacingFinal {
    public String[] solution(String[] players, String[] callings) {

        //현재 랭킹
        HashMap<String, Integer> currRanking = new HashMap<>();
        for (int i = 1; i <= players.length; i++) {
            currRanking.put(players[i-1], i);
        }
        //랭킹 변동
        for(String winner:callings){

            int calledRank = currRanking.get(winner)-1;
            String loser = players[calledRank-1];
            
            players[calledRank-1] = winner; //뒤 -> 앞
            players[calledRank] = loser; //앞 -> 뒤
            
            currRanking.put(winner, calledRank);
            currRanking.put(loser , calledRank+1);
        }
        return players
    }
}
```
