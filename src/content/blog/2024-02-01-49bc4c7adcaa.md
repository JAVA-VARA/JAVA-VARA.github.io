*경화는 과수원에서 귤을 수확했습니다. 경화는 수확한 귤 중 'k'개를 골라 상자 하나에 담아 판매하려고 합니다. 그런데 수확한 귤의 크기가 일정하지 않아 보기에 좋지 않다고 생각한 경화는 귤을 크기별로 분류했을 때…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/138476)[](https://school.programmers.co.kr/learn/courses/30/lessons/138476)

## Solution1

```
import java.util.*;

public class Tangerine {
    public int solution(int k, int[] tangerine) {

        Map<Integer, Integer> countTanBySize = new HashMap<>();
        for(int tan : tangerine){
            countTanBySize.put(tan, !countTanBySize.containsKey(tan) ? 1 : countTanBySize.get(tan) + 1);
        }

        int i =0;
        int[] arr = new int[countTanBySize.size()];
        for(int ea: countTanBySize.keySet()){
            arr[i] = countTanBySize.get(ea);
            i++;
        }

        Integer[] arr2 = Arrays.stream(arr).boxed().toArray(Integer[]::new);
        Arrays.sort(arr2, Collections.reverseOrder());

        int answer = 0;
        int count = 0;
        for(int x : arr2){
            if(answer >= k){
                break;
            }
            answer += x;
            count += 1;
        }
        return count;
    }
    public static void main(String[] args) {
        Tangerine tangerine = new Tangerine();
        System.out.println(tangerine.solution(6, new int[] {1, 3, 2, 5, 4, 5, 2, 3})); //3
        System.out.println(tangerine.solution(4, new int[] {1, 3, 2, 5, 4, 5, 2, 3})); //2
        System.out.println(tangerine.solution(2, new int[] {1, 1, 1, 1, 2, 2, 2, 3})); //1
    }
}
```

## Solution2

```
import java.util.*;

public class Tangerine {
    public int solution(int k, int[] tangerine) {

        //삼항연산자 대신 getOrDefault 메서드 사용
        Map<Integer, Integer> countTanBySize = new HashMap<>();
        for(int tan: tangerine){
            countTanBySize.put(tan, countTanBySize.getOrDefault(tan,0)+1);
        }
        //람다 표현식을 사용해 내림차순 정렬
        List<Integer> list = new ArrayList<>(countTanBySize.keySet());
        list.sort((o1, o2) -> countTanBySize.get(o2)-countTanBySize.get(o1));

        int count = 0;
        for(int key : list){
            k-= countTanBySize.get(key);
            count += 1;
            if(k <= 0 ){
                break;
            }
        }
        return count;
    }
}
```
