### 혼자 공부하는 자바스크립트

## 06. 객체

06–1.객체의 기본

정의

- 객체(object): ‘이름(name)’과 값(value)’로 구성된 속성을 가진 자바스크립트의 기본 테이터 타입으로, 실제로 존재하는 사물을 의미한다.

객체는 중괄호로 생성하며 아래와 같이 쉼표로 연결해서 입력한다.

```
    const product = {
        제품명: '7D 건조 망고',
        유형: '당절임',
        성분: '망고, 설탕, 메타중아황산나트륨, 치자황액소',
        원산지: '필리핀'
        }

    console.log(product.제품명)*
    console.log(product['제품명'])*

    *객체 속성에접근하는 2가지 방법(예시)
    객체 뒤에 대괄호 혹은 온점을 사용하여 접근할 수 있다.


    const object = {
        "with space":273,
        "with !@#@$@#$^%&^":52
    }

    console.log(object["with space"])**

** 식별자로 사용할 수 없는 단어를 키로 사용하는 경우 
무조건 대괄호를 사용해야 속성에 접근할 수 있다.
```

- 속성과 메소드

— 속성: 객체 내부의 값

— 메소드: 속성 중 함수 자료형

- 메소드 내부에서 this 키워드 사용하기: 메소드 내에서 자기 자신이 가진 속성을 출력하고 싶을 때 사용

```
[메소드 선언 및 this 키워드 사용하기]
<script>
const pet = {
        name: '경민',
        eat: function(food){
            console.log(this.name+ '이는 ' + food + '을 먹습니다.')
        }
    }
    pet.eat('풀')
</script>


[메소드 간단 선언 구문]
메소드를 아래와 같이 작성하면 더 간단하게 선언 가능하니 참고.

<script>
 const pet2 = {
        name: '구름',
        eat (food){
            console.log(this.name+'이는 '+food+'을 좋아합니다.')
        }
    }
    pet2.eat('밥')
</script>
```

- 동적으로 객체 속성 추가/제거하기

```
<script> 
  //객체 선언
  const student = {}

    //속성 추가 
    student.이름 = '윤인성'
    student.취미='악기'
    student.장래희망='백수'

    //출력
    console.log(JSON.stringify(student, null, 2))

    //속성 제거
    delete student.장래희망

    //출력
    console.log(JSON.stringify(student, null, 2))

</script>
```

06–2. 객체의 속성과 메소드 사용하기

- 기본 자료형을 객체로 선언하기

```
const 객체 = new 객체 자료형 이름()

new Number(10)
new String('hi')
new Bollean(true)

위와 같이 사용하면 숫자, 문자열, 불 객체를 생성할 수 있다. 
기본 자료형이 아닌 객체로 선언되었으므로 속성을 가질 수 있으며,
메소드도 활용 가능하다.

>const f = new Number(1)
undefined

>type of f
"object"

>f.sample = 10

>f.sample
10 -> 속성을 가질 수 있다.

>f
(1, sample:10)

>f+valueOf()
1  ->valueOf 메소드를 통해 값을 추출할수 있다.
```

- 기본 자료형의 일시적 승급: 편리성을 위해 기본 자료형의 속성과 메소드를 호출할 때 일시적으로 기본 자료형을 객체로 승급시킨다. 일시적으로 사용은 가능하나 속성과 메소드를 추가로 가질 수는 없다.

```
> const h = '안녕하세요'
undefined

>h.sample = 10
10

>h.sample
undefined
```

- 프로토타입으로 메소드 추가하기

```
객체 자료형 이름.prototype.메소드 이름 = function(){}

[1]prototype으로 숫자 메소드 추가하기

<script>

        //power()메소드 추가
        Number.prototype.power=function(n=2){
            return this.valueOf()**n
        }

        //Number 객체의 power()메소드를 사용합니다.
        const a = 12
        console.log('a.power():' , a.power())
        console.log('a.power(3):', a.power(3))
        console.log(a.valueOf(4))

</script>

[실행결과]
a.power():144
a.power(3): 1728
20736

[2]prototype으로 문자 메소드 추가하기

<script>

        //contain() 메소드를 추가합니다.

        String.prototype.contain = function (data){
            return this.indexOf(data)>=0
        }

        Array.prototype.contain = function(data){
            return this.indexOf(data)>=0
        }

        //String 객체의 contain() 메소드를 사용합니다.
        const x = '안녕하세요'
        console.log('안녕 in 안녕하세요:', x.contain('안녕'))
        console.log('없는데 in 안녕하세요', x.contain('없는데'))

        //Array 객체의 contain()메소드를 사용합니다.
        const y = [273, 32, 103, 57, 52]
        console.log('273 in [273, 32, 103, 57, 52]:', y.contain(273))
        console.log('0 in [273, 32, 103, 57, 52]:', y.contain(0))

</script>
```

- Math 객체

```

    console.log('# 랜덤한 숫자')

    console.log('# 랜덤한 숫자 범위 이동')
    console.log('-5~5 사이의 랜덤한 숫자:', num*10-5)

    console.log('')

    console.log('# 랜덤한 정수 숫자')
    console.log('-5~5 사이의 랜덤한 숫자:', Math.floor(num*10-5))
    console.log('-25~25 사이의 랜덤한 숫자:', Math.floor(num*50-25))
    console.log('')

    </script>

예제②

```
[모질라 문서에서 Math 객체와 관련된 내용 읽고 sin 90도 값을 구해라.(sin90 = 1]

    <script> 
        const degree=90
        Math.sin(degree)

        console.log( Math.round(Math.sin(degree)))

모질라 문서에서 sin 값 구하는 메소드 확인했을 때 Math.sin() 메소드 사용하는 것을 보고 
Math.sin(degree)을 구해보니 0.8939...값이 나왔다. 
문제에서 정답이 "1" 이라고 하여 Math.round() 메소드를 사용하여 단순히 정수값으로 반올림하여

하지만 너무 문제가 쉽게 풀리는 것이 이상하여 
모질라에 재접속하여 Math.sin()메소드를 재확인,
"Math.sin(radians)" 으로 값을 구해야함을 확인하였다.

    <script>
        const deGree=90
        const radian= deGree*( Math.PI / 180)

       console.log(Math.sin((radian))
    </script>

*1 degree = π / 180 radian
