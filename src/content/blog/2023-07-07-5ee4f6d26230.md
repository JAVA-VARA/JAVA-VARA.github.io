*당신은 폰켓몬을 잡기 위한 오랜 여행 끝에, 홍 박사님의 연구실에 도착했습니다. 홍 박사님은 당신에게 자신의 연구실에 있는 총 N 마리의 폰켓몬 중에서 N/2마리를 가져가도 좋다고 했습니다. 홍 박사님 연구실의…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/1845)[](https://school.programmers.co.kr/learn/courses/30/lessons/1845)

### [Sol1]

```
package Programmers_Solution;

import java.util.HashSet;

public class Poketmon {
    public int solution(int[] nums) {
        HashSet<Integer> set = new HashSet<Integer>();
        for (int i = 0; i < nums.length; i++) {
            int num = nums[i];
            set.add(num);
        }

        int answer = 0;
        if(set.size() > nums.length/2){
            answer = nums.length/2;
        } else
            answer = set.size();
        return answer;
    }

    public static void main(String[] args) {
        Poketmon pk = new Poketmon();
        System.out.println(pk.solution(new int[] {3,1,2,3}));
    }
}
```

### [Sol2]

```
import java.util.HashSet;

public class Poketmon {
    public int solution(int[] nums) {
        HashSet<Integer> set = new HashSet<>();
        for (int num : nums) {set.add(num);}

        return Math.min(set.size(), nums.length / 2);
    }
}
```
