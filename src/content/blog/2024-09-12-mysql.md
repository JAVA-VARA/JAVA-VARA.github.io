### **업그레이드 된 아이템 구하기**

[**코딩테스트 연습 - 업그레이드 된 아이템 구하기**  
*어느 한 게임에서 사용되는 아이템들은 업그레이드가 가능합니다. 'ITEM_A'->'ITEM_B'와 같이 업그레이드가 가능할 때 'ITEM_A'를 'ITEM_B' 의 PARENT 아이템, PARENT 아이템이 없는…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/273711)[](https://school.programmers.co.kr/learn/courses/30/lessons/273711)

```
SELECT ITEM_ID,ITEM_NAME,RARITY
FROM ITEM_INFO
WHERE ITEM_ID IN
    (SELECT T.ITEM_ID 
    FROM ITEM_TREE T
    JOIN ITEM_INFO I
    ON T.PARENT_ITEM_ID = I.ITEM_ID
    WHERE I.RARITY = "RARE")
ORDER BY ITEM_ID DESC
```

### [문제]

아이템의 희귀도가 ‘RARE’인 아이템들의 모든 다음 업그레이드 아이템의 아이템 ID(ITEM_ID), 아이템 명(ITEM_NAME), 아이템의 희귀도(RARITY)를 출력하는 SQL 문을 작성해 주세요. 이때 결과는 아이템 ID를 기준으로 내림차순 정렬주세요.

### [문제 쪼개기]

1. 각 아이템의 다음 업그레이드 아이템들을 찾는다.
2. 그 중 아이템의 희귀도가 ‘RARE’인 아이템을 고른다.
3. 아이템 ID(ITEM_ID), 아이템 명(ITEM_NAME), 아이템의 희귀도(RARITY)출력
4. 결과를 아이템 ID를 기준으로 내림차순 정렬

### [해결 과정]

1. **각 아이템의 다음 업그레이드 아이템들을 찾는다.**

다음 업그레이드 아이템이 있으려면 PARENT_ITEM_ID 가 있어야 한다.

```
SELECT *
FROM ITEM_TREE T
JOIN ITEM_INFO I
ON T.PARENT_ITEM_ID = I.ITEM_ID
```

ITEM_TREE table의 PARENT_ITEM_ID 열을 기준으로 ITEM_INFO table의 ITEM_ID를 inner join하면 PARENT_ITEM_ID가 있는 행만 남게 된다.

![](/images/medium/582d32664d83/1.png)

2. 아이템의 ID를 ITEM_TREE table기준(좌측 테이블)으로 반환하면, 업그레이드가 가능한 아이템들의 다음 업그레이드 된 아이템들의 ID를 구할 수 있다.

```
SELECT T.ITEM_ID 
    FROM ITEM_TREE T
    JOIN ITEM_INFO I
    ON T.PARENT_ITEM_ID = I.ITEM_ID
    WHERE I.RARITY = "RARE"
```

![](/images/medium/582d32664d83/2.png)

3. 이중 select문으로 위에서 반환 받은 아이템들의 ITEM_ID, ITEM_NAME, RARITY 출력 & 내림차순 정렬

```
SELECT ITEM_ID,ITEM_NAME,RARITY
FROM ITEM_INFO
WHERE ITEM_ID IN
    (SELECT T.ITEM_ID 
    FROM ITEM_TREE T
    JOIN ITEM_INFO I
    ON T.PARENT_ITEM_ID = I.ITEM_ID
    WHERE I.RARITY = "RARE")
ORDER BY ITEM_ID DESC
```

![](/images/medium/582d32664d83/3.png)
