## DAY 11. 함수를 정의하고 호출하기

**[함수 호출 방법]**

```
def 함수 이름(인자): #인자가 없으면 생략 가능.
    함수의 내용
    return 삼수의 결과값 #결과값이 없을 때는 생략 가능
```

**[함수 정의하고 호출하기]**

```
def hello(): #def 명령어로 함수를 정의
    print("hi python") #hello 함수를 정의

hello() #함수 호출
hello()
hello()

[실행 결과]
hi python
hi python
hi python
```

**[인자가 있는 함수]**

```
def hello2(name):
    print("Hello", name) #이름을 인자로 전달받아 Hello와 함께 출

hello2("Mark")
hello2("Justine")
hello2("Pungja")

[실행 결과]
Hello Mark
Hello Justine
Hello Pungja
```

**[결과값이 있는 함수]**

```
#a의 제곱을 구하는 함수
def square(a):
    c=a*a
    return c

#밑변이 a이고 높이가 h인 삼각형의 넓이를 구하는 함수
def triangle(a,h):
    c=a*h/2
    return c

s1 = 4
s2 = square(s1)
print(s1,s2)

print(triangle(3,4))

[실행 결과]
4 16
6.0
```

## DAY12. 함수 응용하기

**[1부터 n까지의 합을 구하는 함수]**

```
def sum_func(n):
    s=0
    for x in range(1, n+1):
        s=s+x
    return s

print(sum_func(10))
print(sum_func(100))

[실행 결과]
55
5050
```

**[1부터 n까지의 곱을 구하는 함수]**

```
def mul_func(n):
    s=1
    for x in range(1,n+1):
        s=s*x
    return s
print(mul_func(10))

[실행 결과]
3628800
```

**[다각형 그리기]**

```
import turtle as t

def polygon(n):
    for x in range(n):
        t.fd(50)
        t.lt(360/n)

def polygon2(n,a):
    for x in range(n):
        t.fd(a)
        t.lt(360/n)

polygon(5)

t.up()
t.fd(100)
t.down()

polygon2(6,60)
```

import turtle as t

t.bgcolor("black")
t.speed(0)

for x in range(200):
    if x&3 == 0:
        t.color("red")
    if x%3 ==1 :
        t.color("yellow")
    if x%3 ==2 :
        t.color("blue")

    t.lt(119)
