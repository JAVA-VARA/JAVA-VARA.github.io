## #3

비트 연산자* 관련된 내용을 복습하고 천천히 문제를 풀었다. 먼저 & 연산자**를 사용해 DEVELOPERS와 SKILLCODES 테이블을 조인했다. 머릿속에 쿼리 결과가 어떻게 반환 될지 잘 그려지지 않아 일단 JOIN한 전체 테이블을 반환해보았다.

```
SELECT A.ID, A.FIRST_NAME, A.EMAIL,A.SKILL_CODE, BIN(A.SKILL_CODE) AS BINARY_SKILL_CODE ,B.NAME, B.CATEGORY, B.CODE,BIN(B.CODE) AS BINARY_CODE
FROM DEVELOPERS A
JOIN SKILLCODES B 
ON (A.SKILL_CODE & B.CODE) = B.CODE
ORDER BY A.FIRST_NAME
```

![](/images/medium/32501f4829b9/1.png)

*컴퓨터에서 숫자를 이진수(0과 1)로 표현하여 처리하는 방식  
**“&” 연산자는 두 숫자를 비트 단위로 비교하여 둘 다 1인 자리만 1을 반환한다.

## #4

개발자가 가진 스킬을 기준으로 반환된 표를 볼 수 있었다. 이 표에서 문제에서 요구하는 PYTHON OR C# SKILL을 가진 개발자를 찾았다.

```
SELECT DISTINCT ID, EMAIL, FIRST_NAME, LAST_NAME
FROM DEVELOPERS A
JOIN SKILLCODES B 
ON (A.SKILL_CODE & B.CODE) = B.CODE
WHERE B.NAME  = 'Python' OR B.NAME = 'C#'
ORDER BY A.ID 
```

PYTHON OR C# 이므로 두 SKILL을 모두 가진 개발자는 중복으로 반환 되기 때문에 DISTINCT로 중복되는 값을 제거해주었다.

## #5

PYTHON OR C# SKILL을 가진 개발자를 찾는 WHERE절. IN 함수를 사용해 더 가독성 있게 코드를 변경했다.

```
SELECT DISTINCT ID, EMAIL, FIRST_NAME, LAST_NAME
FROM DEVELOPERS A
JOIN SKILLCODES B ON (A.SKILL_CODE & B.CODE) = B.CODE
WHERE B.NAME IN ('Python', 'C#')
ORDER BY ID;
```
