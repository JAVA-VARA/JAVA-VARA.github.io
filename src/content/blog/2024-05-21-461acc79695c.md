내림차순 정렬을 계속 까먹어서 한번 더 정리했다.

## 오름차순

```
int[] arr ={2,1,3}
Arrays.sort(arr);

//Result: 1, 2, 3

String[] arr ={"b","a","c"}
Arrays.sort(arr);

//Result: a, b, c
```

## 내림차순

### - int

```
int[] arr = {4,2,3,1}

//[1]
//int형 배열 -> Integer 배열로 boxing(Primitive -> Wrapper 클래스)
Integer[] arr2 = Arrays.stream(arr).boxed.toArray(Integer[]::new);
//Arrays.sort로 정
Arrays.sort(arr2,Collections.reverseOrder());
//결과 4,3,2,1

//[2]정렬 후 다시 int형 배열로 변경
arr = Arrays.stream(arr)
          .boxed().sorted(Collections.reverseOrder())
          .mapToInt(Integer::intValue).toArray();
```

*int -> Integer로 바꿔야 하는 이유

**sort 메서드(Arrays.java)**

```
public static <T> void sort(T[] a, Comparator<? super T> c) {
        if (c == null) {
            sort(a);
        } else {
            if (LegacyMergeSort.userRequested)
                legacyMergeSort(a, c);
            else
                TimSort.sort(a, 0, a.length, c, null, 0, 0);
        }
    }
```

=>sort 메서드는 제네릭 타입 T의 배열을 정렬하는 자바의 표준 라이브러리 메서드다. 여기서 T 는 객체 타입을 의미하기 때문에 객체 배열에 대해서만 작동한다.

따라서 primitive type인 int[] 를 객체 타입인 Integer[]로 바꿔줘야하는 과정이 필요한 것이다.

### - String

```
String[] arr = {"a","b","c"}
Arrays.sort(arr,Collections.reverseOrder());
```
