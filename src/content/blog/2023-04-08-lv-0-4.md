이진수를 의미하는 두 개의 문자열 `bin1`과 `bin2`가 매개변수로 주어질 때, 두 이진수의 합을 return하도록 solution 함수를 완성해주세요.

Sol1)

1. 이진수를 십진수로 바꾼다.

파이썬에서는 기본적으로 10진수 형태로 숫자를 표현한다. 다른 진수의 형태로 숫자를 표현하려면 숫자 앞에 접두어를 붙여줘야 한다.

- 2진수: `0b`
- 8진수: `0o`
- 16진수: `0x`
2. 변환 후 값을 더해준다.
3. 더해준 값을 이진수로 다시 변환한다.
4. “0b” 가 접두어로 붙으므로, 해당 string을 제외한 값을 return 한다.
- replace()로 “0b” 제거

```
def solution(bin1, bin2):
    answer = ''
    a= int("0b"+bin1 ,2)
    b= int("0b"+bin2 ,2)
    c= bin(a+b).replace("0b","")

    return c

print(solution("10", "11")) #"101"
print(solution("1001", "1111")) #"11000"
```

- 슬라이싱 연산자로 2번째부터 출력

```
def solution(bin1, bin2):
    answer = ''
    a= int("0b"+bin1 ,2)
    b= int("0b"+bin2 ,2)
    c= bin(a+b)[2:]

    return c
```

## A를 B로 만들기

문자열 `before`와 `after`가 매개변수로 주어질 때, `before`의 순서를 바꾸어 `after`를 만들 수 있으면 1을, 만들 수 없으면 0을 return 하도록 solution 함수를 완성해보세요.

```
def solution(before, after):
    a = sorted(before)
    b = sorted(after)

    for i in range(len(after)):
        if a[i] != b[i]:
            answer = 0
            break
        else:
            answer = 1

    return answer

print(solution("olleh", "hello")) #1
print(solution("allpe", "apple")) #0
```

```
def solution(my_string):
    print(list(set(my_string)))
    return my_string

```
