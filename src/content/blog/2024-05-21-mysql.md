## mysql 비밀번호 초기화

MySQL root 계정에 접속하려고 하는데 pw 오류로 접속이 안돼서 비밀번호 재설정 방법에 대해 알아보았다.

1. 작업관리자에서 mysql 혹은 mysqld를 종료
2. 관리자 권한으로 cmd 실행 후 mysql이 저장된 경로로 이동
3. 이동한 경로에서 mysqld.exe — skip-grant-tables — console — shared-memory 입력
4. **mysqld — initialize — console**
5. mysqld.exe — skip-grant-tables — console — shared-memory를 입력
6. 관리자 권한으로 cmd 새로운 창 실행 후 mysql -u root 입력
7. mysql에 정상 접속
8. NULL로 root 비밀번호 변경 , 다시 접속하여 진짜 비밀번호로 변경

```
use mysql;
UPDATE user SET authentication_string=null WHERE User='root';
select authentication_string from user; 
flush privileges; 
```

9. exit 명령어 입력.
10. 비밀번호 변경

```
ALTER USER 'root'@'localhost' IDENTIFIED WITH caching_sha2_password BY '새로 설정할 비밀번호';
```
