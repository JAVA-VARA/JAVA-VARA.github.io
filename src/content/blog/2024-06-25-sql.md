## 프로그래머스-SQL-**조건에 부합하는 중고거래 댓글 조회하기**

[**코딩테스트 연습 - 조건에 부합하는 중고거래 댓글 조회하기**  
*다음은 중고거래 게시판 정보를 담은 USED_GOODS_BOARD 테이블과 중고거래 게시판 첨부파일 정보를 담은 USED_GOODS_REPLY 테이블입니다. USED_GOODS_BOARD 테이블은 다음과 같으며…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/164673)[](https://school.programmers.co.kr/learn/courses/30/lessons/164673)

```
SELECT 
    G.TITLE, 
    G.BOARD_ID, 
    R.REPLY_ID, 
    R.WRITER_ID, 
    R.CONTENTS, 
    DATE_FORMAT(R.CREATED_DATE, '%Y-%m-%d') AS CREATED_DATE

FROM 
    USED_GOODS_BOARD G

JOIN
    USED_GOODS_REPLY R ON G.BOARD_ID = R.BOARD_ID

WHERE 
    G.CREATED_DATE >= '2022-10-01' AND G.CREATED_DATE < '2022-11-01'

ORDER BY 
    R.CREATED_DATE ASC, 
    G.TITLE ASC;
```
