### 09–2 클래스의 고급 기능

**[private 속성과 메소드]**

```
<script>
        class Square{
            constructor(length){
                this.length = length
            }
            getPerimeter(){return 4*this.length}
            getArea(){return this.length * this.length}
        }

        //클래스 사용하기
        const square = new Square(-10)
        console.log(`정사각혁의 둘레:${square.getPerimeter()}`)
        console.log(`정사각형의 넓이: ${square.getArea()}`)
    </script>

[실행결과]
정사각혁의 둘레:-40
정사각형의 넓이: 100
```

다만, 0 이하의 경우 예외를 발생시켜 클래스 사용자에게 그렇게 사용할 수 없다고 인지해주어야함**.**

**클래스 사용자가 클래스 속성(or 메소드)을 의도하지 않은 방향으로 사용하는 것을 막아 클래스의 안전성을 확보**하기 위해 나온 문법이**private** 속성과 메소드입니다.

```
    <script>
        //정사각형 클래스
        class Square2{
            constructor(length){
                if(length <= 0){
                    throw '길이는 0보다 커야합니다.'
                }
                this.length = length
            }
            getPerimeter(){return 4*this.length}
            getArea(){return this.length*this.length}
        }

        //클래스 사용하기
        const square2 = new Square2(-10) //=>음수 지정하는 것을 막을 수 없다.
        console.log(`정사각혁의 둘레:${square2.getPerimeter()}`)
        console.log(`정사각형의 넓이: ${square2.getArea()}`)
    </script>
```

private 속성 사용 시 속성과 메소드 이름 앞에 #을 붙이고, 사용하기전에 미리 외부에 어떤 속성을 사용하겠다고 선언해야함

```
class 클래스 이름{
#속성 이름
#메소드 이름(){}
}
```

```
<script>
        class Square3{
            #length //length 속성을 private 속성으로 사용하겠다고 선언.

            constructor(length){
                if(length<=0){
                    throw '길이는 0보다 커야합니다.'
                }
                this.#length = length
            }
            getPerimeter(){return 4*this.#length}
            getArea(){return this.#length * this.#length}
        }
        const square3 = new Square3(10) //=>음수 지정하는 것을 막을 수 없다.
        console.log(`정사각혁의 둘레:${square3.getPerimeter()}`)
        console.log(`정사각형의 넓이: ${square3.getArea()}`)
    </script>
```

**[게터(getter)와 세터(setter)]**

private 속성 사용하면 클래스 외부에서 접근할 수 없으므로 잘못 사용하는 문제를 줄일 수 있다. 그러나 접근이 불가능 하므로, square 객체의 length 속성이 몇 인지 확인할 수 없고, length 속성 변경이 불가능 하다. 상황에 따라 속성을 읽고 쓸 수 있는 메소드를 만들어서 제공해야 한다.

```
    <script>
        //정사각형 클래스
        class Square4{
            #length

            constructor(length){
                this.setLength(length)
            }

            setLength(value){
                if(value <= 0){
                    throw '길이는 0보다 커야합니다.'
                }
                this.#length = value
            }
            
            /*
            set 메소드: 속성에 값을 지정할 때 사용
            함수를 사용하므로 내부에서 예외 처리 등을 할 수 있다.
            */

            getLength(value){
                return this.#length
            }

            //get 메소드: 속성 값을 확인할 때 사용

            getPerimeter(){return 4*this.#length}
            getArea(){return this.#length * this.#length}
        }

        //클래스 사용하기
        const square4 = new Square4(11)
        console.log(`한 변의 길이는 ${square4.getLength()}입니다.`)

        //예외 발생시키기
        square4.setLength(-10)

    </script>
```

get 키워드와 set 키워드 조합하기

```
class 클래스이름{
   get 이름(){return 값}
   set 이름(value){}
        }
```

```
<script>

        //정사각형 클래스

        class Square{
            #length

            constructor(length){
                this.length =  length 
                //this.length에 값을 지정하면, 
                //set length(length) 메소드 부분이 호출
            }

            get length(){
                return this.#length
            }
            get perimeter(){
                return this.#length*4
            }
            get area(){
                return this.#length*this.#length
            }

            set length(length){
                if(length <= 0){
                    throw '길이는 0보다 커야하므니다'
                }
                this.#length = length
            }
        }

        //클래스 사용하기
        const squareA = new Square(15)
        console.log(`한 변의 길이: ${squareA.length}`)
        console.log(`둘레:${squareA.perimeter}`)
        console.log(`넓이: ${squareA.area}`)

        //예외발생시키기
        const squareB = new Square(-10)

    </script>
```

[static 속성과 메소드]

프레임워크 개발을 효율적으로 개발할 수 있도록 다양한 패턴 고안하는데 이러한 패턴을 ***디자인 패턴***이라고 한다.

static 속성과 메소드는 인스턴스를 만들지 않고 일반적인 변수, 함수처럼 사용할 수 있다.

```
    <script>
        class 클래스 이름{
            static 속성 = 값
            static 메소드(){}
        }
    </script>
```

- static 키워드 사용하기

```
 <script>
//#counter 라는 이름의 static 속성과 메소드를 만들었다.
        class Square{
            #length
            static #counter = 0 
            //private 특성과 static 특성은 한꺼번에 적용 가능하다.

            static get counter(){
                return Square.#counter
            }
            constructor(length){
                this.length=length
                Square.#counter += 1
                //counter 속성은 Square 객체의 생성자가 호출될 때 마다 1씩 증가하도록 설정
            }

            //perimeterOf 와 areaOf 메소드 추가하여 Square 객체를 생성하지 않고도 둘레와 넓이를 간단하게 구할 수 있게 설정.
            static perimeterOf(length){
                return length * 4
            }
            static areaOf(length){
                return length*length
            }
            get length(){return this.#length}
            get perimeter(){return this.#length *4}
            get area(){return this.#length*this.#length}

            set length(length){
                if(length <=0){
                    throw '길이는 0보다 커야 합니다.'
                }
                this.#length = length
            }
        }
        //static 속성 사용하기
        const squareA = new Square(10)
        const squareB = new Square(20)
        const squareC = new Square(30)  
        console.log(`지금까지 생성된 Square 인스턴스는 ${Square.counter}개입니다.`)

        //static 메소드 사용하기
        console.log(`한 변의 길이가 20인 정사각형의 둘레는 ${Square.perimeterOf(20)}입니다.`)
        console.log(`한변의 길이가 30인 정사각형의 넓이는 ${Square.areaOf(30)}입니다.`)
    </script>

[실행 결과]
지금까지 생성된 Square 인스턴스는 3개입니다.
한 변의 길이가 20인 정사각형의 둘레는 80입니다.
한변의 길이가 30인 정사각형의 넓이는 900입니다.
```

[오버라이드]

부모가 갖고 있는 함수를 자식에 다시 선언해서 덮어 쓰는 것

- 메소드에서 순서대로 메소드 호출하기

```
    <script>
        class LifeCycle{
            call(){
                this.a()
                this.b()
                this.c()
            }
            a(){console.log('a()메소드를 호출합니다.')}
            b(){console.log('b()메소드를 호출합니다.')}
            c(){console.log('c()메소드를 호출합니다.')}
        }

        //인스턴스를 생성합니다.
        new LifeCycle().call()

        //오버라이드 후 인스턴스 생성

        class Child extends LifeCycle{
            a(){
                console.log('자식의 a()메소드입니다.')
            }
        }
        new Child().call()

        //a()메소드에 있던 출력이 바뀜.
        //만약 부모에 있던 메소드의 내용도 사용하고 싶다면 
        //super.메소드()를 사용한다.

        class Child2 extends LifeCycle{
            a(){
                super.a()
                console.log('자식의 a()메소드입니다.')
            }
        }
        new Child2().call()
    </script>

[실행 결과 1]
a()메소드를 호출합니다.
b()메소드를 호출합니다.
c()메소드를 호출합니다.

[실행 결과 2(오버라이드)]
자식의 a()메소드입니다.
b()메소드를 호출합니다.
c()메소드를 호출합니다.

[실행 결과 3(super.메소드 사용)]
a()메소드를 호출합니다.
자식의 a()메소드입니다.
b()메소드를 호출합니다.
c()메소드를 호출합니다.
```

- toString()메소드 오버라이드하기

```
    <script>
        class Pet {
            constructor(name,age){
                this.name = name
                this.age = age
```
