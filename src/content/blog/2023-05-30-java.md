### 상수 선언:

final 이라는 키워드를 붙여 선언한다. 데이터 값이 바뀌지 않는 메모리 공간

```
public class ConstantExam {
    public static void main(String[] args) {
        int i;
        i = 10;
        i = 5;
        System.out.println(i);

        final int j;
        j = 100;
        // j = 10;
        System.out.println(j);

        final double PI = 3.14159;
        int radius = 3;
        double result = radius * 2 * PI;
        System.out.println(result);

        final int OIL_PRICE = 1450;
        int totalPrice = 50 * OIL_PRICE;
        System.out.println(totalPrice);

    }
}
```

### 기본형 형변환

- 묵시적 형변환: 작은 자료형을 더 큰 자료형으로 바꿀 때는 묵시적으로 형이 바뀐다.
- 명시적 형변환: 큰 자료형을 더 작은 자료형으로 바꿀 대는 명시적으로 형을 바꿔 준다.

```
public class TypeCastingExam {
    public static void main(String[] args) {
        int x = 5000;
        long y = x;
        System.out.println(y);

        long x2 = 5;
        // int y2 = x2 => 컴파일러가 에러를 발생시킨다.
        int y2 = (int) x2; // 강제 형변환을 통해 큰자료형을 더 작은 자료형으로 바꿀 수 있다.
        System.out.println(y2);

        int intValue = 200;
        long longValue = intValue;
        System.out.println(longValue);

        long longValue2 = 20;
        int intValue2 = (int) longValue2;
        System.out.println(longValue2);

    }
}
```

### 비교 연산자

```
public class OperationExam4 {
    public void calculate(int a, int b) {
        boolean c = a > b;
        boolean d = a == b;
        boolean e = a != b;

        System.out.println(a + "은(는)" + b + "보다 큽니까?" + c);
        System.out.println(a + "은(는)" + b + "와(과) 같나요?" + d);
        System.out.println(a + "은(는)" + b + "와(과) 다른가요?" + e);
    }

    public static void main(String[] args) {
        int a = (int) (Math.random() * 10);
        int b = (int) (Math.random() * 10);

        new OperationExam4().calculate(a, b);

        System.out.println(Math.random()); // 0~0.1 사이의 랜덤 값
        System.out.println(Math.random() * 10); // 0~10.0 사이의 랜덤 값
        System.out.println((int) Math.random() * 10); // 0~10 사이의 랜덤 값(형변환)

    }

}
```

### 삼항 연산자

- 조건식 ? 피연산자1 : 피연산자2

— 조건식의 연산 결과가 참이면 피연산자 1

— 조건식의 연산 결과가 거짓이면 피연산자 2

```
import java.util.Calendar;

public class TernaryExam {

    public static void main(String[] args) {
        int b1 = (5 < 4) ? 50 : 40;
        System.out.println(b1);

        int b2 = 0;
        if (5 > 4) {
            b2 = 50;
        } else {
            b2 = 40;
        }
        System.out.println(b2);

        int hour = Calendar.getInstance().get(Calendar.HOUR_OF_DAY);
        String ampm;
        ampm = hour < 12 ? "오전" : "오후";
        System.out.println("지금 시간은" + hour + "시 이고," + ampm + "입니다.");

    }

}
```

### Switch문

case, default, break 문으로 구성.

```
import java.util.Calendar;

public class SwitchExam {
    public static void main(String[] args) {
        int month = Calendar.getInstance().get(Calendar.MONTH) + 1;
        String season = "";
        switch (month) {
            case 12:
            case 1:
            case 2:
                season = "겨울";
                break;

            case 3:
            case 4:
            case 5:
                season = "봄";
                break;

            case 6:
            case 7:
            case 8:
                season = "여름";
                break;

            case 9:
            case 10:
            case 11:
                season = "가을";
                break;
        }
        System.out.println("지금은" + month + "월이고" + season + "입니다.");
    }
}
```

### While 문

```
public class WhileExam {

    public static void main(String[] args) {
        int i = 0;

        while (i < 10) {
            System.out.println(i);
            i++;

        }

        int total = 0;
        int j = 1;
        while (j <= 100) {
            total = total + j;
            j++;
        }
        System.out.println(total);

        int k = 1;
        while (k <= 10) {
            System.out.println(k);
            k++;

        }

        int x = 1;
        while (x < 11) {
            if (x % 2 == 0) {
                System.out.println(x);
            }
            x++;

        }

    }
}
```
