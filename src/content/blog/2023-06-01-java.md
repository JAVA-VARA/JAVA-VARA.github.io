### 변수 생성 및 소멸 시점

**클래스에서 사용하는 변수의 종류**

- **클래스 변수 **  
static 키워드가 붙은 변수. 클래스를 생성하지 않아도 실행파일이 메모리에 로드될 때 생성한다. 프로그램을 시작할 때 생성/종료 시 소멸

### 접근 제한자

클래스는 필드와 메서드를 가진다. 관련 있는 필드와 메서드를 모아놓은 것을 캡슐화 라고 한다. 캡슐화된 필드,메서드 중 외부에 노출하고 싶지 않은 속성이나 메서드에 대한 접근을 제한할 때 사용하는 것이 접근제한자이다. 필드, 메서드, 클래스 앞에 붙여 사용할 수 있다.

**[접근 제한자 범위]**

- public: 어떤 클래스는 접근할 수 있는 접근 제한
- protected: 같은 패키지인 경우만 접근 허용. 다른 패키지라도 상속받은 경우에는 접근 허용
- private: 자기 자신만 접근 가능
- default: 자기 자신 & 자기 자신과 같은 패키지 안에서 접근 허용
- 접근 제한자 범위의 넓이: public > protected > default > private

```
package javaStudy;

public class AccessObj {
    public int p1 = 3;
    protected int p2 = 4;
    private int i = 1;
    int k = 2; //default
}
```

```
package javaStudy;

public class AccessObjExam {
    public static void main(String[] args) {
        AccessObj obj = new AccessObj();
        System.out.println(obj.p1);
        System.out.println(obj.p2);
        System.out.println(obj.i); 
        //자기 자신만 접근 가능하므로 컴파일 오류가 발생.
        System.out.println(obj.k);
    }

}
```

- super() 키워드 사용

생성자는 객체를 초기화한다. 생성자가 호출될 때 자동으로 부모의 생성자가 호출되면서 부모 객체를 초기화한다. 부모의 생성자를 호출하기 위해서는 super() 라는 키워드를 사용한다.

```
package javaStudy;

public class Truck extends Car4 {
    public Truck() {
        super();
        System.out.println("Truck의 기본 생성자입니다.");
    }

}

Car4의 기본 생성자 입니다.
Truck의 기본 생성자입니다.
```

- super() 키워드 사용의 이유

```
package javaStudy;

public class Car4 {
    public Car4(String name) {
        System.out.println("Car4의 name 생성자 입니다.");
    }
```

Implicit super constructor Car4() is undefined. Must explicitly invoke another constructor

=> super()로 부모 생성자를 호출하지 않으면, 컴파일러는 기본 생성자만 호출한다. 그러나, 부모 클래스에 기본 생성자가 없는 경우, 위와 같은 error가 발생하기 때문이다.

=> 아래와 같이 super() 키워드를 통해 부모 생성자를 호출하면 error 없이 호출이 가능하다.

```
package javaStudy;

public class Truck extends Car4 {
```
