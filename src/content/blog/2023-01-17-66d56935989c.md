## 07. 문서 객체 모델

## 07–2. 이벤트 활용

[1]이벤트 모델

- 표준 이벤트 모델

```
document.body.addEventListener('keyup',()=>{})
```

- 고전 이벤트 모델: 문서 객체가 가지고 있는 ‘*on○○○’ *으로 시작하는 속성에 함수 할당하여 이벤트 연결

```
document.body.onkeyup = (event) =>{}

*onkeyup: 속성
```

- 인라인 이벤트 모델: *on○○○’ *으로 시작하는 속성을 HTML 요소에 직접 넣어서 이벤트 연결

```
<script>
const listener = (event) => {

}
</script>

<body onkeyup = "listener(event)">
</body>

*HTML 요소의 on○○○ 속성에 자바스크립트 코드를 넣는 것.
위 코드에서는 listener()라는 함수 호출하여 
on○○○ 속성 내부에서 변수 event를 활용할 수 있다.
이 변수를 listener() 함수의 매개변수로 전달한다.
```

[2] 키보드 이벤트

- keydown : 키가 눌릴 때 실행(입력 & 꾹 누르고 있을 때 모두 실행)
- keypress : 키가 입력되었을 때 실행(아시아권의 문자 제대로 처리 X)
- keyup : 키보드에서 키가 떨어질 때 실행

[2–1] 남은 글자 수 출력하기

```
키보드 이벤트로 입력 양식의 글자 수 세는 프로그램.

<!DOCTYPE html>
<html>
<head>

    <title>DOMContentLoaded</title>

    <script>
        document.addEventListener('DOMContentLoaded',()=>{
            const textarea = document.querySelector('textarea');

                h1.textContent = `글자수: ${length}`;
            })

</head>
<body>
    <textarea></textarea>
    <h1></h1>
    
    
</body>
</html>
```

[2]키보드 키 코드 사용하기

- code: 입력한 키
- kecCode: 입력한 키를 나타내는 숫자
- altKey: Alt 키 눌렀는지
- ctrlKey: Ctrl 키 눌렀는지
- shiftKey: Shift 키 눌렀는지

```
    <script>
         document.addEventListener('DOMContentLoaded',()=>{
            const h2 = document.querySelector('h2')
            const print = (event) => {
                let output=''
                output += `alt:${event.altKey}<br>`
                output += `ctrl:${event.ctrlKey}<br>`
                output += `shift:${event.shiftKey}<br>`
                //이벤트가 발생하면 불 값을 반환
                output += `code:${typeof(event.code) !== 'undefined' ? event.code:event.keyCode}<br>`
                //event.code가 있으면 event code를 출력하고 undeifned 이라면 event.keyCode를 출력합니다.
                h2.innerHTML = output
            }

            document.addEventListener('keydown', print)
            document.addEventListener('keyup', print)
        })

    </script>

<body>
<h2></h2>
</body>
```

```
아래와 같이 상황에 따라 이벤트 리스너 내부에서 textarea 변수에 접근할 수 없는 경우가 있음.
 

<script>
```

코드의 규모가 커지면 이벤트 리스너를 외부로 분리하게 되는 경우가 있는데 이때 이벤트를 발생시킨 객체에 접근하는 방법은 아래와 같다.

(1)event.currentTarget 속성 사용

```
    <script>
        const listener = (event) =>{
            const length = event.currentTarget.value.length
            h5.textContent = `글자 수:${length}`
        }

        document.addEventListener('DOMContentLoaded',()=>{
            const textarea = document.querySelector('textarea')
            const h5 = document.querySelector('h5')
            textarea.addEventListener('keyup', listener)
        })
    </script>

*위 코드에서는 event.currentTarget이 textarea가 된다.
```

(2) this 키워드 사용

```
<script>
    const listener =function(event){

        const textarea = document.querySelector('textarea')
```

[5]글자 입력 양식 이벤트

- 입력 양식(form): 사용자로부터 입력을 받을 때 사용하는 요소

(ex) textarea, button, select …

```
[button을 클릭할 때 inch를 cm 로 변환하는 프로그램]

<head>

    <title>Document</title>

    <script>
        document.addEventListener('DOMContentLoaded',()=>{
            const input = document.querySelector('input')
            const button = document.querySelector('button')
            const p = document.querySelector('p')
            //요소로 태그 설정

            button.addEventListener('click',()=>{
                //입력을 숫자로 변환합니다.
                const inch = Number(input.value)
                const cm = inch*2.54
                //숫자가 아니라면 바로 리턴합니다.
                if(isNaN(inch)){
                    //isNaN() 함수:어떤 값이 NaN(Not a Number)인지 판별
                    //매개변수 값이 숫자가 아니라면 true 값이 생성되고,
                    //이때 "숫자를 입력해주세요" 문구를 발행한다.
                    p.textContent = '숫자를 입력해주세요.'
                    return
                }

                //변환해서 출력합니다.
                //입력된 값이 숫자라면 아래와 같이 값을 변환해서 출력한다.
                
                p.textContent = `${cm}cm`
            })

        })
    </script>


<body>
    <input type="text">inch<br>

    <button>계산</button>
    <p></p>
    
</body>
```

[6]이메일 형식 확인하기

```
<!DOCTYPE html>
<html>
<head>

    <title>Document</title>

    <script>
//     1. 이메일, 전화번호 유효성 검사
//     2. 잘못된 이메일 또는 전화번호 실수로 입력하는 것을 막아준다

        document.addEventListener('DOMContentLoaded', ()=>{
            const input = document.querySelector('input')
            const q = document.querySelector('q')
            const isEmail = (value)=>{
                /*골뱅이를 가지고 있고 && 골뱅이 뒤에 점이 있다면...
                (isEmail() 함수는 indexOf()함수를 이용해 
                매개변수로 전달된 값이 이메일인지 확인하고   
                ture 또는 false 값으 리턴한다.)*/
                return (value.indexOf('@')>1)&&(value.split('@')[1].indexOf('.')>1)
            }

            input.addEventListener('keyup',(event)=>{
                const value = event.currentTarget.value
                //event.currentTarget: isEmail이 된다.
                if(isEmail(value)){
                    q.style.color='green'
                    q.textContent = `이메일형식입니다:${value}`
                } else {
                    q.style.color='red'
                    q.textContent = `이메일형식이아닙니다:${value}`
                }
            })

        })
    </script>
</head>
<body>
    <input type="text"></input>
    <q></q>


    
</body>
</html>
```

```
[select 태그를 이용하여 드롭다운 목록을 만들고,
```

[7–2]multiple select 태그

```
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Document</title>

    <script>
        document.addEventListener('DOMContentLoaded',()=>{
            const select = document.querySelector('select')
            const p = document.querySelector('p')

            select.addEventListener('change', (event)=>{
                const options = event.currentTarget.options
                const list = []
                for(const option of options){
                    if(option.selected){
                        list.push(option.textContent)
                    }
                }
                p.textContent=`선택:${list.join(',')}`
            })
        })
    </script>

</head>
<body>
    <select multiple>
        <option>1</option>
        <option>2</option>
        <option>3</option>
        <option>4</option>
        <option>5</option>

    </select>

    <p></p>
    
</body>
</html>
```

cm 단위를 여러 단위로 변환하는 프로그램

```
<!DOCTYPE html>

    <script>
        document.addEventListener('DOMContentLoaded',()=>{
            let currentValue
            let convert = 10

            const select = document.querySelector('select')
            const input = document.querySelector('input')
            const span = document.querySelector('span')

            const calculate = ()=>{
                span.textContent=(currentValue*convert).toFixed(2)
            }

            select.addEventListener('change',(event)=>{
                const options = event.currentTarget.options
                const index = event.currentTarget.options.selectedIndex
                convert = Number(options[index].value)
                calculate()
            })
            input.addEventListener('keyup',(event)=>{
                currentValue=Number(event.currentTarget.value)
                calculate()
            })
        })
    </script>
</head>
<body>
    <input type="text">cm=
    <span></span>
    <select>
        <option value="10">mm</option>
        <option value="0.01">m</option>
        <option value="0.393701">inch</option>
    </select>
    
</body>
</html>
```
