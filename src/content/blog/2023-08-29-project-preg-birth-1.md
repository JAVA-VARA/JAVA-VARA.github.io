### 기능 요구 사항 정리하기

지금까지 공부했던 것들을 응용하여 게시판 서비스를 만들어 보고자 한다. 작년부터 올해까지 임신/출산의 과정을 거치면서 자의로 그리고 와이프의 요청에 따라 필요한 정보를 찾아야 하는 경우가 많았다.

궁금한 부분에 대해 주치의 선생님께 질문하는 경우도 있었지만 구글링, 맘카페, 유튜브 등을 통해 상당수의 정보를 얻었다. 그 과정에서 정확한 정보의 부재, 인터넷에 떠도는 낭설들, 여기 저기 산재 되어 있는 정보에 대한 불편함을 느꼈다.

임신과 출산과 관련한 정확한 정보들을 보기 쉽도록 한 곳에 모으고, 유저들이 서로 소통할 수도 있는 게시판을 만들어보고 싶어 이 프로젝트를 진행하게 되었다.

## Project

- **Project Name:** Project_Preg&Birth
- **서비스 목적: **임신/출산을 앞둔 엄마, 아빠를 위한 정보 공유/전달 게시판 서비스

## 기능 요구 사항

아래와 같은 기능을 가진 게시판을 만들어 보고자 한다.

- **사용자**

### **1.로그인/회원가입**

1) 회원가입  
- 회원 정보: 이름, 닉네임, 주민번호, 성별, 전화번호, 이메일 주소, 사진(필수x) 포함.  
- 중복 가입 방지  
- 회원 가입 후 확인 이메일 전송

2) 로그인

3) 로그아웃

4) 아이디/PW 찾기  
- 아이디 찾기 버튼 누르면 해당 페이지로 연결 → 아이디를 이메일로 발송  
- PW 찾기 버튼 누르면 해당 페이지로 연결 → PW 변경 링크를 이메일로 발송 → 변경 화면 → 변경 완료 → 완료 시 로그인 페이지로 연결

### **2.마이페이지**

1) 프로필 수정(이름, 닉네임, 개인정보 등 수정 가능)

2) 내가 올린 게시물 확인 기능 -> 게시물 누르면 해당 페이지로 이동.

3) 회원 탈퇴 기능  
- 회원 탈퇴 후 확인 이메일 전송  
- 탈퇴한 회원 목록 저장.(관리자 페이지에서 확인 가능하도록 설정)

### **3.게시판**

1) CRUD 기능

2) 댓글, 대댓글 달기 기능

3) 첨부 파일(사진) 업로드 기능

4) 자신이 업로드한 게시글에 댓글이 달릴 경우 알림 기능

5) 유용한 사이트 링크 바로가기 기능 설정

6) 게시글 제목 옆에 작성 일자, 작성자, 조회수 표시

7) 화면 좌측에 게시판 카테고리 메뉴가 보이도록 설정 → 카테고리 클릭 시   
해당 페이지로 이동.

8) 게시글 찾기 기능(작성자, 제목)

9) Hot 게시판 기능  
- 조회수가 100 이상인 경우 게시판 상단에 노출  
-

4. 출산 예정일, D-DAY 확인 기능   
홈페이지 상단에 보이도록 설정(페이지를 이동해도 계속 보이도록 설정)

**[관리자]**

1. 대시보드(통계 기능)

1) 접속자 수 (월별, 연도별 확인)

2) 가입자 수 현황(월별, 연도별 확인)

3) 탈퇴한 회원 수(월별, 연도별 확인)

2. 게시글에 **“공지 사항”** 글 등록 가능 권한 부여.
