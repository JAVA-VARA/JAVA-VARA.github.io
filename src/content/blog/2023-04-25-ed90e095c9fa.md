### — 원소 삽입(일반적인 상황)

```
def insertAfter(self, prevm newNode):
  newNode.next = prev.next 
  #newNode의 next는 현재 prev가 가리키고 있는 node를 가리키도록함.
  prev.next = newNode #prev의 next가 가리키는 것을 삽입한 newNode로 바꿈.
  self.nodeCount += 1
   return True
```

### — 원소 삽입(tail에 삽입하는 경우)

```
def insertAfter(self, prevm newNode):
  newNode.next = prev.next 
  
  if prev.next is None:
    self.tail = newNode
   #만약 prev.next가 가리키는 것이 없다면 해당 node가 tail이므로,
   #self.tail이 newNode를 참조하도록 한다.

  prev.next = newNode 
  self.nodeCount += 1
   return True
```

**— 메서드 insertAt()의 구현**

(1) pos 범위 조건 확인  
(2) pos == 1 인 경우, head 뒤에 새 node 삽입  
(3) pos == nodeCount + 1 인 경우 prev ← tail  
(4) pos != nodeCount + 1 인 경우 prev ← getAt(…)

```
def inserAt(self, pos, newNode):
  if pos < 1 or pos > self.nodeCount + 1:
    return False

  if pos != 1 and pos == self.nodeCount +1:
    prev =  self.tail

  else:
    prev = self.getAt(pos-1)

return self.insertAfter(prev, newNode)
```

### — 원소 삭제(일반적인 상황):

prev의 다음 node를 삭제하고, 그 node의 data를 return

**[코드 구현 시 주의 사항]**  
(1)prev 가 마지막 node 일때(prev.next = None)  
- 삭제할 node가 없음  
- return None

(2)리스트 맨 끝 node를 삭제할 때(curr.next = None)  
- tail 조정 필요함.

### — 두 리스트의 연결

 def concat(self, L):

    if L.tail:
      self.tail = L.tail

## 양방향(이중) 연결리스트(doubly linked lists)

![](/images/medium/ed90e095c9fa/2.png)

### Node의 구조 확장

```
class Node:
  def __init__(self.item):
    self.data = item
    self.prev = None
    self.next = None
```

### dummy node

dummy node를 리스트 처음,끝에 모두 추가.   
 → data 를 담고 있는 node들은 모두 같은 모양이 된다.

![](/images/medium/ed90e095c9fa/3.png)

```
class DoublyLinkedList:

    def __init__(self,item):
        self.nodeCount = 0

        self.head = Node(None)
        self.tail= Node(None)
        #1 head와 tail을 아무 data를 가지지 않는 node로 만든다.

        self.head.prev = None
        self.head.next = self.tail #2 head의 next 는 tail로
        self.tail.prev= self.head #3 tail의 prev는 head로 만든다.
        self.tail.next= None
```

![](/images/medium/ed90e095c9fa/4.png)

### — 리스트 순회

```
def traverse(self):
    result = []
    curr = self.head
    while curr.next.next:
    #current 값의 next, next값이 유효하면 시행.
    #curr.next.next = None이 되는 것은 해당 node가 tail임을 의미한다.
        curr = curr.next
        result.append(curr.data)
    return result
```

### — 리스트 역순회

```
def traverse(self):
    result = []
    curr = self.tail
    while curr.prev.prev:
        curr = curr.prev
        result.append(curr.data)
    return result
```
