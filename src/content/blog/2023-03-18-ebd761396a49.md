## 07–1. 인공 신경망

[핵심 패키지와 함수] Dense 신경망에서 가장 기본층인 밀집층을 만드는 클래스

1. 이 층에 첫 번째 매개변수에는 뉴런의 개수 지정
2. acctivation 매개 변수에 사용할 활성화 함수 지정(softmax, sigmoid)
3. Sequential 클래스 맨 처음 추가되는 층에 input_shapte 매개변수로 입력 크기 지정

Sequential 케라스에서 신경망 모델을 만드는 클래스 클래스 객체 생성 시 신경망 모델에 추가할 층 지정 가능 1개 이상인 경우 파이썬 리스트로 전달

compile() 모델 객체를 만든 후 훈련하기 전에 사용할 손실 함수와 측정 지표 등을 지정하는 메소드

- loss 매개변수 => 손실 함수 지정
- metrics 매개변수 => 훈련 과정에서 측정하고 싶은 지표 지정.

evaluate 모델 성능 평가 메소드, 입력고 ㅏ타깃 데이터 전달


## 07–2. 심층 신경망

```
from tensorflow import keras
(train_input, train_target), (test_input, test_target) = keras.datasets.fashion_mnist.load_data()

from sklearn.model_selection import train_test_split
train_scaled = train_input / 255.0
train_scaled = train_scaled.reshape(-1, 28*28)
train_scaled, val_scaled, train_target, val_target = train_test_split(train_scaled, train_target, test_size=0.2, random_state=42)

#은닉층(은닉층의 개수 정할 때 특별한 기준 없음)
dense1 = keras.layers.Dense(100, activation='sigmoid', input_shape=(784,))

#출력층
dense2 = keras.layers.Dense(10, activation = 'softmax')

model = keras.Sequential([dense1, dense2])
#여러 개의 층을 만들 때 리스트로 만들어서 전달.(주의: 출력층을 제일 마지막에 배치)

model.summary()

#다른 방법1
model = keras.Sequential([
    keras.layers.Dense(100,activation = 'sigmoid', input_shape=(784,), name = 'hidden'),
    keras.layers.Dense(10, activation = 'softmax', name='output')
], name='패션 MNIST 모델')

model.summary()

#다른 방법2
model = keras.Sequential()
model.add(keras.layers.Dense(100, activation = 'sigmoid', input_shape=(784,)))
model.add(keras.layers.Dense(10, activation = 'softmax'))
model.summary()

#모델 훈련하기
model.compile(loss='sparse_categorical_crossentropy', metrics='accuracy')
model.fit(train_scaled, train_target, epochs=5)
```

[렐루 함수]

```
model = keras.Sequential()
model.add(keras.layers.Flatten(input_shape=(28,28)))
model.add(keras.layers.Dense(100, activation = 'relu'))
model.add(keras.layers.Dense(10, activation = 'softmax'))

model.summary()

(train_input, train_target), (test_input, test_target) = keras.datasets.fashion_mnist.load_data()

    train_scaled, train_target, test_size=0.2, random_state=42
)

model.compile(loss='sparse_categorical_crossentropy', metrics='accuracy')
model.fit(train_scaled, train_target, epochs = 5)

model.evaluate(val_scaled, val_target)
```

[옵티마이저]

신경망의 가중치와 절편을 학습하기 위한 알고리즘 또는 방법

- 기본 경사 하강법 / SGD 옵티마이저

```
sgd=keras.optimizers.SGD(learning_rate=0.1) #기본값 0.1, 변경 가능
model.compile(optimizer='sgd', loss = 'sparse_categorical_crossentropy', metrics='accuracy')
```

- 네스테로프: 모멘텀 최적화 모멘텀 최적화를 2번 반복하여 구현

```
sgd = keras.optimizers.SGD(momentum=0.9, nesterov = True)
```

- 적응적 학습률 옵티마이저

모델이 최적점에 가까이 갈수록 학습률을 낮출 수 있다.

```
# Adagrad
adagrad = keras.optimizers.Adagrad()
model.compile(optimizer = adagrad, loss='sparse_categorical_crossentropy', metrics = 'accuracy')

# RMSprop
rmsprop = keras.optimizers.RMSprop()
model.compile(optimizer = rmsprop, loss='sparse_categorical_crossentropy', metrics = 'accuracy')

# Adam: 모멘텀 최적화와 RMSprop 장점 접목한 것것
model.compile(optimizer = 'adam', loss='sparse_categorical_crossentropy', metrics='accuracy')
```
