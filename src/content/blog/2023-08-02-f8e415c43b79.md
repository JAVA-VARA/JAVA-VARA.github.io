### Solution_1

```
import java.util.HashMap;
import java.util.Map;

public class Solution {
    public String solution(String[] survey, int[] choices) {
        String answer = "";

        Map<Integer, Integer> scoreOfNum = new HashMap<>();
        int[] numbers = {1, 2, 3, 4, 5, 6, 7};
        int[] scores = {3, 2, 1, 0, 1, 2, 3};

        for (int i = 0; i < numbers.length; i++) {
            scoreOfNum.put(numbers[i], scores[i]);
        }

        Map<String, Integer> scoreBoard = new HashMap<>();
        String[] category = {"R","T","C","F","J","M","A","N"};
        for (String character: category){
            scoreBoard.put(character, 0);
        }

        for(int i = 0 ; i<choices.length;i++){
            if(choices[i] < 4){
                scoreBoard.put(String.valueOf(survey[i].charAt(0)), 
                scoreOfNum.get(choices[i]) + scoreBoard.get(String.valueOf(survey[i].charAt(0))));
            }
            if(choices[i] > 4){
                scoreBoard.put(String.valueOf(survey[i].charAt(1)), 
                scoreOfNum.get(choices[i])+ scoreBoard.get(String.valueOf(survey[i].charAt(1))));
            }
        }

        answer += scoreBoard.get("R") >= scoreBoard.get("T") ? "R" : "T";
        answer += scoreBoard.get("C") >= scoreBoard.get("F") ? "C" : "F";
        answer += scoreBoard.get("J") >= scoreBoard.get("M") ? "J" : "M";
        answer += scoreBoard.get("A") >= scoreBoard.get("N") ? "A" : "N";

        return answer;
    }

    public static void main(String[] args) {
        Solution mbtiTest = new Solution();
        System.out.println(mbtiTest.solution(new String[] {"AN", "CF", "MJ", "RT", "NA"}, new int[] {5, 3, 2, 7, 5}));
        System.out.println(mbtiTest.solution(new String[] {"TR", "RT", "TR"}, new int[] {7, 1, 3}));
    }
}

### Solution_2

```
public class MbtiTest {
    public String solution(String[] survey, int[] choices) {
        //StringBuilder pattern 사용*
        StringBuilder answerBuilder = new StringBuilder(); 
        //...중략...

        //key값에 string 대신 char 삽입.
        Map<Character, Integer> scoreBoard = new HashMap<>();
        char[] mbtiChars = {'R', 'T', 'C', 'F', 'J', 'M', 'A', 'N'};
        for (char character: mbtiChars){
            scoreBoard.put(character, 0);
        }

        for(int i = 0 ; i<choices.length;i++){
            //변수를 사용하여 가독성을 높였고, Map의 key값을 char로 설정하여
            //string -> char로 변환하는 과정을 없앴다.
            char firstChar = survey[i].charAt(0);
            char secondChar = survey[i].charAt(1);

            if(choices[i] < 4){
                scoreBoard.put(firstChar, scoreOfNum.get(choices[i]) + scoreBoard.get(firstChar));
            }
            if(choices[i] > 4){
                scoreBoard.put(secondChar, scoreOfNum.get(choices[i]) + scoreBoard.get(secondChar));
            }
        }
        //Builder 패턴을 사용하여 가독성을 높여보았다.
        answerBuilder
                .append(scoreBoard.get('R') >= scoreBoard.get('T') ? "R" : "T")
                .append(scoreBoard.get('C') >= scoreBoard.get('F') ? "C" : "F")
                .append(scoreBoard.get('J') >= scoreBoard.get('M') ? "J" : "M")
                .append(scoreBoard.get('A') >= scoreBoard.get('N') ? "A" : "N");
        
        return String.valueOf(answerBuilder);
    }
}

- StringBuilder:
1. 메모리 효율성

**문자열**의 경우에는 문자열 연산 시(solution_1에서 answer += x 에 해당하는 부분)마다 새로운 문자열 객체를 생성하며 반복적으로 문자열을 조작하는 경우 메모리 사용량이 늘어날 수 있다.

**문자 배열**은 해당 부분을 직접 수정할 수 있어서 연산이 더 효율적이고, 메모리 사용량을 줄일 수 있다.

2. 성능

**문자열**은 immutable한 자료형이기 때문에, 각 문자에 접근할 때마다 인덱스를 참조하여 해당 위치의 문자를 가져와야 한다. 이에 따라 문자열의 길이만큼의 시간 복잡도를 가진다.

**문자배열**은 메모리상에 연속된 구조로 저장되어 있어, 각 문자에 O(1) 시간 내에 접근 가능하며, 문자열의 길이와 무관하게 접근 속도가 일정하다.
