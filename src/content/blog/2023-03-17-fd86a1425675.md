## 06. 비지도학습

## 군집 알고리즘

타깃을 모르는 사진 종류별로 분류

비지도 학습: 훈련 데이터에 타킷이 없는 머신러닝의 한 종류. 타깃이 없기 때문에 외부의 도움 없이 학습해야함. ex) 군집, 차원 축소

히스토그램: 구간 별로 값이 발생한 빈도를 그래프로 표시한 것

군집: 비슷한 샘플끼리 하나의 그룹으로 모으는 비지도 학습 작업. 군집 알고리즘으로 모은 샘플 그룹을 클러스터라고 부른다.

## K-평균

[작동 방]

1. 무작위로 K개의 클러스터 중심을 정한다.
2. 각 샘플에서 가장 가까운 클러스터 중심심을 찾아 해당 클러스터의 샘플로 지정

```
import numpy as np
fruits = np.load('fruits_300.npy')
fruits_2d = fruits.reshape(-1,100*100)

from sklearn.cluster import KMeans
km=KMeans(n_clusters=3, random_state=42)
km.fit(fruits_2d)

#군집화된 결과는 KMeans 클랙스 객체의 label_ 속성에 저장된다.
#labels_ 배열의 길이는 샘플 개수와 같다

print(km.labels_)

print(np.unique(km.labels_, return_counts=True))

import matplotlib.pyplot as plt
def draw_fruits(arr, ratio=1):
  n=len(arr) #n은 샘플 개수, len()함수로 배열의 개수 알 수 있다.
  #ratio: figsize는 ratio 매개변수에 비례하여 커진다.
  
  #한 줄에 10개씩 이미지를 그린다.
  #샘플 개수는 10으로 나누어 전체 행 개수를 계산한다.
  #np.ceil()는 주어진 숫자보다 '크며' 가장 가까운 정수를 반환함.
  #np.floor()는 주어진 숫자보다 작으며 가장 가까운 정수 반환함.
  rows = int(np.ceil(n/10))
  
  #행이 1개이면 열의 개수는 샘플 개수입니다. 그렇지 않으면 10개 입니다.
  cols = n if rows < 2 else 10
  fig, axs = plt.subplots(rows, cols, figsize=(cols*ratio, rows*ratio), squeeze=False)
  for i in range(rows):
    for j in range(cols):
      if i*10 + j < n :
        axs[i,j].imshow(arr[i*10 + j], cmap='gray_r')
      axs[i,j].axis('off')
  plt.show()

#draw_fruits() 함수는 [샘플 개수, 너비, 높이]의 3차원 배열을 입력받아 가로로 10개씩 이미지를 출력한다.
#샘플 개수에 따라 행과 열의 개수를 계산하고 figsize를 지정
#figsize는 ratio 매개변수에 비례하여 커진다.
#ration의 기본값은 1
 
draw_fruits(fruits[km.labels_==0])
draw_fruits(fruits[km.labels_==1])
draw_fruits(fruits[km.labels_==2])


#[클러스터 중심]
#KMeans 클래스가 최종적으로 찾은 클러스터의 중심은 cluster_centers_ 속성에 저장되어 있다.
#이 배열은 fruits_2d 샘플의 클러스터 중심이기 때문에 
#각 중심을 이미지로 출력하려면 100*100 크기의 2차원 배열로 바꿔야 한다.
#KMeans 클래스는 훈련 데이터 샘플에서 클러스터 중심까지 거리로 변환해 주는 transform() 메소드를 가지고 있다.

draw_fruits(km.cluster_centers_.reshape(-1, 100, 100), ratio=3)

print(km.transform(fruits_2d[100:101]))
print(km.predict(fruits_2d[100:101]))
draw_fruits(fruits[100:101])

print(km.n_iter_)
```

[최적의 k찾기] k-평균 알고리즘의 단점 클러스터 개수를 사전에 지정해야 함.

- 엘보우(elbow) 방법: 클러스터의 개수를 늘려가면서 이너셔*의 변화를 관찰 최적의 클러스터 개수를 찾는 방법
- 이너셔(inertia): (클러스터 중심 ~ 클러스터 샘플 간의 거리)², 클러스터에 속한 샘플이 얼마나 가깝게 모여있는지 나타내는 값으로 클러스터가 증가할수록 이너셔 감소하며 최적의 개수 = 클러스터 개수와 이너셔 값의 그래프가 꺽이는 지점이다.

```
inertia = []

for k in range(2,7):
  km = KMeans(n_clusters=k, random_state=42)
  km.fit(fruits_2d)
  inertia.append(km.inertia_)
  #append() ()에 값 입력 => 새로운 요소를 array 맨끝에 객체로 추가 

plt.plot(range(2,7), inertia)
plt.xlabel('k')
plt.ylabel('inertia')
plt.show()
```

## 주성분 분석

[차원과 차원 축소]

특성: 데이터가 가진 속성. *과일 사진의 경우 10,000개의 픽셀이 있으므로, 10,000개의 특성 즉 차원이 있다고 할 수 있다.

[차원 축소] 주성분 분석(PCA, principal component analysis)

데이터에 있는 분산이 큰 방향을 찾는 것으로 이해 분산: 데이터가 널리 퍼져있는 정도, 분산이 큰 방향의 벡터를 *주성분이라고 한다.

- 주성분 벡터: 원본 데이터에 있는 어떤 방향
- 주성분 벡터의 원소 개수 = 원본 데이터셋에 있는 특성 개수

```
#PCA 클래스
!wget https://bit.ly/fruits_300_data -O fruits_300.npy

import numpy as np
fruits = np.load('fruits_300.npy')
fruits_2d = fruits.reshape(-1, 100*100)

from sklearn.decomposition import PCA

pca = PCA(n_components=50)
#n_component를 통해 주성분의 개수 지정

pca.fit(fruits_2d)

print(pca.components_.shape)

draw_fruits(pca.components_.reshape(-1,100,100))
print(fruits_2d.shape)

fruits_pca = pca.transform(fruits_2d)
print(fruits_pca.shape)

#원본 데이터 재구성

#inverse_transform() 메소드 사용하여 복원

fruits_inverse = pca.inverse_transform(fruits_pca)
print(fruits_inverse.shape)

fruits_reconstruct = fruits_inverse.reshape(-1, 100, 100)
for start in [0, 100, 200]:
  draw_fruits(fruits_reconstruct[start:start+100])
  print("\n")

print(np.sum(pca.explained_variance_ratio_))

plt.plot(pca.explained_variance_ratio_)
plt.show()
```

print(np.mean(scores['fit_time']))

scores = cross_validate(lr, fruits_pca, target)

pca.fit(fruits_2d)

print(pca.n_components_)
#결과값: 2

fruits_pca = pca.transform(fruits_2d)
print(fruits_pca.shape)
#결과값: (300,2)

#2개의 특성만 사용하고도 교차 검증의 결과가 좋을지 확인
scores= cross_validate(lr, fruits_pca, target)
print(np.mean(scores['test_score']))
print(np.mean(scores['fit_time']))
