### Solution_2

다른 사람이 각 단계를 메서드로 구현한 것을 보고, 내 코드도 저렇게 만들어 볼 수 있지 않을까 싶어 아래와 같이 구현해 보았다. 구현을 위해 공부하는 중에 체이닝 메서드라는 것을 알게 되어 공부한 내용을 적용해 보았다.

- 조건

```
1단계 new_id의 모든 대문자를 대응되는 소문자로 치환합니다.
2단계 new_id에서 알파벳 소문자, 숫자, 빼기(-), 밑줄(_), 마침표(.)를 제외한 모든 문자를 제거합니다.
3단계 new_id에서 마침표(.)가 2번 이상 연속된 부분을 하나의 마침표(.)로 치환합니다.
4단계 new_id에서 마침표(.)가 처음이나 끝에 위치한다면 제거합니다.
5단계 new_id가 빈 문자열이라면, new_id에 "a"를 대입합니다.
6단계 new_id의 길이가 16자 이상이면, new_id의 첫 15개의 문자를 제외한 나머지 문자들을 모두 제거합니다.
     만약 제거 후 마침표(.)가 new_id의 끝에 위치한다면 끝에 위치한 마침표(.) 문자를 제거합니다.
7단계 new_id의 길이가 2자 이하라면, new_id의 마지막 문자를 new_id의 길이가 3이 될 때까지 반복해서 끝에 붙입니다.
```

```
public class RecommandId {
    public String solution(String new_id) {

        String answer = new RekId(new_id)
                .replaceToLowerCase()
                .noSpecialChar()
                .toSingleDot()
                .noBlank()
                .noStartEndDot()
                .over15()
                .under3()
                .result();

        return answer;
    }

    private static class RekId {
        private String answer;

        RekId(String answer) {
            this.answer = answer;
        }
        //#1
        private RekId replaceToLowerCase() {
            answer = answer.toLowerCase();
            return this;
        }
        //#2
        private RekId noSpecialChar() {
            answer = answer.replaceAll("[^a-z0-9._-]", "");
            return this;
        }
        //#3
        private RekId toSingleDot() {
            while (answer.contains("..")) {
                answer = answer.replace("..", ".");
            }
            return this;
        }
        //#5
        private RekId noBlank() {
            if (answer.equals("") || answer.equals(".")) {
                answer = "a";
            }
            return this;
        }
        //#4
        private RekId noStartEndDot() {
            if (answer.charAt(0) == '.') {
                answer = answer.replaceFirst(".", "");
            }
            if (answer.charAt(answer.length() - 1) == '.') {
                answer = answer.substring(0, answer.length() - 1);
            }
            return this;
        }
        //#6
        private RekId over15() {
            if (answer.length() > 15) {
                answer = answer.substring(0, 15);
            }
            if (answer.charAt(answer.length() - 1) == '.') {
                answer = answer.substring(0, answer.length() - 1);
            }
            return this;
        }
        //#7
        private RekId under3() {
            while (answer.length() < 3) {
                answer += answer.charAt(answer.length() - 1);
            }
            return this;
        }
        //#8 결과 반환
        private String result() {
            return answer;

        }
    }
}
```

위와 같이 코드를 수정하므로써, 1~7단계 가 서로 독립적으로 작동할 수 있게되었고, 메서드의 작성 순서를 변경해도 결과에는 변동이 없음을 확인할 수 있었다.

각 단계가 독립적이기 때문에 나중에 id 추천 기능 변경이 필요한 경우 추가/삭제/수정이 용이하고, 나중에 새로운 id 추천 기능을 만들 때에도, 1~7 단계 메서드 중 필요한 코드만 골라 재사용 할 수 있기 때문에 시간도 절약할 수 있겠다.
