## 포인터로 연결 리스트 만들기

연결리스트에 데이터를 삽입할 때 노드용 인스턴스를 생성하고, 데이터를 삭제할 때 노드용 인스턴스를 없앤다.

Node: 데이터용 필드 data와 자신과 같은 클래스형의 인스턴스를 참조하기 위한 참조용 필드 next를 갖는다. 자신과 같은 형의 인스턴스를 참조하는 필드가 있는 구조를 자기 참조형(self-referential)이라고 한다.

```
from typing import Any, Type

class Node:
    def __init__(self, data: Any = None, next:Node = None):
        self.data = data
        self.next = next
```

Node class에는 __init__()함수가 있다. 이 함수는 전달 받은 data와 next를 해당 필드에 대입한다. 호출할 때 어떤 인수도 생략할 수 있으며, 생략할 경우 None으로 간주한다.

```
class LinkedList:
    
    def __init__(self) -> None:
        self.no = 0
        self.head = None
        self.current = None

    def __len__(self) -> int:
        return self.no
```

[1] __init()__ 함수: 노드가 하나도 없는 빈 연결 리스트를 생성한다. 머리 노드를 참조하기 위한 node형 필드 head에 none을 대입한다. 노드가 존재하지 않는 빈 연결 리스트는 head가 참조해야 하는 노드가 존재하지 않으므로 None 값으로 한다.

> 주의!!! head는 머리 노드에 대한 참조일 뿐 머리 노드 그 자체가 아니다!!!!

[2] len() 함수: 연결 리스트 노드의 개수를 반환하는 함수. no값을 그대로 반환한다.

**— 빈 연결 리스트: **노드가 존재하지 않을 때 head 값은 None이므로 아래식으로 리스트가 비어 있는지 검사할 수 있다.

```
head is None 
#연결 리스트가 비어 있는지 확인
```

**— 노드가 1개인 연결 리스트:** 노드가 하나만 존재하는 연결 리스트.   
Node가 머리형이면서 꼬리형이기 때문에 head가 참조하는 뒤쪽 포인터의 값이 None이므로 아래식으로 연결 리스트의 노드가 하나 뿐인지 검사할 수 있다.

```
head.next is None
```

**— 노드가 2개인 연결리스트**

```
head.next.next is None
```

**— 꼬리 노드의 판단:** Node 형인 변수 p가 리스트에 있는 노드를 참조한다면, p가 참조하는 노드가 연결리스트의 꼬리 노드인지 아래식으로 검사할 수 있다.

```
p.next is None
```

### **검색을 수행하는 search() 함수**

인수로 주어진 데이터 data와 값이 같은 노드를 검색하는 함수. 검색 알고리즘은 선형 검색을 사용한다. 찾고자 하는 노드를 만날 때까지 머리 노드부터 순서대로 스캔한다.

스캔 시 다음 조건 가운데 하나만 성립해도 검색이 종료된다.

- 종료 조건 1: 검색 조건을 만족하는 노드를 발견하지 못하고 꼬리 노드까지 간 경우
- 종료조건 2: 검색 조건을 만족하는 노드를 발견한 경우

```
#data와 값이 같은 노드를 검색
def search(self, data:Any)->int:

    cnt = 0  
    ptr = self.head

    while ptr is not None:
      if ptr.data == data:
        self.current = ptr
        return cnt
      cnt += 1
      ptr = ptr.next
    return -1

#연결 리스트에 data가 포함되어 있는지 확인.
def __contains__(self. data:Any) ->bool:
  return self.search(data) >= 0
```

### if __name__ == “__main__”에 대하여

```
if __name__=="__main__"
```

‘name 이라는 변수의 값이 main 이면 아래 코드를 실행해라’ 라는 뜻. 메인 함수의 시작을 의미하며, 현재 스크립트 파일이 실행되는 상태를 파악하기 위해 사용.

- 파이썬 코드 실행 방식
1. 들여쓰기를 통해 코드 실행의 레벨 결정
2. main이 존재하지 않는다. 대신 들여쓰기가 되지 않은 level 0의 코드를 가장 먼저 실행시킨다.

내장 변수 __name__: 현재 모듈의 이름을 담고 있는 내장 변수. 이 변수는 직접 실행된 모듈의 경우 __main__이라는 값을 가지게 되며, 직접 실행되지 않은 import 된 모듈은 모듈의 이름명(파일명)을 가지게 된다.

[예시]

- module.py

```
def hello():
    print('hello')
    
print(__name__)
hello()

[실행 결과]
__main__
hello
```

1. __name__내장 변수를 출력
- main.py

```
import module

print(__name__)
module.hello()

[실행 결과]
module
__main__
hello
```

1. import된 module의 __name__이 먼저 module이라는 이름으로 출력
2. main.py의 __name__이 가지고 있는 __main__이 출력
3. 모듈의 hello()함수 호출 결과가 출력

**직접 실행한 파일은__name__ 내장변수에 __main__이라는 값이 들어가고, import된 모듈은 각 모듈의 이름이 들어간다.**

module.py를 아래와 같이 수정하면,

```
def hello():
    print('hello')

if __name__ == "__main__":
    hello()

[실행결과]
hello
```

main.py에서 아래와 같이 실행된다.

```
import module

module.hello()

[실행결과]
hello
```
