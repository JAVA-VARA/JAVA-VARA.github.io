## 혼자 공부하는 자바 스크립트

DAY 2

03. 조건문

03–1. if 조건문

- **if 조건문: **조건에 따라 코드 실행 or 실행하지 않도록 사용
- **else: **if 조건문 뒤에 사용, if 조건문이 거짓일 때 출력
- **중첩 조건문:** 조건문 중첩해서 사용하는 경우
- **if else if 조건문:** 중첩 조건문에서 중괄호 생략!, 겹치지 않는 3가지 이상의 조건으로 나눌 때 사용

```
<script>
        //변수를선언합니다.


        const a=Number(prompt('월을 입력해주세요',''))
        if(3<=a&&a<=5){
            alert('입력한 달은 봄입니다.')
        } else if(6<=a&&a<=8){
            alert('입력한 달은 여름입니다.')
        } else if(9<=a&&a<=11){
            alert('입력한 달은 가을입니다')
        } else if(a===1||a===2||a===12){
            alert('입력한달은겨울입니다.')
        }else{
            alert('달은 1~12까입니다. 똑바로 입력해주십시오리너구리')
        }
</script>
```

오늘 공부한 내용을 가장 많이 사용하여 만들어 낸 조건문이다. 간단한 구문이지만, 예제의 정답을 보지 않고 처음 구현해내어 보았다는 것에 의의를:)

코드를 작성해보니, 처음부터 1~12 외의 숫자가 입력이 불가능하도록 처리할 수는 없을까? 영어 및 약어(January, Febuary, Mar, Apr,…etc) 혹은 다른 외국어를 입력했을 때도 입력한 값의 계절이 어느 계절인지 출력해낼 수 있는 방법은 무엇일까? 더 간단하고 효율적으로 작성하는 방법 등이 궁금해진다.
