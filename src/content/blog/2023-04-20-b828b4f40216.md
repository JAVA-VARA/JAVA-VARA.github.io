### **2. 리스트 순회**

**(예제)**추상적 자료구조로 `LinkedList` 라는 이름의 클래스가 정의되어 있다고 가정하고, 이 리스트를 처음부터 끝까지 순회하는 메서드 `traverse()` 를 완성하세요.

리턴하는 순서는 연결 리스트에 들어있는 데이터 아이템의 순서와 동일해야한다.  
예1)L에 들어 있는 노드들이 43 -> 85 -> 62 인 경우 => [43,85,62] 반환  
예2)빈 연결리스트인 경우 => [] 반환.

sol)  
0. 빈 array를 만든다.(array = [])  
1. curr.head 부터 시작해서 curr.next 값을 array.append(curr.next)로 추가  
2. curr.next가 none인 경우 반복문 종료  
- curr.next == None 반복문 종료  
- curr.next != None 이면 해당 노드의 curr.data 값을 arrary에 append()   
- curr의 포인터가 next node를 가리키도록 설정

```
class Node:
    def __init__(self, item):
        self.data = item #입력한 item을 연결리스트의 data(값)로 만들어주는 메소드
        self.next = None #다음 연결리스트의 값을 가리키는 메소드

class LinkedList:
    def __init__(self):
        self.nodeCount = 0 #리스트 내 노드 개수 count
        self.head = None #노드 첫번 째 값
        self.tail = None #노드 마지막 값

    def getAt(self, pos):
        if pos < 1 or pos > self.nodeCount: #pos라는 값을 입력했을 때 그 값이 1보다작거나, 노드의 총 길이보다 길면
            return None #none 반환
        i = 1 #그렇지 않으면 i =1이고,
        curr = self.head #curr 이라는 변수는 self.head(=>노드의 첫번째 값) 이다
        while i < pos: # i 값이 pos 값보다 작을 때까지,(원하는 인자까지 도달하면.)
            curr = curr.next #curr의 값은 curr.next 이다.(curr의 다음 연결 리스트의 값임.)
            i += 1
        return curr

    def traverse(self):
        array = []
        curr = self.head
        
        while curr != None: 
            array.append(curr.data)
            curr = curr.next
```

**[주의 사항을 유의하여 코드 재구성]**

```
def insertAt(self, pos, newNode):
  if pos < 1 or pos > self.nodeCount+1:
    return False

  if pos = 1: #맨 앞에 삽입하는 경우
    newNode.next = self.head
    self.head = newNode
  
   else:
    prev = self.getAt(pos-1)
    newNode.next = prev.next
    prev.next = newNode
  
  if pos = self.nodeCount+1 #맨 마지막에 삽입하는 경우
    self.tail = newNode

  self.nodeCount += 1
  return True
```
