4) Table 합치기(join 기능)

원하는 data의 table을 합칠 수 있는 기능.

```
SHOW TABLES;
RENAME TABLE topic TO topci_backup;
SHOW TABLES;
RENAME TABLE topci_backup TO topic_backup;
SELECT*FROM topic_backup;

CREATE TABLE `topic` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `title` varchar(30) NOT NULL,
  `description` text,
  `created` datetime NOT NULL,
  `author_id` int(11) DEFAULT NULL,
  PRIMARY KEY (`id`)
);

DROP TABLE author;

CREATE TABLE `author` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
```

6. DATABASE SERVER(service 제공자)

갑과 을에 해당하는 컴퓨터가 서로 정보를 요청/제공하면서 동작하는 시스템

- index(색인): 양적 완화의 구원 keyword, 사용자들이 검색을 자주 하는 컬럼에 색인을 걸어둠
- modeling: 성능, 설계 상 문제 해결을 위한 keyword
- backup: 내 컴퓨터와 별도의 컴퓨터에 복제해서 보관 , keyword: mysqldump, binary log
- cloud: 내 컴퓨터가 아닌 큰 회사들의 인프라를 임대해서 원격 제어, backup도 알아서 해줌 (ex)AWS RDS, Google Cloud SQL for MySQL, AZURE Database for MySQL
- programming: DB SYSTEM 핸들링 (ex) python mysql api, php mysql api, java mysql api
