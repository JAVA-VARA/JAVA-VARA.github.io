## while 문 반복

어떤 조건이 성립하는 동안 반복해서 처리하는 것을 ***반복 구조(루프/loop)라고 한다. ***while 문은 실행하기 전에 반복을 계속할 것인지를 판단하는데 이런 구조를 ***판단 반복 구조***라고 한다.

```
#1부터 N까지 정수의 합 구하기

print('1부터 n까지의 정수 합을 구합니다.')
n = int(input('n값을 입력하세요'))

sum = 0
i = 1

while i<=n:
    #여기서 부터 루프 본문
    sum += i
    i += 1

print(f'1부터 {n}까지의 합은 {sum} 입니다.')

[실행 결과]
1부터 n까지의 정수 합을 구합니다.
n값을 입력하세요5
1부터 5까지의 합은 15 입니다.
```

i값이 n값을 초과해야 while 반복을 마칠 수 있으므로, 반복문을 마친 뒤의 i값은 6이 된다.(5 아님)  
 => 반복을 제어할 때 사용하는 i를 카운터용 변수라고 한다. print로 i 값을 확인해보면 아래와 같이 6이 나온다.

```
print(f'i값은 {i}')

i값은 6
```

- **반복 과정에서 조건 판단하기 1**

```
#a부터 b까지의 정수의 합을 구하기 1
print('a부터 b까지의 정수의 합을 구합니다.')
a=int(input('a값: '))
b=int(input('b값: '))

if a>b:
    a,b=b,a

sum=0
for i in range(a, b+1):
    if i< b:
        print(f'{i} + ',end='')
        #i가 b보다 작으면 합을 구하는 과정 출력

    else:
        print(f'{i} = ', end='')
        #i가 b보다 크거나 같으면 최종값 출력을 위해 " i= " 을 출력

    sum += i
print(sum)

[실행 결과]
a부터 b까지의 정수의 합을 구합니다.
a값: 1
b값: 5
1 + 2 + 3 + 4 + 5 = 15
```

위 구문은 i<b 구문이 불필요하게 실행되어 효율이 좋지 않다. 이를 아래와 같이 개선할 수 있다.

```
#a부터 b까지의 정수의 합을 구하기 2
print('a부터 b까지의 정수의 합을 구합니다.')
a=int(input('a값: '))
b=int(input('b값: '))

if a>b:
    a,b=b,a

sum=0

for i in range(a, b):
        print(f'{i} + ',end='')
        sum += i

print(f'{b} = ', end='')
sum += b

print(sum)

[실행 결과]
a부터 b까지의 정수의 합을 구합니다.
a값: 1
b값: 5
1 + 2 + 3 + 4 + 5 = 15
```

실행 결과는 같지만 i가 b보다 크거나 같음을 판단하지 않으므로 판단 횟수가 n번에서 0번으로 줄어들고, 반복 횟수도 1회 감소하여 효율이 더 높다.

- **반복 과정에서 조건 판단하기 2**

```
#+와 -를 번갈아 출력하기 1

print('+와 -를 번갈아 출력합니다')
n = int(input('몇 개를 출력할까요?'))

for i in range(n):

[실행 결과]
+와 -를 번갈아 출력합니다

+-+-+-+-+-
```

★내 생각으로는 아래와 같이 코드가 작성되어야 한다고 생각했으나, 논리 연산에서 ***“0은 거짓/ 1은 참” or “0은 거짓/0 제외 참”***으로 처리한다는 사실을 알게 되어, 책에서와 같이 더 효율적으로 코드를 작성할 수 있음을 확인하였다.

```
for i in range(n):
    if i%2 != 0:
        print('-', end='') #i가 홀수인 경우 -출력★
    else:
        print('+', end='') #i가 짝수인 경우 +출력★

print()
```

*#+와 -를 번갈아 출력하기1*처럼 코드 작성 시 2가지 문제점이 있다.

1. for문을 반복할 때마다 if문 수행된다.
2. 상황에 따라 유연하게 수정하기 어렵다.

이를 해결하기 위해 아래와 같이 코드를 수정할 수 있다.

```
#+와 -를 번갈아 출력하기 2

print('+와 -를 번갈아 출력합니다')
n = int(input('몇 개를 출력할까요?'))

for _ in range(n//2): #파이썬에서 for 문을 순환하며 반환하는 값을 사요할 필요가 없을 때 '_'를 사용한다.
    print('+-', end='') #+-를 n//2개 출력

if n%2: #n값이 홀수면 반복문 종료 후 마지막에 '+'를 출력한다.
    print('+',end='')
```

효율적인 이유  
 1)반복문 내에서 if 구문 실행하지 않기 때문에  
 2)나눗셈도 n//2, n%2 두 번만 수행된다.  
 3)카운터용 변수를 0에서 1로 바꿔도 유연하게 대응 가능

```
for _ in range(1, n //2 +1):
    print('+-', end='')
```

n값을 먼저 2로 나누고 나중에 1을 더하는 것보다 (n+1)값을 2로 나누는 것이 더 직관적으로 코드를 표현할 수 있을 것 같아서 아래와 같이 코드를 변경해보았다.

```
#+와 -를 번갈아 출력하기 4

print('+와 -를 번갈아 출력합니다')
n = int(input('몇 개를 출력할까요?'))

for _ in range(1, (n+1)//2):
    print('+-', end='')

if n%2: 
    print('+',end='')
```

그러나 내 예상과는 다르게 +-가 한 set 씩 덜 출력되었다! 파이썬은 range(1, n)에서 n값 뒤에 소수점이 붙더라도 n-1 회까지만 반복을 진행하나보다.

- **반복 과정에서 조건 판단하기 3**

```
#*를 n개 출력하되 w개마다 줄바꿈하기 1

print('*을 출력합니다.')
n=int(input('몇개를 출력할까요우?'))
w=int(input('몇개마다 줄을 바꿀까요?'))

for i in range(n): #n번 반복
    print('*', end='')
    if i%w ==w-1: #n번 판단
        print() #줄바꿈

if n%w: #1번 판단
    print() #줄 바꿈
```

*#*를 n개 출력하되 w개마다 줄 바꿈 하기 1*과 같이 코드 작성 시 for 문을 반복할 때마다 if 구문이 수행되어서 비효율적이다. 아래와 같이 코드를 더 효율적으로 작성할 수 있다.

```
#*를 n개 출력하되 w개마다 줄바꿈하기 2

print('*을 출력합니다.')
n=int(input('몇개를 출력할까요우?'))
w=int(input('몇개마다 줄을 바꿀까요?'))

for _ in range(n//w): #n//w 번 반복
    print('*'*w)

rest = n%w
if rest: #if 문 판단 1번
    print('*' * rest)
```
