### Solution_1

```
package Programmers_Solution;

import java.util.LinkedList;
import java.util.Queue;
import java.util.Stack;

public class MakeBurger {
    public int solution(int[] ingredient) {
        Queue<Integer> queue = new LinkedList<>();
        Stack<Integer> stack = new Stack<>();
        LinkedList<Integer> list1 = new LinkedList<>();

        LinkedList<Integer> list2 = new LinkedList<>();
        list2.add(1);
        list2.add(2);
        list2.add(3);
        list2.add(1);

        for (int inside : ingredient) {
            queue.add(inside); 
        }

        while (!queue.isEmpty() && queue.peek() != 1) { 
            queue.poll();
        }

        int answer = 0;
        while (!queue.isEmpty()){
            int food = queue.poll();
            list1.add(food);
            stack.push(food);

            if(list1.size() < 4 ){
                continue;
            }

            if(list1.equals(list2)){
                answer +=1;

                stack.pop();
                stack.pop();
                stack.pop();
                stack.pop();

                list1.clear();
                if (stack.empty()) {
                    continue;
                }
                list1.add(stack.peek());
            }
            else{
                list1.removeFirst();
            }
        }
        return answer;
    }
        public static void main (String[]args){
            MakeBurger makeBurger = new MakeBurger();
            System.out.println(makeBurger.solution(new int[]{2, 1, 1, 2, 3, 1, 2, 3, 1}));
            System.out.println(makeBurger.solution(new int[]{1, 3, 2, 1, 2, 1, 3, 1, 2}));
        }
    }
```

### Solution_3

stack에 하나의 요소를 추가할 때마다 stack 내 마지막 4개의 요소를 꺼내어 내가 원하는 배열과 일치하는지 비교했다.

Solution_1에서 확인한 반례를 포함하면서, LinkedList를 사용함으로써 발생하는 시간복잡도 문제를 해결할 수 있었다.

```
import java.util.Stack;

public class Solution {
    public int solution(int[] ingredient) {
        int answer = 0;

        Stack<Integer> stack = new Stack<>();
        int [] burger = {1, 2, 3, 1};

        for (int inside : ingredient) {
            stack.push(inside);

            if(stack.size() < 4){
                continue;
            }

            int a = stack.pop();
            int b = stack.pop();
            int c = stack.pop();
            int d = stack.pop();

            if( a == 1 & b==3 && c == 2 && d == 1) {
                answer += 1;

            }else{
                stack.push(d);
                stack.push(c);
                stack.push(b);
                stack.push(a);
            }
        }
        return answer;
    }
}
```

### Solution_4

코드가 의미하는 바를 명확하게 하기 위해 Solution_2의 변수명과 if 구문을 수정하였다.

```
import java.util.Arrays;
import java.util.Stack;

public class MakeBurgerOpt {
    public int solution(int[] ingredient) {
        int answer = 0;

        Stack<Integer> stack = new Stack<>();
        int[] recipe = {1,2,3,1};

        for (int inside : ingredient) {
            stack.push(inside);

            if(stack.size() < 4){
                continue;
            }

            int order_4 = stack.pop();
            int order_3 = stack.pop();
            int order_2 = stack.pop();
            int order_1 = stack.pop();
            int[] isBurger = {order_1, order_2, order_3 ,order_4};

            if(Arrays.equals(isBurger, recipe)) {
                answer += 1;

            }else{
                stack.push(order_1);
                stack.push(order_2);
                stack.push(order_3);
                stack.push(order_4);
            }
        }
        return answer;
    }
}
```
