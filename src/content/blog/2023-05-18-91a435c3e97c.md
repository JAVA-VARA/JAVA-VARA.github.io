0번부터 n — 1번까지 n명의 학생 중 3명을 선발하는 전국 대회 선발 고사를 보았습니다. 등수가 높은 3명을 선발해야 하지만, 개인 사정으로 전국 대회에 참여하지 못하는 학생들이 있어 참여가 가능한 학생 중 등수가 높은 3명을 선발하기로 했습니다.

각 학생들의 선발 고사 등수를 담은 정수 배열 `rank`와 전국 대회 참여 가능 여부가 담긴 boolean 배열 `attendance`가 매개변수로 주어집니다. 전국 대회에 선발된 학생 번호들을 등수가 높은 순서대로 각각 a, b, c번이라고 할 때 10000 × a + 100 × b + c를 return 하는 solution 함수를 작성해 주세요.

### [sol1]

1. 대회 참여 가능 학생 선별  
 — attendance가 True 인 경우, 해당 index를 가지는 rank를 배열에 추가  
 — 등수 별로 나열(sort() 함수 사용)

2. 선별된 학생이 몇 번 index에 존재하는지 확인
3. 10000 × a + 100 × b + c 계산.

```
def solution(rank, attendance):
    answer1 = []
    answer2 = []

    for i in range(len(attendance)):
        if attendance[i] is True:
            answer1.append(rank[i])
    answer1.sort()

    for j in answer1:
        for k in range(len(attendance)):
            if j == rank[k]:
                answer2.append(k)

    return 10000 * answer2[0] + 100 * answer2[1] + answer2[2]


print(solution([3, 7, 2, 5, 4, 6, 1], [False, True, True, True, True, False, False]))
# 20403
print(solution([1, 2, 3], [True, True, True]))
# 102
print(solution([6, 1, 5, 2, 3, 4], [True, False, True, False, False, True]))
# # 50200
```

### [sol2]

제한사항

- `rank`의 원소는 1부터 n까지의 정수로 모두 서로 다릅니다.

위 제한 사항을 보고, rank 값을 key 값으로 하는 dictionary() 로 문제를 해결할 수 있을 것 같아 시도해보았고, 좀 더 효율적인 코드를 만들 수 있었다.

```
def solution3(rank, attendance):
    dict01 = {}
    for i in range(len(attendance)):
        if attendance[i]:
            dict01[rank[i]] = i

    dict02 = sorted(dict01.items())

    return dict02[0][1] * 10000 + dict02[1][1] * 100 + dict02[2][1]
```

### [sol3]

다른 사람의 풀이를 보고 enumerate() 함수를 이용하여 아래와 같이 코드를 변경해 보았다.

```
def solution2(rank, attendance):
    arr = []
    for i, attend in enumerate(attendance):
        if attend:
            arr.append((rank[i], i))

    arr.sort()

    a, b, c = arr[:3]

    return 10000 * a[1] + 100 * b[1] + c[1]
```

### enumerate():

파이썬 내장 함수. 인덱스와 원소로 이루어진 튜플(tuple)을 만들어준다.다.index를 0이 아닌 다른 수로 시작하고 싶은 경우, enumerate() 함수 호출 시 start 인자에 원하는 숫자를 입력한다.

```
for i, attend in enumerate(attendance, start=100):
    print(i, attend)
```
