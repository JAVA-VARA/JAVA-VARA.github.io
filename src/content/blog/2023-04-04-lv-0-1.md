오늘 프로그래머스 코딩테스트 LV.0의 문제들 중 해결하는데 가장 오랜 시간이 걸리고, 배울 점이 많았던 문제의 풀이 과정을 기록했다.

## [Q] 문자열 계산하기

`my_string`은 "3 + 5"처럼 문자열로 된 수식입니다. 문자열 `my_string`이 매개변수로 주어질 때, 수식을 계산한 값을 return 하는 solution 함수를 완성해주세요.

**[solution 1]**

eval(expression) 함수: expression 인자에 string 값(수식, 함수, 객체 등)을 넣으면 해당 값을 그대로 실행하여 결과를 출력

```
def solution(my_string):
    answer = eval(my_string)
    return answer
```

eval() 함수는 표현식을 그대로 실행시켜주기 때문에 편리하지만 보안 상의 취약점을 가지고 있다. 또한, 코드의 가독성이 떨어지고, 디버깅을 어렵게 만들 수 있기 때문에 사용이 지양된다고 한다.

그리하여 다른 방법을 통해 문제를 해결하고자, 아래와 같이 새롭게 코드를 작성하였다.

**[solution 2]**

문자열 내 수식* ”3–4–7 + 5 + 1"* 이 있어, 해당 문자열을 배열로 만든 후* “3+(-4)+(-7)+(+5)+(+1)”*와 같이 변형하여 계산한 값을 return 하고자 했다.

처음에 아래와 같이 String의 공백을 제거 후 list로 변환하면 될 것이라고 생각하여 코드를 작성했으나, 오류가 발생했다. print(string_list)로 확인해보니, 2자리 수 이상의 수가 오는 경우, 각 자리 수가 모두 배열의 요소로 변환되어 부정확한 계산값이 반환 됨을 확인하였다..(ex. 100 => [1,0,0]

```
def solution(my_string):
    #1 공백제거
    new_string = my_string.replace(' ','')

    #2 string 을 list 로 변환
    string_list = list(new_string)
    print(string_list)
    print(len(string_list))
    
    #3 연산자와 숫자 합치기
    sum = 0
    for i in range(1, len(string_list), 2):
        join_str = "".join(string_list[i:i+2])
        sum += int(join_str)

    #4 최종 결과값 환산

    answer = int(string_list[0]) + sum

    return answer

print(solution("3 - 4 - 7 + 5 + 1"))
print(solution("100 - 200 - 7 + 5 + 100 + 800"))
```

string을 split() 함수를 이용하여 list로 변환 후, 재시도하였고, 내가 원하는 값을 얻을 수 있었다.

- split() 함수: 문자열을 일정한 규칙으로 잘라서 리스트로 만들어 주는 함수

```
문자열.split(sep, maxsplit)
#문자열을 maxsplit 횟수만큼 sep의 구분자를 기준으로 
#문자열을 구분하여 잘라서 리스트로 만들어준다.

문자열.split() => 기본값: none 이며, 띄어쓰기(공백)을 기준으로 문자열을 자른다.
문자열.split('구분자')
문자열.split('구분자', 분할횟수)
문자열.split(sep='구분자', maxsplit=분할횟수)
```

```
def solution(my_string):
    #1 string 을 list 로 변환
    string_list = my_string.split()
    print(string_list)

    #3 연산자와 숫자 합치기
    sum = 0
    for i in range(1, len(string_list), 2):
        join_str = "".join(string_list[i:i+2])
        sum += int(join_str)

    #4 최종 결과값 환산

    answer = int(string_list[0]) + sum

    return answer


print(solution("3 - 4 - 7 + 5 + 1"))
print(solution("100 - 200 - 7 + 5 + 100 + 800"))
```

정답 제출 이후 나와 같은 개념으로 접근했지만 훨씬 더 간결하게 작성된 코드를 발견하여 참고하고자 가져왔다.

```
def solution3(my_string):
    answer = 0

    for i in my_string.replace(' - ',' + -').split(' + '):
        #print(int(i))
        answer += int(i)

    return answer

print(solution3("3 - 4 - 7 + 5 + 1"))
print(solution3("100 - 200 - 7 + 5 + 100 + 800"))
```
