### 03. 검색 알고리즘

## 03–1. 검색 알고리즘이란

- 선형검색: 무작위로 늘어놓은 데이터 집합에서 검색 수행
- 이진검색: 일정한 규칙으로 늘어놓은 데이터 집합에서 빠른 검색 수행
- 해시법: 추가/삭제가 자우 일어나는 데이터 집합에서 아주 빠른 검색 수행 — 체인법: 같은 해시값 데이터를 연결 리스트로 연결  
— 오픈 주소법: 데이터를 위한 해시값이 충돌할 때 재해시하는 방법

=> 용도, 목적, 실행 속도, 자료 구조 등을 고려하여 선택한다.

## 03–2. 선형 검색(=순차 검색/sequential search)

원하는 키값을 가진 원소를 찾을 때까지 맨 앞부터 스캔하여 순서대로 검색하는 알고리즘.

### **조건**

검색 실패: 검색할 값을 찾지 못하고 배열의 맨 끝을 지나간 경우  
검색 성공: 검색한 값과 같은 원소를 찾는 경우.

```
from typing import Any, Sequence

def seq_search(a:Sequence, key:Any)->int:
    i = 0

    while True:
        if i ==len(a):
            return -1 
            #1 종료조건: 검색해 실패하면 -1을 반환
        if a[i] == key:
            return i 
            #2 종료조건: 검색에 성공하여 현재 검사한 배열의 인덱스 반환
        i+=1

if __name__=='__main__':
    num = int(input('원소의 수를 입력하세요'))
    x = [None]*num

    for i in range(num):
        x[i] = int(input(f'x[{i}]:'))

    ky = int(input('검색할 값을 입력하세여'))

    idx = seq_search(x,ky)

    if idx == -1:
        print('검색값을 갖는 원소가 존재하지 않습니다.')
    else:
        print(f'검색값은 x[{idx}]에 있씁니다.')
```

## 03–3. 이진 검색(binary search)

원소가 오름차순이나 내림차순으로 정렬된 배열에서 효율적으로 검색할 수 있는 알고리즘.   
검색 진행 시 마다 검색 범위가 절반으로 좁혀진다. 주목할 원소를 다음에 검색할 범위의 중간 지점으로 바로 이동한다.

- 사용 조건: 데이터가 정렬(sort)되어 있어야 한다.

### 검색 범위 설정

- pl(첫번째 인덱스): 0  
pr(마지막 인덱스): n-1  
pc(pr과 pl의 중간 인덱스): n-1//2

1. **a[pc] < key 일 때**  
중앙에서 오른쪽으로 한 칸 이동하여 새로운 왼쪽 끝 pl로 지정하고, 검색 범위를 뒤쪽 절반으로 줄인다.  
- a[pl]~a[pc]는 제외  
- a[pc+1] ~ a[pr]로 범위 재설정.  
- pl 값을 pc +1로 업데이트 한다.
2. **a[pc] > key 일 때**  
중앙에서 왼쪽으로 한 칸 이동하여 새로운 오른쪽 끝 pr로 지정하고, 검색 범위를 앞쪽 절반으로 줄인다.  
- a[pl] ~ a[pc-1]로 범위 재설정.  
- pr 값을 pc-1로 업데이트 한다.  
- a[pc]~a[pr]는 제외
3. **검색 종료 조건**  
- a[pc]값이 key 값과 일치하는 경우  
- 검색 범위가 더 이상 없는 경우

```
from typing import Any, Sequence

def bin_search(a:Sequence, key:Any) -> int:
#시퀀스 a에서 key와 일치하는 원소를 이진 검색

    pl = 0
    pr = len(a)-1

    while True:
        pc = (pl+pr)//2 #중앙 원소의 인덱스
        if a[pc] == key:
            return pc
        elif a[pc] < key:
            pl = pc + 1 #검색 범위 뒤쪽 절반으로 좁힘
        else:
            pr = pc - 1 #검색 범위 앞쪽 절반으로 좁힘

        if pl > pr:
            break
        return -1

if __name__ == '__main__':
    num = int(input('원소 수를 입력해라'))
    x= num*[None]

    print('배열 데이터를 오름차순으로 입력하세요')

    x[0]=int(input('x[0]:'))

    for i in range(1, num):
        while True:
            x[i] = int(input(f'x[{i}]'))
            if x[i] >= x[i-1]: #w직전에 입력한 원솟값보다 큰 값을 입력
                break

    ky = int(input('검색할 값을 입력하세요'))

    idx = bin_search(x,ky)

    if idx == -1:
        print('검색값을 갖는 원소가 없읍니다.')
    else:
        print('검색한 값은x[{idx}]에 있습니다.')
```

***검색하는데 필요한 비교 횟수는 평균 log n이다.**  
- 검색에 실패하는 경우: log(n+1)  
- 검색에 성공하는 경우: log(n-1)

### 복잡도(complexity)

- **시간 복잡도:** 입력값의 변화에 따라 연산을 실행하는 때, 연산 횟수에 비해 시간이 얼마가 걸리는가 평가.
- **공간 복잡도:** 메모리(기억 공간)와 파일 공간이 얼마나 필요한지 평가
1. **선형 검색의 시간 복잡도**  
2가지 이상의 계산으로 구성된 알고리즘의 복잡도는 차원이 더 높은 쪽의 복잡도를 우선으로 한다.

```
                     실행 횟수 | 복잡도
i = 0              #1 1         O(1) =>데이터 수 n과 무관함.
 
while i < n:       #2 n//2      O(n)* =>2,3,5의 평균 시행 횟수는 n//2 이다.
  if a[i] == key:  #3 n//2      O(n)
    return i       #4 1         O(1)
  i+= 1            #5 n//2      O(n)
return -1          #6 1         O(1)    

*O(n): n에 비례하는 횟수만큼 실행되는 경우 복잡도는 O(n)으로 나타낸다.

위 선형 알고리즘의 복잡도는
O(n) = O(1) + O(n) +O(n) + O(1) + O(n) + O(1)
     = O(max(1, n, n, 1, n, 1))
```

## 03–4. 해시법(hashing)

#정렬된 배열에서 원소 추가하기: 중간에 새로운 값을 저장하려면, 추가하려는 값 뒤쪽의 원소들이 한칸 씩 뒤로 이동해야한다. 원소가 이동하는데 필요한 복잡도는 O(n)이고, 데이터가 커질 수록 비용이 증가한다.

=> 데이터 검색 + 추가/삭제를 효율적으로 수행할 수 있도록 해주는 알고리즘이 바로 해시법!

### 해시값(hash value)

배열의 키 값(원소의 값)을 원소의 개수로 나눈 나머지

### 해시 테이블(hash table)

**해시값을 “인덱스”로 하여** 원소를 새로 저장한 배열  
(데이터를 저장할 위치 = 인덱스)

### 해시 함수(hash function)

키를 해시값으로 변환하는 과정

### 버킷(buket)

해시 테이블에서 만들어진 원소(해시 값에 저장된 원소)

### 해시 충돌

새로 추가할 원소의 해시값이 기존의 해시값과 일치(충돌)하는 경우.  
(저장할 버킷이 중복되는 현상)

- 키와 해시값의 대응 관계가 1:1 일 필요는 없다.(키와 해시값은 일반적으로 다대 1*(n:1)*
- 해시법에서 충돌이 발생하는 경우 해결 방법  
 **[1]체인법:** 해시값이 같은 원소를 연결 리스트로 관리한다.  
 **[2]오픈 주소법:** 빈 버킷을 찾을 때까지 해시를 반복한다.

### [1]체인법(Chaining, 오픈 해시법)

해시값이 같은 데이터를 체인 모양의 연결 리스트로 연결하는 방법.  
배열의 각 버킷(해시 테이블)에 저장하는 것은 인덱스를 해시값으로 하는 연결 리스트의 앞쪽 노드*를 참조하는 것.

*노드(node): 관리할 데이터를 보관(존재)하는 곳. 자료구조에서 관리하고 있는 정보들 중 하나를 저장하고있는 단위. 데이터와 다음 데이터를 가리키는 주소(포인터, 참조값)로 이루어져 있다.

```
from __future__ import annotations
from typing import Any, Type
import hashlib

class Node:
    def __init__(self, key: Any, value: Any, next:Node) -> None:
        self.key = key
        self.value = value
        self.next = next
```

**#Node 클래스 만들기  
**Node 클래스는 개별 버킷을 나타낸다. 클래스에는 세가지 필드가 있다.

- key: 키(임의의 자료형)
- value: 값(임의의 자료형)
- next: 뒤쪽 노드를 참조(Node형)

```
from __future__ import annotations
from typing import Any, Type
import hashlib

class Node:
#키와 값이 짝을 이루는 구조. 키에 해시 함수를 적용하여 해시값을 구한다.
    def __init__(self, key: Any, value: Any, next:Node) -> None:
    #__init__()함수
    #key, value, next를 전달받아 
    #각각 대응하는 필드인 self.key, self.value, self.next에 대입
        self.key = key
        self.value = value
        self.next = next
```

**[Review]**

- **class(클래스): **변수, 메소드, 함수 등을 묶어서 하나의 새로운 객체로 만드는 것.  
(와플을 만드는 틀/기계)

- **Object(객체):** 클래스를 통해 만들어진 각 객체는 고유한 성격을 가진다.(와플 기계로 만든 와플)
- **instance(인스턴스):**클래스로 만든 객체.(객체가 메모리에 할당되어 실제 사용될 때 인스턴스라고 부른다.)특정 객체가 어떤 클래스의 객체인지를 관계 위주로 설명할 때 사용. 인스턴스 생성을 위해서는 클래스 이름 뒤에 ()를 넣으면 된다.

- **메서드(method): 클래스 안에서 구현하는 함수  
**메서드의 첫 번째 매개변수 이름은 클래스의 인스턴스 자신이고, 관례적으로 self 라는 이름을 사용한다.

- **class에 매서드 추가하기**

```
class ChainedHash:
    def __init__(self, capacity:int) -> None:        
        #class에 메소드는 아래와 같이
        #인스턴스.XXX의 형식으로 변수나, 메소드에 접근한다.

        self.capacity = capacity

```

- 생성자(**constructor**): 클래스를 기반으로 인스턴스를 생성할 때 처음 호출되는 메소드. 객체가 생성되면 자동으로 호출되어 객체를 초기화한다.

**#ChainedHash 해시 클래스 만들기  
**ChainedHash클래스는 필드 2개로 구성.

- capacity: 해시 테이블의 크기(배열 table의 원소 수)를 나타낸다.
- table: 해시테이블을 저장하는 list형 배열을 나타낸다.

```
class ChainedHash:

    def __init__(self, capacity:int) -> None:
        #1 Node형 인스턴스를 초기화

        self.capacity = capacity #해시 테이블의 크기를 지정
        self.table = [None]*self.capacity #해시 테이블(리스트)을 선언

    def hash_value(self, key:Any) -> int:
        #해시값을 구함

        if isinstance(key, int):
            return key%self.capacity
        return(int(hashlib.sha256(str(key).encode()).hexdigest(),16)%self.capacity)
```

1. **__init__() 함수로 초기화**  
빈 해시 테이블을 생성한다. 매개변수 capacity에 전달받은 것은 해시 테이블의 크기이다. 원소 수가 capacity 인 list 형의 배열 table을 생성하고 모든 원소를 none으로 한다.  
__init__() 함수가 호출된 직후 배열 table의 모든 원소는 None이다. 해시테이블의 각 버킷은 맨 앞부터 table[0], table[1],…table[capacity-1]순으로 접근 가능하다.

2. **hash_value() 해시 함수 만들기**  
hash_value() 함수는 인수 key에 대응하는 해시값을 구합니다.

**[2–1]해시와 해시 함수 알아보기**

- **key가 int 형인 경우  
**key를 해시 크기 capacity로 나눈 나머지를 해시값으로 한다.

- **key가 int 형이 아닌 경우  
**key가 정수가 아닌 경우 capacity로 나눌 수 없어 *표준 라이브러리**로 형 변환 후 해시값을 얻는다.

*[표준 라이브러리]**

- sha256 알고리즘: hashlib 모듈에서 제공하는 알고리즘을 바탕으로한다. 바이트 문자열의 해시값을 구하는 알고리즘의 생성자이다.
- encode() 함수: hashlib.256에 바이트 문자열 인수 전달해야한다. 이때 key를 str형 문자열로 변환한 뒤 그 문자열을 encode()함수에 전달하여 바이트 문자열 생성
- hexdigest()함수: 해시값을 16진수 문자열로 꺼낸다.
- int(): hexdigest()함수로 꺼낸 문자열을 16진수 문자열로 하는 int형으로 바꾼다.

### search()함수

키로 원소를 검색하는 search() 함수

1. 해시 함수를 사용하여 키를 해시값으로 반환
2. 해시값을 인덱스로 하는 버킷에 주목
3. 버킷이 참조하는 연결 리스트를 맨 앞부터 차례로 스캔. 키와 같은 값이 발견되면 검색 성공, 원소의 맨 끝까지 스캔해서 발견되지 않으면 검색에 실패

```
    def search(self, key: Any) -> Any:
        """키가 key인 원소를 검색하여 값을 반환"""
        hash = self.hash_value(key)  # 검색하는 키의 해시값
        p = self.table[hash]         # 노드를 노드

        while p is not None:
            if p.key == key:
                 return p.value  # 검색 성공
            p = p.next           # 뒤쪽 노드를 주목

        return None              # 검색 실패
```

③20 → 33 으로 찾아가면 검색에 성공

**(2)26 검색하기  
**①26의 해시값: 0   
②table[0]이 None이므로 검색에 실패합니다.

### add()함수

키가 key이고 값이 value인 원소 추가

1. 해시 함수를 사용하여 키를 해시값으로 변환
2. 해시값을 인덱스로 하는 버킷에 주목한다
3. 버킷이 참조하는 연결 리스트를 맨 앞부터 차례대로 선형 검색
4. 키와 같은 값이 발견되면 키가 이미 등록된 경우이므로 추가 실패
5. 원소 맨 끝까지 발견되지 않으면 해시값이 리스트의 맨 앞 노드를 추가한다.

```
def add(self, key: Any, value: Any) -> bool:
        """키가 key이고 값이 value인 원소를 삽입"""
        hash = self.hash_value(key)  # 삽입하는 키의 해시값
        p = self.table[hash]         # 주목하는 노드

        while p is not None:
            if p.key == key:
                return False         # 삽입 실패
            p = p.next               # 뒤쪽 노드에 주목

        temp = Node(key, value, self.table[hash])
        self.table[hash] = temp      # 노드를 삽입
        return True                  # 삽입 성공
```

③13을 저장하는 노드 생성  
④새로 생성된 노드에 대한 참조를 table[0]에 대입.

**(2)46 추가하기**

⑤추가한 노드의 뒤쪽 포인터인 next가 20을 주목하도록 노드를 업데이트 한다.

### remove()함수

키가 key인 원소를 삭제한다.

1. 해시함수를 사용하여 키를 해시값으로 변환
2. 해시값을 인덱스로 하는 버킷에 주목
3. 버킷이 참조하는 연결 리스트를 맨 앞부터 차례로 선형 검색.
4. 키와 같은 값이 발견되면 그 노드를 리스트에서 삭제
5. 없으면 삭제 실패.

```
# Do it! 실습 3-5[D]
    def remove(self, key: Any) -> bool:
        """키가 key인 원소를 삭제"""
        hash = self.hash_value(key)  # 삭제할 키의 해시값
        p = self.table[hash]         # 주목하고 있는 노드
        pp = None                    # 바로 앞 주목 노드

        while p is not None:
            if p.key == key:  # key를 발견하면 아래를 실행
                if pp is None:
                    self.table[hash] = p.next
                else:
                    pp.next = p.next
                return True  # key 삭제 성공
            pp = p
            p = p.next       # 뒤쪽 노드에 주목
        return False         # 삭제 실패(key가 존재하지 않음)
```

Example) **69삭제하기  
**①69 해시값: 4  
②table[4]에 저장되어 있는 참조하는 곳의 리스트를 선형 검색  
③이 노드 뒤쪽 노드는 17을 저장한다.  
④17을 저장한 노드에대한 참조를 table[4]에 대입하면 노드가 삭제된다.

### dump() 함수

해시 테이블의 내용을 한꺼번에 통째로 출력한다. 각 노드의 키와 값을 출력하는 작업 반복. 해시값이 같은 버킷이 연결 리스트에 의해 체인 모양으로 묶인 모습 확인할 수 있다.

```
    def dump(self) -> None:
        """해시 테이블을 덤프"""
        for i in range(self.capacity):
            p = self.table[i]
            print(i, end='')
            while p is not None:
                print(f'  → {p.key} ({p.value})', end='')  
                # 해시 테이블에 있는 키와 값을 출력
                p = p.next
            print()
```
