Day 1.

### 가상환경(virtual env)

독립적인 파이썬 실행 환경. 가상 환경을 생성하면, 각각의 가상 환경은 다른 가상 환경에 영향을 미치지 않아, 프로젝트별로 사용하는 패키지 버전 충돌 등을 방지한다.

### HTTP

HTML 문서와 같은 리소스들을 가져올 수 있도록 해주는 프로토콜.  
**(클라이언트-서버 프로토콜)**

![](/images/medium/c61789656333/1.png)

클라이언트와 서버들은 개별적인 메시지 교환에 의해 통신한다. 보통 브라우저인 클라이언트에 의해 전송되는 메시지를 요청(*requests*)이라고 부르며, 그에 대해 서버에서 응답으로 전송되는 메시지를 응답(*responses*)이라고 부른다.

![](/images/medium/c61789656333/2.png)

(출처:[https://developer.mozilla.org/ko/docs/Web/HTTP/Overview](https://developer.mozilla.org/ko/docs/Web/HTTP/Overview))

### HTTP Method:

1. GET: 리소스 조회, 검색. URL에 파라미터를 포함해서 요청을 보내며, 응답으로 HTML, 이미지, 텍스트 등을 받아온다.
2. POST: 요청 데이터 처리, 서버에 새로운 데이터를 생성, 기존 데이터를 업데이트할 때 사용. (ex. 로그인)
3. PUT: 리소스 대체, 덮어쓰기 시 사용
4. DELETE: 리소스 삭제 시 사용
5. PATCH: 리소스 부분 변경 시 사용

### 데코레이터

함수나 클래스를 꾸며주는 역할을 하는 파이썬의 기능. 함수나 클래스의 기능을 확장하거나 수정할 때 사용(함수를 감싸는 데코레이터는 함수의 호출 전, 후에 추가적인 로직을 수행한다.)
