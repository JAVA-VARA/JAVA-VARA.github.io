### 혼자 공부하는 자바스크립트

## 08. 예외 처리

### 08–1. 구문 오류와 예외

오류

- 구문 오류: 프로그램 실행 전 발생하는 오류, 코드가 실행되지 않는 오류
- 예외(런타임 오류):프로그램 실행 중 발생하는 오류, 코드 실행 중간에 발생하는 오류

[구문 오류]

구문 오류가 발생하는 코드

```
<script>
//프로그램 시작 확인
console.log('#프로그램이 시작되었습니다!')

//구문 오류가 발생하는 부분
console.log('괄호를 닫지 않는 실수를 했습니다'
</script>
```

[예외/런타임 오류]

```
    <script>
        //프로그램 시작 확인
        console.log("#프로그램이 시작되었습니다!")
        console.rog("log를 rog로 잘못 입력했습니다.")
    </script>
```

자바스크립트에서 SyntaxError라고 출력 되는 오류 이외의 모든 오류(TypeError, ReferenceError, RangeError)가 예외로 분류된다.

[기본 예외 처리]

조건문을 사용해서 예외가 발생하지 않게 만든다.

```
<querySelector()메소드로 추출된 문서 객체가 없는 경우>


<body></body>

<script>
    document.addEventListener('DOMContentLoaded',()=>{
        const h1 = document.querySelector('h1')
        h1.textContent = "안녕하세요"
    })
</script>

=> Uncaught TypeError: Cannot set properties of null
(querySelector() 메소드로 문서 객체를 추출한 뒤 textContent 속성에 글자를 할당하는 코드
그런데 body 태그 내부에 h1 태그가 없어 에러 발생함.)

<예외 처리로 해결!>
문서 객체를 선택했는데 문서 객체가 없는 경우, 
조건문으로 h2 태그가 존재하는 경우만 textContent 속성을 변경하도록 예외처리

<script>
    document.addEventListener('DOMContentLoaded',()=>{
        const h2 = document.querySelector('h2')
        if(h2){
            h2.textContent = "안녕하세요"
        } else{
            console.log('h2 태그를 추출할 수 없습니다')
        }
        
    })
</script>

[실행 결과]
h2 태그를 추출할 수 없습니다
```

[고급 예외 처리]

try catch finally 구문 사용

```
<script>
    try{
        //예외가 발생할 가능성이 있는 코드
    } catch(exception){
        //예외가 발생했을 때 실행할 코드
    } finally{
        //무조건 실행할 코드(필요한 경우에만 사용)
    }
</script>

try 구문 안에서 예외를 발생하면 이를 catch 구문에서 처리한다. 
finally 구문은 필수 사항은 아니며, 
예외 발생 여부와 상관없이 수행해야 하는 작업이 있을 때 사용한다.
```

<예시1-try, catch 사용>

```
<script>
    try{
        willExcept.byeBye()
        console.log('try 구문의 마지막 줄')
    } catch(exception){
        console.log('')
    } 
</script>

[실행 결과]
catch 구문의 마지막 줄

변수 willExcept 존재하지 않는데, willExcept의 byeBye()메소드를 사용함.
willExcept 객체, byeBye()메소드도 존재하지 않으므로,
프로그램은 예외를 발생해서 종료된다.
```

<예시2-try, catch,finally 사용>

```
<script>
    try{
        willExcept.byeBye()
        console.log('try 구문의 마지막 줄')
    } catch(exception){
        console.log('catch 구문의 마지막 줄')
    } finally{
        console.log('finally 구문의 마지막 줄')
        //예외 발생 여부와 상관 없이 무조건 실행되는 코드
    }
</script>

[실행 결과]
catch 구문의 마지막 줄
finally 구문의 마지막 줄
```

<예시3-finally>

finally 구문 사용 하는 이유

- try catch 구문 내부에서 return / break / continue 키워드 만날 때 결과가 달라진다.

```
<script>

        alert('C위치입니다.')

</script>

```

## 08–2. 예외 처리 고급

예외 객체: try catch 구문 사용 시 catch 괄호 안에 입력하는 식별

throw: 강제로 예외를 발생시킬 때 사용하는 키워드

[1]예외 객체 속성

name: 예외 이름

message: 예외 메시

```
    <script>
        try{
            const array = new Array(99999999999999999)
        } catch(exception){
            console.log(exception)
            console.log()
            console.log(`예외 이름: ${exception.name}`)
            console.log(`예외 메시지:${exception.message}`)
        }
    </script>

[실행 결과]
RangeError: Invalid array length
예외 이름: RangeError
예외 메시지:Invalid array length

*자바스크립트에서 배열 크기는 4,294,967,295까지 가능
일부러 오류 발생 시킨 후 예외 처리해봄.
```

[2]예외 강제 발생

- 예외를 강제로 발생시킬 때 throw 키워드 사용.

```
<script>
        throw 문자열 -> 단순하게 예외를 발생
         
        throw new Error(문자열) ->조금 더 자세하게 예외를 발생시킨다.

</script>
```

- 예외 강제로 발생시키고 잡기

```
<script>
    function divide(a,b){
        if(b===0){
            throw '0으로는 나눌 수 없습니다.'
        }
        return a/b
    }

    console.log(divide(10,2))
    console.log(divide(10,0))
</script>

[실행 결과]
5
Uncaught 0으로는 나눌 수 없습니다.
```

- 예외를 강제로 발생시키기

```
<script>
    function test(object){
        console.log(object.a+object.b)
    }
    test({})
</script>
```

위 코드 에서 두 가지 예외가 발생한다.

오류 1: object 객체에 a속성, b속성이 없다. 따라서 object.a와 object.b는 존재하지 않는 값이다.

오류 2: 존재하지 않는 값을 더하므로 object.a+object.b 실행 시에도 예외 발생한다.

하지만 자바스크립트의 경우 존재하지 않는 값에 대해 아래와 같이

object.a = undefined / object.b = undefined 로 출력된다.

이에 따라

object.a+object.b = undefined + undefined = NaN이 나와

오류 없이 코드가 정상적으로 실행된다. 위 코드를 안전하게 사용하기 위해 다음과 같이 강제로 예외를 발생시킨다.

```
<script>
    function test(object){
        if(object.a !==undefined&&object.b !==undefined){
            console.log(object.a+object.b)
        }else{
            throw new Error("a 속성과 b속성을 지정하지 않았습니다.")
        }
    }
    test({})
</script>

[실행 결과]
Uncaught Error: a 속성과 b속성을 지정하지 않았습니다.
```

[예제]

```
<script>
    try{
        console.log('try 구문입니다.')

        })
    }catch(e){
        console.log('catch 구문입니다.')
    }finally{
        console.log('finally 구문입니다.')

</script>

```
