[**코딩테스트 연습 - 즐겨찾기가 가장 많은 식당 정보 출력하기**  
*다음은 식당의 정보를 담은 REST_INFO 테이블입니다. REST_INFO 테이블은 다음과 같으며 REST_ID, REST_NAME, FOOD_TYPE, VIEWS, FAVORITES, PARKING_LOT…*school.programmers.co.kr](https://school.programmers.co.kr/learn/courses/30/lessons/131123)[](https://school.programmers.co.kr/learn/courses/30/lessons/131123)

#1 Try

```
SELECT FOOD_TYPE, REST_ID, REST_NAME, FAVORITES
FROM REST_INFO
GROUP BY FOOD_TYPE 
HAVING MAX(FAVORITES)
ORDER BY FOOD_TYPE DESC
```

![](/images/medium/b75adf32b88f/1.png)

실패…아래 구문을 통해 식당 별 즐겨찾기 수에 대해 비교해보았고, 일식에서 하이가쯔네보다 더 즐겨찾기 수가 많은 스시사카우스가 있지만, 해당 사항이 반영되지 않았음을 알게되었다.

```
SELECT REST_NAME,  REST_ID, FOOD_TYPE, MAX(FAVORITES) AS FAVORITES, FAVORITES
FROM REST_INFO
GROUP BY FOOD_TYPE
```

![](/images/medium/b75adf32b88f/2.png)

### [#2 TRY / Final Solution]

그룹 별 즐겨찾기 수의 최댓값만 먼저 추출해보았다.

```
SELECT MAX(FAVORITES) FROM REST_INFO GROUP BY FOOD_TYPE
```

![](/images/medium/b75adf32b88f/3.png)

위 값을 포함하는 열을 서브 쿼리를 이용하여 매칭 후, 문제에서 요구한 사항을 해결할 수 있었다.

```
SELECT FOOD_TYPE, REST_ID, REST_NAME, FAVORITES
FROM REST_INFO
WHERE FAVORITES IN (SELECT MAX(FAVORITES) FROM REST_INFO GROUP BY FOOD_TYPE)
GROUP BY FOOD_TYPE
ORDER BY FOOD_TYPE DESC
```
