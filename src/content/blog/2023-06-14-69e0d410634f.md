### [보호소에서 중성화 수술을 거친 동물의 정보]

**- 보호소 들어올 당시 중성화 X**

```
SEX_UPON_INTAKE FROM ANIMAL_INS_IN WHERE SEX_UPON_INTAKE LIKE 'Intact%'
```

**- 보호소 나갈 때 중성화 O**

```
SEX_UPON_OUTCOME FROM ANIMAL_OUTS WHERE SEX_UPON_OUTCOME LIKE 'Spayed%' OR SEX_UPON_OUTCOME LIKE 'Neutered%'
```

=> 위 두 조건을 만족하면서 테이블을 두 테이블을 INNER JOIN하여 최종적으로 아래와 같이SQL문을 작성하였다.

```
SELECT I.ANIMAL_ID, I.ANIMAL_TYPE, I.NAME
FROM ANIMAL_INS AS I
JOIN ANIMAL_OUTS AS O
ON I.ANIMAL_ID = O.ANIMAL_ID
WHERE 
I.SEX_UPON_INTAKE LIKE 'Intact%' AND
(O.SEX_UPON_OUTCOME LIKE 'Spayed%' OR O.SEX_UPON_OUTCOME LIKE 'Neutered%')
```
