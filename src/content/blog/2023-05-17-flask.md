## 템플릿의 공통화와 상속

jinja2 템플릿 엔진에는 공통의 템플릿 파일을 상속하는 기능이 있다. 공통 템플릿을 생성, 상속함으로써 중복된 코드를 쓸 필요가 없어진다.

### 공통 템플릿 생성

```
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>{% block title %}{% endblock %}</title>
    <link rel="stylesheet" href="{{url_for('crud.static', filename='style.css')}}"/>
</head>

<body>
    {% block title %}{% endblock %}  
</body>
</html>
```

상속처에서 개별의 구현이 필요한 부분에는 여러 개의 block을 아래와 같이 사용할 수 있다.

```
<body>
    {% block [block_name] %}{% endblock %}  
</body>
```

### **from_object 사용 방법**

config를 파이썬 객체로부터 읽어 들인다. 로컬 환경과 테스트 환경의 config 설정을 작성. 필요에 따라 스테이징 환경이나 실제 가동 환경의 설정을 추가한다.

- ***config : ***config 디렉터리는 환경 파일을 저장할 디렉터리이다. default.py 파일은 모든 환경에서 공통으로 사용할 환경 변수를 저장하고, production.py 파일은 서버 환경에서, development.py 파일은 개발 환경에서 사용할 환경 변수를 저장한다.
- config.py

```

# baseConfig 클래스 설정
class BaseConfig:

    WTF_CSRF_SECRET_KEY = "ADFASFDASDF"

# config 사전에 환경의 키명과 클래스명을 매핑한다.

    "testing": TestingConfig,
    "local": LocalConfig,
}
```

### from_pyfile

직접 파이썬 config 파일을 지정해서 읽어 들이는 방법. 환경별로 config를 준비해 두고, 이용하고 싶은 환경에 맞춰서 파일을 복사하여 config.py라는 파일명으로 변경함으로써 환경을 바꾼다.

한 개 이상의 항의 합으로 이루어진 식을 다항식이라고 합니다. 다항식을 계산할 때는 동류항끼리 계산해 정리합니다. 덧셈으로 이루어진 다항식 `polynomial`이 매개변수로 주어질 때, 동류항끼리 더한 결괏값을 문자열로 return 하도록 solution 함수를 완성해보세요. 같은 식이라면 가장 짧은 수식을 return 합니다.

sol)

1. 문자열로 주어진 인자를 배열로 변경
2. x가 포함된 항들과 정수로 이루어진 항을 구분한다.
3. 각각의 항을 더한다.
4. 조건에 맞추어 문자열로 변환한다.

```
def solution(polynomial):
    a = 0
    b = 0
    polynomial = polynomial.replace("+", "").split() 
    #공백제거, "+"를 기준으로 split하여 배열을 만든다.

    for i in polynomial:
        if "x" in i:
        #배열로 변환한 후 "x"를 포함하고 있는 값 중에서
            if len(i) >= 2:
             #길이가 2 이상인 경우, 계수가 2 이상이므로,
                a += int(i[:-1])
                #계수의 값을 더해준다.
            else:
                a += 1
                #길이가 1인 경우 계수의 값이 1이므로, 1을 더해준다.
        else:
            b += int(i)
            #"x"를 포함하지 않는다면, 정수를 의미하므로, 해당 값을 더해준다.
            
    if a == 0:
        return str(b)
    elif a==1:
        if b != 0:
            return f"x + {b}"
    elif a>1:
        if b ==0:
            return f"{a}x"
        else:
            return f"{a}x + {b}"

print(solution("3x + 7 + x")) #1
print(solution("x + x + x")) #2

print(solution("x + 7")) #3
print(solution("10x + 20x + 30x + 7")) #4
print(solution("7 + 11")) #5
print(solution("7 + 11x")) #6
print(solution("x"))  #7 =>1x
```

처음에는 #1, #2의 test case만을 가지고, 결괏값을 확인한 후 답안을 제출했으나, 일부 경우에서 통과하지 못했다. 통과하지 못한 경우의 수를 확인하고자 #3~#7까지 test case를 추가하였고, #7 test case에서 “1x” 가 return 되어, a==1 일 때, b==0 인 조건이 누락되었음을 알게되었다.
