## SQL Alchemy

파이썬이 제공하는 O/R 매퍼*, SQL 코드를 쓰지 않고 파이썬 코드로 데이터베이스를 조작할 수 있다.

- 데이터베이스와 프로그래밍 언어 간에 호환되지 않는 데이터를 반환한다.

### SQL Alchemy 설정

SQLite: 앱에 내장해서 이용하는 오픈 소스 데이터베이스. 로컬에 데이터를 파일로 저장할수도 있다.

- app.py

```
from pathlib import Path #1 Path를 import 한다.
from flask import Flask

from flask_migrate import Migrate #2 Migrate class를 import 한다.
from flask_sqlalchemy import SQLAlchemy #3 SQLAlchemy 클래스를 import 한다.

app = Flask(__name__)
db = SQLAlchemy() #4 SQLAlchemy를 인스턴스화한다.


@app.route("/")
def index():
    return "hello"


def create_app():
    app = Flask(__name__)
    #5 SQLite를 SQLAlchemy로 사용하기위해 앱의 config 설정을 한다.
    app.config.from_mapping(
        SECRET_KEY="123123123123123",
        SQLALCHEMY_DATABASE_URI=f"sqlite:///{Path(__file__).parent.parent / 'local.sqlite'}",
        #DATABASE URI에 SQLite의 데이터베이스를 출력하는 경로 지정
        SQLALCHEMY_TRACK_MODIFICATIONS=False, # Flase로 설정해야 경고문구가 나오지 않으므로 설정.
    )

    db.init_app(app) #6 SQLAlchemy와 앱을 연결한다.
    Migrate(app, db) #7 Migrate와 app을 연결한다.

    from apps.minimalapp.crud import views as crud_views

    app.register_blueprint(crud_views.crud, url_prefix="/crud")
    return app
```

### 데이터베이스 조작하기

- **flask db init: **데이터베이스 초기화 명령어. 명령어 실행 시 migrations 디렉터리가 생성된다.
- **flask db mirgrate:** 데이터베이스의 마이그레이션 파일을 생성하는 명령어. 모델 정의를 바탕으로 migrations/versions아래에 파이썬 파일로 데이터베이스에 적용하기 전의 정보가 생성된다.
- **flask db upgrade: **마이그레이션 정보를 실제로 데이터베이스에 반영하기 위한 명령어. 명령어 실행하면 users 테이블이 생성된다.
- **flask db downgrade: **migrate한 데이터베이스를 적용하기 전의 상태로 되돌릴 수 있다.

- **query filter: 주로 검색 조건을 좁히거나 정렬하기 위해 이용  
**— filter(): 조건에 맞는 값을 모두 가져온다.  
 — filter_by():레코드를 가져올 조건을 지정  
 — limit():가져올 레코드의 개수와 상한을 지정  
 — offset():레코드를 가져올 행의 시작 위치를 지정  
 — order_by(): 레코드 정렬  
 — group_by():레코드 그룹화

- **executer: SQL을 실행하고 결과를 취득하기 위해 이용  
 — all():**모든 레코드를 가져온다.  
** — first():** 1번째 레코드를 가져온다.  
** — first_or_404():**1번째 레코드를 가져오거나, 없으면 404 오류 반환  
** — get():**기본키를 지정하여 레코드를 가져온다.  
** — get_or_404():** 기본키를 지정하여 레코드를 가져오지 않으면 404 오류 반환  
** — count():**레코드의 개수를 가져온다.  
** — paginate(): **페이징으로 레코드를 취득한다.

- 사용 방법 예시

```

   .filter_by(id=2, username="admin") #query filter
   .all() #executer

from flask_wtf import FlaskForm
from wtforms import PasswordField, StringField, SubmitField
from wtforms.validators import DataRequired, Email, Length

# 사용자 신규 작성과 사용자 편집 폼 클래스

class UserForm(FlaskForm):
    # 사용자 폼의 username 속성의 라벨과 검증을 설정한다.
    username = StringField(
        "사용자명",
        validators=[
            DataRequired(message="사용자명은 필수입니다."),
            Length(max=30, message="30문자 이내로 입력해주세요"),
        ],
    )

    # 사용자폼email 속성의 라벨과 검증을 설정한다.
    email = StringField(
        "메일주소",
        validators=[
            DataRequired(message="메일주소는 필수입니다요"),
            Email(message="메일 주소의 형식으로 입력해주십사 부탁드립니다."),
        ],
    )

    # 사용자 폼 password 속성의 라벨과 검증을 설정한다.
    password = PasswordField("비밀번호", validators=[DataRequired(message="비밀번호는 필수입니다.")])

    # 사용자폼 submit의 문구를 설정한다.
    submit = SubmitField("신규 등록")
```

- apps/create/view.py(엔드포인트 만들기)

```
from flask import Blueprint, render_template, redirect, url_for
from apps.minimalapp.app import db  # db import
from apps.minimalapp.crud.model import User  # user class를 import 한다.
from apps.minimalapp.crud.forms import UserForm

@crud.route("/users/new", methods=["GET", "POST"])
def create_user():
    # UserForm을 인스턴스화한다.

    form = UserForm()
    if form.validate_on_submit():
        # 사용자를 작성한다.
        user = User(
            username=form.username.data,
            email=form.email.data,
            password=form.password.data,
        )

        db.session.add(user)
        db.session.commit()

        return redirect(url_for("crud.users"))
    # return render_template("apps/minimalapp/templates/crud/create.html", form=form)
    return render_template("crud/create.html", form=form)
```
