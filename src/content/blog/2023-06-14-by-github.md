## 1. CLI(Command Line Interface)

### **Linux 기반 cmd**

```
mkdir sample => sample이라는 이름의 디렉터리를 생성
cd sample => sample 디렉터리로 이동
cd .. => 부모 디렉터리로 이동
nano 파일이름.txt => 파일 생성
```

### **git 기본 명령어**

```
git => 저장소 설정
git init =>  Initialize repository
git status: working tree status
git add: add to staging area
git commit -m "메시지 작성": create version
git log: show version
git diff: show changes
git log -p
git checkout
git checkout [branch_name] branch 이동
git branch [branch_name] branch 생성
git rest --hard: git reset
=> 이전 버전으로 돌아간다. 돌아가고싶은 버전의 commit_id를 입력한다.
git revert [commit_id]
=> "버전을 삭제하지 않으면서!!!" 이전 버전으로 돌아간다.
바로 이전 단계로만 이동 가능하다.
```

### .gitignore

git으로 관리하고 싶지 않은 문서, 파일들은 .gitignore 폴더를 만들어 별도로 관리한다.

## 2. Branch & Conflict

## Branch

- git branch [branch명]으로 branch를 생성하여, 별도로 관리할 수 있다.
- git checkout [branch명]을 통해 원하는 branch로 이동하여 작업 가능하다.

### 병합(merge)

서로 다른 branch에서 작업한 내용을 서로 병합할 수 있다.

### 충돌(conflict)

작업한 사항이 겹치는 경우, 업데이트 된 사항을 자동으로 반영하지 않고, 사용자에게 어느 부분을 삭제할 수 있게 한다.
