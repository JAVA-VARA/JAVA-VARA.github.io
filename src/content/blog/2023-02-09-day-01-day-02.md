[숫자를 추측해서 맞히는 프로그램]

1. 1~30에 랜덤 숫자 지정  
2. 사용자가 랜덤 숫자 추측하여 입력  
3. 같으면 “정답”  
4. 틀리면 숫자를 맞힐 수 있게 힌트를 준다.

```
import random

n=random.randint(1,30) #1~30 사이 임의의 수를 뽑는다.

while True: #무한 반복
    x=input("숫자를 골라주세요")
    y=int(x) #입력한 값을 비교할 수 있도록 정수로 변환

    if y==n:
        print("즁답입니다!")
        break #정답을 맞히면 break로 while 반복 블록을 빠져나간다.
        
    if(y > n):
        print("다운!")
    if(y < n):
        print("업!")
```
