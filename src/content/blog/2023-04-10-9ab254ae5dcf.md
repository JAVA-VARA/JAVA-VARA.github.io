## 01–2. 반복적인 알고리즘

### **#가로 세로 길이가 정수이고 넓이가 area 인 직사각형에서 변의 길이 나열하기**

```
area = int(input('직사각형의 넓이를 입력하세요.'))

for i in range(1, area + 1):
    if i*i > area:
        # 구문이 참이면 break 시행 for 문이 강제 종료됨.
        break
    if area % i:
        #파이썬에서는 0: 거짓, 0 외의 수: 참 
        # => 나머지가 있다면(area가 i로 나누어 떨어지지 않으면) 
        # if 문이 참이 되므로 continue 구문 실행되어 for문의 다음 반복으로 진행.
        continue 
        
    print(f'{i}*{area//i}')
```

```
x and y == not x or not y
x or y == not x and not y
```

## 02–1. 자료구조와 배열

- **자료구조:** 데이터 단위와 자체 사이의 물리적 또는 논리적인 관계

### #등가성 vs 동일성

- 등가성(==): 좌변과 우변의 **“값”**이 같은지 비교
- 동일성(is): 좌변과 우변의 **“값” **+ **“객체의 식별번호”**까지 같은지 비교

### #내포 표기 생성

리스트 안에서 for, if 문을 사용하여 새로운 리스트를 생성하는 기법

```
numbers = [1,2,3,4,5]
twise = [num*2 for num in numbers if num%2 == 1]
print(twise)
```

## 02–2. 배열

### #시퀀스 원소의 최댓값 출력하기

```
#part 1
from typing import Any, Sequence

def max_of(a:Sequence) -> Any:
    #시퀀스형 a 원소의 최댓값을 반환
    maximum = a[0]
    
    for i in range(1,len(a)):
        if a[i] > maximum:
            maximum = a[i]
    return maximum

#part 2
if __name__=='__main__':
    print('배열의 최댓값을 구합니다.')
    num = int(input('원소 수를 입력하세요:'))

    x = [None]*num
    #원소 수가 num개인 리스트를 생성

    for i in range(num):
        x[i] = int(input(f'x[{i}]값을 입력하세여'))

    print(f'최대값은{max_of(x)}입니다.')
```

### #Part 1 **max_of 함수의 정의 및 특성**

- 정의

```
from typing import Any, Sequence

def max_of(a:Sequence) -> Any:
```

Any: 제약이 없는 임의의 자료형을 의미

Sequence: sequence형(sequence type**)을 의미

***리스트, 바이트 배열, 문자열, 튜플, 바이트열 등이 있다.*

1. 건네받는 매개변수 a 의 자료형은 Sequence type 이다.
2. 반환하는 것은 임의의 자료형인 Any 이다.
- 특성

```
def max_of(a:Sequence) -> Any:
#1. 함수 안에서는 배열 a의 원소 값을 변경하지 않는다.
#2. 호출하는 쪽이 넘겨주는 인수의 자료형은 시퀀스형 이라면 상관 없다.
    maximum = a[0]
    
    for i in range(1,len(a)):
        if a[i] > maximum:
        #3. 인수의 원소를 비교 연산자로 값을 비교할 수 있다면,
        #   다른형(int형, float형)이 섞여 있어도 된다.
            maximum = a[i]
    return maximum
    #최대값의 원소가 int형이면 int 값을 반환, float형이면 float값을 반환
```

### #Part 2 재사용할 수 있는 모듈 작성하기

- 모듈: 하나의 스크립트 프로그램, 확장자(.py)를 포함하지 않는 파일의 이름 자체를 모듈 이름으로 사용한다.
- 프로그램 파일 이름이 max.py 이므로, 모듈 이름은 max 이다.
- 모듈도 파이썬 객체의 일부이다.
- 프로그램이 처음 임포트되는 시점에 모듈 객체가 생성되면서 초기화된다.

*모듈 객체에는 __name__외에도, __loader__, __package__, __spec__, __path__, __file__ 등이 있다.*
