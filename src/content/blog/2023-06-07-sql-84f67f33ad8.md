## 1. 데이터베이스와 SQL

### [1]DBMS 정의(Database Management System)

데이터베이스를 관리하고 운영하는 소프트웨어. 여러 명의 사용자나 응용프로그램과 공유하고, 동시에 접근이 가능하다.

### [2]DB 모델링

테이블의 구조를 미리 설계, 결정하는 과정(현실에서 쓰이는 것을 테이블로 변경)

- 폭포수 모델(Waterfall model)
1. 프로젝트 계획
2. 업무 분석
3. 시스템 설계
4. 프로그램 구현
5. 테스트
6. 유지 보수

### [3]데이터베이스 구성

- 기본 키(PK,Primay Key): 각 행을 구분하는 유일한 열. 중복, 공백 허용하지 않음.

- 데이터 베이스
- DBMS
- 열
- 열 이름
- 데이터 형식
- 행
- SQL

## 2. SQL 기본 문법

### SELECT ~ FROM ~ WHERE

SELECT: 테이블에서 데이터를 추출하는 기능

SELECT **열 이름** FROM **테이블 이름**WHERE** 조건**

```
SELECT * FROM member;
SELECT mem_name from member;
SELECT addr, debut_date, mem_name From member;
SELECT addr, debut_date "데뷔 일자", mem_name From member;
select* FROM member WHERE mem_name = "블랙핑크";
select* from member WHERE mem_number = 4;
select mem_id, mem_name FROM member where height <= 162;
select mem_name, height, mem_number FROM member where height >= 165 AND mem_number >6;
select mem_name, height, mem_number FROM member where height >= 165 OR mem_number >6;
select mem_name, height FROM member where height between 163 AND 165;
SELECT mem_name, addr from member where addr IN('경기', '전남', '경남');
```

### LIKE

```
-- 일부 글자 검색
SELECT * FROM member where mem_name LIKE "우%";
SELECT * FROM member where mem_name LIKE "__핑크";
```

### 서브 쿼리

```
-- 서브 쿼리 / SELECT 문 안에 SELECT 추가.
SELECT height From member where mem_name = '에이핑크';
Select mem_name, height from member Where height >164;

-- 서브쿼리로 위 두 쿼리 합치기
SELECT mem_name, height from member WHERE height > (Select height from member where mem_name = '에이핑크');
```

### LIMIT

```
-- 전체중 앞에 3건만 조회

-- 데뷔일자가 빠른 회원 3건만 추출(주로 ORDER BY와 함께 사용한다.)

-- 3번째부터 2건만 조회
SELECT mem_name, height From member order by height DESC LIMIT 3, 2;
```


### GROUP BY

```
SELECT mem_id, SUM(amount) FROM buy GROUP BY mem_id;
```

**[집계 함수]**

- SUM(): 합계

```
-- id별로 구매한 개수(amount)를 합쳐서 출력해준다. group by로 회원별로 묶어준 후에 sum()함수로 구매한 개수를 합쳐준다.
SELECT mem_id, SUM(amount) FROM buy GROUP BY mem_id;
SELECT mem_id "회원 아이디", SUM(amount) "총 구매 개수" from buy group by mem_id;
select mem_id "회원 아이디", SUM(price*amount) "총 구매 금액" from buy group by mem_id;
```

- AVG(): 평균

```
select AVG(amount) "평균 구매 개수" from buy;
select mem_id, AVG(amount) from buy group by mem_id;
```

- MIN(): 최솟값
- MAX(): 최댓값
- COUNT(): 행의 개수
- COUNT(DISTINCT):행의 개수(중복은 1개만 인정)

```
select count(*) from member; -- 전체회원수
select count(phone1) "연락처가 있는 회원" from member; -- 열이름값이 null인 것을 제외한 행의 개수를 count한다.select AVG(amount) "평균 구매 개수" from buy;
select mem_id, AVG(amount) from buy group by mem_id;
```

### HAVING

```
select 
mem_id "회원아이디", 
SUM(price*amount) "총 구매 금액" 
from buy group by mem_id 
having sum(price*amount) >1000
ORDER BY sum(price*amount) desc;
```

## 3. 데이터 변경을 위한 SQL 문

### INSERT

```
INSERT INTO 테이블[(열1, 열2, ....)] VALUES (값1, 값2....)
```

테이블 이름 다음에 나오는 열은 생략 가능하나, 이 경우, VALUES다음에 나오는 값들의 순서 및 개수는 테이블을 정의할 때 열의 순서 및 개수와 동일해야 한다.

```
USE market_db;

CREATE TABLE hongong1(toy_id INT, toy_name CHAR(4), age INT);
INSERT INTO hongong1 VALUES(1, '우디', 25);

-- 나이를 입력하고 싶지 않다면 생략 -> NULL 값이 들어간다.
INSERT INTO hongong1(toy_id, toy_name) VALUES(2, '버즈');

-- 열의 순서를 바꿔서 입력하고 싶은 경우, 열 이름과 값을 원하는 순서에 맞춰 써준다.
INSERT INTO hongong1(toy_name, age, toy_id) VALUES('제씨', 20, 3);

-- 자동으로 증가하는 AUTO_INCREMENT
-- AUTO_INCREMENT 로 지정하는 열은 PK로 지정해줘야 한다.alter
CREATE TABLE hongong2(
toy_id INT AUTO_INCREMENT Primary key,
toy_name CHAR(4),
age INT);

INSERT INTO hongong2 VALUES(NULL, '보핍', 25);
INSERT INTO hongong2 VALUES(NULL, '슬링키', 22);
INSERT INTO hongong2 VALUES(NULL, '렉스', 21);
SELECT * FROM hongong2;

SELECT LAST_INSERT_ID();

-- 입력되는 값이 100부터 시작하도록 변경
ALTER TABLE hongong2 AUTO_INCREMENT=100;
INSERT INTO hongong2 VALUES(NULL, '재남', 35);
SELECT * FROM hongong2;
```

시스템 변수

MYSQL에서 자체적으로 가지고 있는 설정값이 저장된 변수. 시스템 변수 앞에는 일반적으로 @@가 붙는다.

- 시스템 변수 값 확인: SELECT @@시스템변수
- 전체 시스템 변수 종류 확인: SHOW GLOBAL VARIABLES

```
-- 입력되는 값 1000으로 지정, 입력값이 3씩 증가하도록 설정(시스템 변수 변경이 필요함.)
CREATE TABLE hongong3(
toy_id INT AUTO_INCREMENT PRIMARY KEY,
toy_name CHAR(4),
age INT);

ALTER TABLE hongong3 AUTO_INCREMENT = 1000;
SET @@auto_increment_increment=3;

INSERT INTO hongong3 VALUES (NULL, '토마스', 20);
INSERT INTO hongong3 VALUES (NULL, '제임스', 23);
INSERT INTO hongong3 VALUES (NULL, '고든', 25);

SELECT * FROM hongong3;
```

- 테이블의 데이터를 한 번에 입력(INSERT INTO ~ SELECT)

```
SELECT count(*) FROM world.city;
DESC world.city;

SELECT * FROM world.city LIMIT 5;

CREATE TABLE city_popul(city_name CHAR(35), population INT);
-- INSERT INTO 테이블_이름(열_이름1, 열_이름2,...) SELECT 문 ;
```

### UPDATE

```
-- 데이터 수정

-- UPDATE 테이블_이름 SET 열1=값1, 열2=값2,... WHERE 조건
```

```
USE market_db;
update city_popul
set city_name = '서울'
where city_name = "Seoul";

select*FROM city_popul where city_name = '서울';

-- city name 'New York"을 뉴욕으로 변경 및 인구수도 0으로 변경
update city_popul 
set city_name = '뉴욕', population = 0
where city_name = "New York";

select*from city_popul where city_name = '뉴욕';
```

- **where가 없는 update 문**

```
update city_popul
SET city_name = '서울';
```

모든 열이 ‘서울’로 변경된다. 일반적으로 where 없이는 update문 사용되는 경우가 없으므로, WHERE문이 없는 경우 주의해야 한다.

- 일부 열의 조건을 전체적으로 업데이트 가능하다.

```
update city_popul
SET population = population / 10000;
select * FROM city_popul LIMIT 5;
```

### DELETE

- New가 포함된 행 중 위에서 5개 삭제

```
DELETE FROM city_popul Where city_name LIKE 'New%'
LIMIT 5;
```

- 대용량 테이블 삭제

```
-- 대용량 테이블 삭제
create TABLE big_table1(Select * from world.city, sakila.country);
create TABLE big_table2(Select * from world.city, sakila.country);
create TABLE big_table3(Select * from world.city, sakila.country);

SELECT COUNT(*) from big_table1;

delete FROM big_table1;
DROP table big_table2;
truncate table big_table3;
```

- DROP: table 자체를 삭제
- DELETE: data 삭제, 테이블은 남아있다.(대용량 삭제 시 수행 시간이 오래 걸린다.)
- TURNCATE: data 삭제, 테이블은 남아있다. where문 사용 불가하여, 조건 없이, 테이블 전체의 데이터를 삭제하는 경우 사용

