## 07–1. 문서 객체 조작하기

![](/images/medium/c543b3904a98/1.png)

HTML 페이지에는 html, head, body, title 등의 요소가 있는데 Javascript 에서는 이를 ***문서객체 ***라고 부르며, 이를 조합해서 만든 전체적인 형태를 ***문서객체모델***이라고 한다.

[1] DOMContentLoaded 이벤트: 문서 객체 조작 시 사용

```
    <script>
        document.addEventListener('DOMContentLoaded',()=>{
            //문장
        })
    </script>

★오탈자 입력해도 오류 발생하지 않으므로 주의해서 입력!!
```

[1–1] HTML 코드를 자바스크립트로 조작하기

```
<!DOCTYPE html>
<html>
<head>

    <title>DOMContentLoaded</title>
    <script>
        //HTML 태그를 쉽게 만들 수 있는 콜백 함수를 선언합니다.
        const h1 = (text) => `<h1>${text}</h1>`
    </script>

    <script>
        document.body.innerHTML += h1('1번째 script 태그') -> h1 함수 실행
        //innerHTML : body 태그가 생성되기 이전에 script태그로 body 태그를 조작한다.
    </script>
</head>
<body>
    <script>
        document.body.innerHTML += h1('2번째 script 태그')
    </script>

    <h1>1번째 h1 태그</h1>
    <script>
        document.body.innerHTML += h1('3번째 script 태그')
    </script>
    <h1>1번째 h2 태그</h1>
</body>
</html>

★document.body.innerHTML: 
문서(document) 바디(body) 안에있는 HTML 코드(innerHTML)를 
자바스크립트로 조작할 수 있게 해주는 코드

body 태그 생성 전에 실행한 함수
"document.body.innerHTML += h1('1번째 script 태그')" 는 화면에 출력되지 않는다.
head 태그 내부에 script 태그를 배치하면 body 태그에 있는 문서 객체에 접근 불가능.
head 태그 내부의 script 태그에서 body 태그에 있는 문서에 접근하려면 화면의 문서 객체를
모두 읽어들일 때까지 기다려야 한다.
```

[1–2]DOMContentLoaded 이벤트 사용:

```
<!DOCTYPE html>
<html lang="en">
<head>
    <title>DOMContentLoaded</title>

    <script>
        //DOMContentLoaded 이벤트를 연결합니다.
        document.addEventListener('DOMContentLoaded',()=>{
            const h1 = (text) => `<h1>${text}</h1>`
            document.body.innerHTML += h1('DOMContentLoaded 이벤트 발생')
        })
    </script>
</head>
<body>
    
</body>
</html>
```

```
                header.textContent = 'HEADERS'
```

[2–2]querySelectorAll() 메소드: 문서 객체를 여러 개 추출. 문서 객체 여러 개를 배열로 내부 요소에 접근하고 활용하기 위해 반복문 사용. 일반적으로 forEach() 메소드 사용.

```
<script>
    document.addEventListener('DOMContentLoaded',()=>{
        //요소를 읽어들입니다.
        const header2s = document.querySelectorAll('h2')

        //텍스트와 스타일을 변경합니다.
        header2s.forEach((header2)=>{
            header2.textContent = 'HEADERS'
            header2.style.color = 'white'
            header2.style.backgroundColor='black'
            header2.style.padding = '10px'
        })
    })

</script>

    </head>
    <body>
        <h2></h2>
        <h2></h2>
        <h2></h2>
        <h2></h2>
        
    </body>
```

[3]글자 조작하기

- textContent 속성: 입력된 문자열을 그대로 넣어주고
- innerContent 속성: 입력된 문자열을 HTML 형식으로 넣어준다.

```
<script>
//textContent 속성: 입력된 문자열을 그대로 넣어주고
//innerContent 속성: 입력된 문자열을 HTML 형식으로 넣어준다.

    document.addEventListener('DOMContentLoaded',()=>{
        const a = document.querySelector('#a')
        const b = document.querySelector('#b')

        a.textContent = '<h3>textContent 속성</h3>'
        b.innerHTML = '<h3>innerContent 속성</h3>'
    })
</script>

    <body>
       
        <div id="a"></div>
        <div id = b></div>
        
    </body>

[출력]
<h3>textContent 속성</h3> -> 모든 글자가 그대로 들어감
innerContent 속성 -> <h3></h3>을 HTML 형식으로 출력
```

[6]문서 객체 생성하기

문서 객체를 생성하고 싶은 경우 document.createElement() 메소드 사용

```
document.createElement(문서객체이름)

문서 생성 시 appendChild()메소드가 있음. 
부모 객체 아래에 자식 객체 추가 가능.

부모 객체.appendChild(자식객체)

<script>
    //document.createElement() 메소드로 h4 태그 생성.
    //이를 document.body 태그 아래에 추가
    document.addEventListener('DOMContentLoaded',()=>{
        //문서 객체 생성하기
        const header4 = document.createElement('h4') //h4 태그 생성

        header4.textContent = '문서객체 동적으로 생성하기'
        header4.setAttribute('data-custom', '사용자 정의 속성')
        header4.style.color='white'
        header4.style.backgroundColor='pink'

        document.body.appendChild(header4)
    }
    )


</script>
```

[9]이벤트 설정하기: 모든 문서 객체는 생성되거나 클릭되거나, 마우스를 위에 올릴 때 등 이벤트가 발생한다. 이벤트가 발생할 때 실행할 함수는 *“addEventListener()”* 메소드를 사용한다.

```
문서 객체.addEventListener(이벤트 이름, 콜백함수*)
*이벤트 리스너 또는 이벤트 핸들러라고 부른다.
```

```
[이벤트 연결하기]
h1 태그를 클릭할 때 이벤트 리스너(콜백 함수)를 호출
1. h1 태그 클릭(h1 태그 설정)
2. 내부 변수에서 counter 증가
3. 클릭 횟수 만큼 출력

<script>
        document.addEventListener('DOMContentLoaded',()=>{
            let counter = 0
            const h1 = document.querySelector('h1')

            h1.addEventListener('click',(event)=>{
                counter++
                h1.textContent = `클릭횟수: ${counter}`
            })
        })

    </script>

<style>
    h1{
        /*클릭을 여러번했을때 글자가 선택되는 것을 막기 위한 스타일*/
        user-select: none;
    }
</style>

<body>
    <script>
    <h1>클릭횟수:0</h1>
 </body>
```

[10]이벤트 제거

```
문서객체.removeEventListener(이벤트 이름, 이벤트 리스너)

1. 이벤트 리스너 부분: 연결할 때 사용했던 이벤트 리스너 삽입
2. 이벤트 리스너: 변수 또는 상수로 선언, 이를 이벤트 연결과 연결 제거에 활용
```

```
<!DOCTYPE html>
<html>
<head>

    <title>DOMContentLoaded</title>

    
<script>
    document.addEventListener('DOMContentLoaded', ()=>{
        let counter2 = 0
        let isConnect = false

        const h2 = document.querySelector('h2')
        const p = document.querySelector('p')
        const connectButton = document.querySelector('#connect')
        const disconnectButton = document.querySelector('#disconnect')

        const listener = (event) => {
            h2.textContent = `클릭 횟수:${counter2++}`
        }
        //이벤트를 제거하려면 이벤트 리스너를 변수 또는 상수로 가지고 있어야한다.

        connectButton.addEventListener('click',()=>{
            if(isConnect === false){
                h2.addEventListener('click',listener)
                p.textContent = '이벤트 연결 상태:연결'
                isConnect = true

            }
        })
        disconnectButton.addEventListener('click',()=>{
            if(isConnect === true){
                h2.removeEventListener('click',listener)
                //해제할 때 이벤트 리스너를 사용합니다.
                p.textContent = '이벤트 연결 상태:해제'
                isConnect = false
            }
        })
    })
</script>

<style>
    h2{
        /*클릭을 여러 번 했을 때 글자가 선택되는 것을 막기 위한 스타일*/
        user-select:none;
    }
</style>


</head>

<body>
    <h2>클릭 횟수:0</h2>
    <button id="connect">이벤트 연결</button>
    <button id="disconnect">이벤트제거</button>
    <p>이벤트 연결상태:  
</body>
</html>
```
